# PGP and GPG

## What is PGP?

**PGP (Pretty Good Privacy)** is encryption software used to:

- Encrypt files
- Encrypt emails
- Create digital signatures
- Verify file integrity

It helps keep data **private**, **secure**, and **unchanged**.

---

# What is GPG?

**GPG (Gnu Privacy Guard)** is an **open-source implementation** of the OpenPGP standard.

It provides the same core features as PGP, including:

- Encryption
- Decryption
- Digital signatures
- Key management

> **Simply put:** PGP is the technology, and **GPG** is a free implementation of it.

---

# Common Uses of GPG

GPG is commonly used for:

- Encrypting email messages
- Decrypting encrypted emails
- Digitally signing emails
- Encrypting files
- Verifying file integrity

---

# Generating a GPG Key Pair

Generate a new key pair with:

```bash
gpg --full-gen-key
```

During setup, GPG asks you several questions.

---

## 1. Choose Key Type

Example:

```text
(9) ECC (sign and encrypt)
```

This creates a key that can:

- Sign data
- Encrypt data

---

## 2. Choose Cryptographic Algorithm

Example:

```text
Curve25519
```

Different algorithms provide different security and performance characteristics.

---

## 3. Choose Key Expiration

Example:

```text
0 = Key never expires
```

You can choose:

- Days
- Weeks
- Months
- Years
- Never expire

---

## 4. Enter User Information

GPG asks for:

- Real name
- Email address
- Optional comment

Example:

```text
Real name: Strategos

Email:
strategos@tryhackme.thm
```

This information identifies your key.

---

# Generated Keys

After creation, GPG generates two keys.

## Public Key

- Shared with other people
- Used to encrypt messages sent to you
- Used to verify your digital signatures

---

## Private Key

- Kept secret
- Used to decrypt messages
- Used to create digital signatures

Never share your private key.

---

# Example Output

```text
pub ed25519

uid Strategos <strategos@tryhackme.thm>

sub cv25519
```

Meaning:

| Part | Meaning |
|------|---------|
| **pub** | Public key |
| **uid** | User information |
| **sub** | Subkey used for encryption |

# How Secure Communication Works

Suppose Alice wants to send Bob a secure message.

### Step 1

Bob shares his **public key**.

---

### Step 2

Alice encrypts the message using Bob's public key.

---

### Step 3

Bob receives the encrypted message.

---

### Step 4

Bob decrypts it using his private key.

```text
Alice

Message

↓

Encrypt using Bob's Public Key

↓

Encrypted Message

↓

Internet

↓

Bob

↓

Decrypt using Private Key

↓

Original Message
```

Only Bob can decrypt the message because only Bob has the private key.

---

# Digital Signing

GPG can also digitally sign data.

Signing proves:

- Who created the message
- The message has not been modified

The sender signs using:

```
Private Key
```

The receiver verifies using:

```
Public Key
```

---

# Protecting the Private Key

A GPG private key can be protected with a **passphrase**.

This is similar to protecting an SSH private key.

Example:

```
Private Key

↓

Encrypted with Passphrase
```

Without the correct passphrase, the private key cannot be used.

---

# Cracking Weak Passphrases

If the passphrase is weak, security tools like:

- **John the Ripper**
- **gpg2john**

can attempt to crack it.

Therefore, always use a **strong passphrase**.

---

# Backing Up Your Keys

Your private key is extremely important.

If you lose it:

- You cannot decrypt your encrypted messages.
- You may lose permanent access to encrypted files.

Always keep a secure backup.

---

# Importing a Backup Key

If you get a new computer, import your backup key:

```bash
gpg --import backup.key
```

This restores your GPG keys.

---

# Decrypting an Encrypted File

To decrypt a file:

```bash
gpg --decrypt confidential_message.gpg
```

GPG uses your private key to recover the original message.

---

# Key Terms

| Term | Meaning |
|------|---------|
| **PGP** | Pretty Good Privacy encryption software |
| **GPG** | Open-source implementation of OpenPGP |
| **Public Key** | Shared with others for encryption and signature verification |
| **Private Key** | Secret key used for decryption and digital signing |
| **Passphrase** | Password that protects the private key |
| **Digital Signature** | Proves authenticity and integrity of data |

---

# Summary

- **PGP** is software for secure communication.
- **GPG** is the free, open-source implementation of PGP.
- GPG can:
  - Encrypt files
  - Decrypt files
  - Encrypt emails
  - Digitally sign messages
- `gpg --full-gen-key` creates a public/private key pair.
- The **public key** is shared with others.
- The **private key** must always remain secret.
- A **passphrase** protects the private key.
- Back up your private key safely.
- Use `gpg --import` to restore keys on another computer.
- Use `gpg --decrypt` to decrypt encrypted files.
