# Conclusion

## What is Cryptography?

**Cryptography** is the science of securing communication and data using encryption, codes, and ciphers.

Its main goal is to protect information from attackers and unauthorized users.

---

## What is Cryptanalysis?

**Cryptanalysis** is the study of methods used to break, bypass, or defeat cryptographic systems **without knowing the secret key**.

Instead of creating secure encryption, cryptanalysis focuses on finding weaknesses in encryption algorithms or implementations.

---

## What is a Brute-Force Attack?

A **brute-force attack** is a method where an attacker tries **every possible password or encryption key** until the correct one is found.

### Example

Suppose a password is:

```text
1234
```

An attacker may try:

```text
0000
0001
0002
...
1234
```

Eventually, the correct password is found.

**Pros:**

- Guaranteed to work eventually.

**Cons:**

- Can take an extremely long time for strong passwords or large keys.

---

## What is a Dictionary Attack?

A **dictionary attack** is a smarter attack than brute force.

Instead of trying every possible combination, the attacker tries passwords from a **dictionary or wordlist**.

### Example

The attacker may try:

```text
password
admin
welcome
qwerty
football
letmein
```

This attack works because many users choose common words as passwords.

---

# Brute Force vs Dictionary Attack

| Brute Force | Dictionary Attack |
|-------------|-------------------|
| Tries every possible password or key | Tries common words and passwords |
| Slower | Faster |
| Guaranteed to succeed if given enough time | Only succeeds if the password exists in the wordlist |
| Much more computationally expensive | More efficient against weak passwords |

---

# Key Terms

| Term | Meaning |
|------|---------|
| **Cryptography** | Science of protecting communication and data using encryption |
| **Cryptanalysis** | Science of breaking or bypassing cryptographic systems |
| **Brute-Force Attack** | Tries every possible password or key |
| **Dictionary Attack** | Tries passwords from a dictionary or wordlist |

---

# Summary

- **Cryptography** protects communication using encryption and ciphers.
- **Cryptanalysis** attempts to break or bypass cryptographic security without knowing the key.
- A **brute-force attack** tries every possible password or key until it finds the correct one.
- A **dictionary attack** tries common words or passwords from a predefined wordlist, making it faster than brute force against weak passwords.
