# RSA (Rivest-Shamir-Adleman)

RSA is a **public-key (asymmetric) encryption algorithm** used to securely transmit data over **insecure networks**.

It allows two people to communicate securely even if an attacker can observe all the traffic.

---

# Why is RSA Secure?

RSA is based on a mathematical problem that is **easy in one direction but extremely difficult in the other**.

### Easy Task

Multiply two very large prime numbers.

Example:

```
113 × 127 = 14351
```

Even with much larger prime numbers, multiplication is relatively easy.

---

### Hard Task

Given:

```
14351
```

Find the two prime numbers that were multiplied together.

This is called **factorization**.

For very large numbers (hundreds of digits long), factorization is **practically infeasible** with current technology.

This mathematical difficulty is what gives RSA its security.

---

# Real-World RSA

In real applications:

- **p** and **q** are extremely large prime numbers (around 300 digits each).
- Their product (**n**) becomes a very large number (around 600 digits).

Computers can easily multiply these numbers but cannot efficiently factor the resulting product.

---

# RSA Key Pair

RSA uses two keys:

### Public Key

- Shared with everyone.
- Used to encrypt messages.

---

### Private Key

- Kept secret.
- Used to decrypt messages.

```
          Public Key 🔓
               │
Plaintext ──Encrypt──► Ciphertext
                           │
                    Private Key 🔐
                           │
                     Decrypt
                           │
                     Plaintext
```

# Simplified RSA Example

## Step 1: Choose Two Prime Numbers

Bob chooses:

```
p = 157
q = 199
```

---

## Step 2: Calculate n

```
n = p × q

n = 157 × 199

n = 31243
```

---

## Step 3: Generate Keys

Bob calculates the required RSA values.

He chooses:

```
Public Key

(n, e)

(31243, 163)
```

Private Key:

```
(n, d)

(31243, 379)
```

> The calculations used to generate **e** and **d** involve modular arithmetic and are beyond the scope of these notes.

---

# Encryption Example

Suppose Alice wants to send:

```
Message (m) = 13
```

Using Bob's public key:

```
Ciphertext

c = 13^163 mod 31243

= 16341
```

Alice sends:

```
16341
```

---

# Decryption Example

Bob receives:

```
16341
```

Using his private key:

```
m = 16341^379 mod 31243

= 13
```

Bob successfully recovers the original message.

# Why RSA Works

RSA relies on **modular arithmetic**.

The mathematical proof behind RSA is beyond the scope of this room.

The important idea is:

- Encryption uses the **public key**.
- Decryption uses the **private key**.
- Without the private key, recovering the original message is computationally infeasible.

# RSA in CTFs

RSA is commonly used in **Capture The Flag (CTF)** cryptography challenges.

Challenges often provide some RSA values, and your task is to recover the original message (flag).

---

# Important RSA Variables

| Variable | Meaning |
|----------|---------|
| **p** | First large prime number |
| **q** | Second large prime number |
| **n** | Product of **p × q** |
| **e** | Public exponent |
| **d** | Private exponent |
| **m** | Original message (plaintext) |
| **c** | Encrypted message (ciphertext) |

---

# Key Relationships

```
p × q = n
```

Public Key:

```
(n, e)
```

Private Key:

```
(n, d)
```

Encryption:

```
m → c
```

Decryption:

```
c → m
```

# Summary

- RSA is an **asymmetric encryption algorithm**.
- It uses a **public key** for encryption and a **private key** for decryption.
- RSA security is based on the difficulty of **factoring very large numbers**.
- Multiplying two large prime numbers is easy, but finding those primes from their product is extremely difficult.
- Main RSA variables:
  - **p** = Prime number
  - **q** = Prime number
  - **n = p × q**
  - **e** = Public exponent
  - **d** = Private exponent
  - **m** = Plaintext
  - **c** = Ciphertext
- RSA is widely used for secure communication and appears frequently in **CTF cryptography challenges**.
