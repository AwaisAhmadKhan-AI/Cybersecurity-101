# Types of Encryption

Encryption is divided into **two main types**:

1. **Symmetric Encryption**
2. **Asymmetric Encryption**

---

# Symmetric Encryption

Symmetric encryption uses **the same key** to encrypt and decrypt data.

Because both parties use the same key, it **must remain secret**. This is why it is also called **Private Key Cryptography**.

## How It Works

```
            Shared Secret Key
                  🔑
                  │
Plaintext ──Encrypt──► Ciphertext ──Decrypt──► Plaintext
                  │
            Same Secret Key
```

The same key is used for both encryption and decryption.

---

## Main Challenge

The biggest problem is **securely sharing the secret key**.

### Example

Suppose you create a password-protected document and want to send it to your colleague.

- You can email the encrypted document.
- But you **should not email the password** with it.

If an attacker gains access to the email, they will have:
- The encrypted document
- The password

A safer option is to share the password through another secure channel, such as:
- Phone call
- Secure messaging app
- Meeting in person

---

## Common Symmetric Algorithms

### DES (Data Encryption Standard)

- Adopted in **1977**
- Uses a **56-bit key**
- Became insecure as computers became faster.
- In **1999**, DES was cracked in less than 24 hours.

---

### 3DES (Triple DES)

- Applies DES **three times**.
- Uses a **168-bit key**.
- Effective security is about **112 bits**.
- Deprecated in **2019**.
- Mostly found in **legacy systems**.

---

### AES (Advanced Encryption Standard)

- Adopted in **2001**.
- Current encryption standard.
- Supports key sizes of:
  - 128 bits
  - 192 bits
  - 256 bits

AES is the recommended replacement for DES and 3DES.

---

# Asymmetric Encryption

Asymmetric encryption uses **two different keys**:

- **Public Key** → Used for encryption.
- **Private Key** → Used for decryption.

It is also called **Public Key Cryptography**.

---

## How It Works

```
          Public Key 🔓
               │
Plaintext ──Encrypt──► Ciphertext
                           │
                    Private Key 🔐
                           │
                     Decrypt
                           │
                     Plaintext
```

- The **public key** can be shared with everyone.
- The **private key** must always remain secret.

---

## Key Pair

Every user has:

### Public Key

- Shared publicly.
- Used to encrypt data.

---

### Private Key

- Kept secret.
- Used to decrypt data encrypted with the public key.

Anyone can encrypt data using your public key, but **only you can decrypt it using your private key**.

---

## Common Asymmetric Algorithms

### RSA

Common key sizes:
- 2048 bits (minimum recommended)
- 3072 bits
- 4096 bits

---

### Diffie-Hellman

Used for secure key exchange.

Common key sizes:
- 2048 bits
- 3072 bits
- 4096 bits

---

### ECC (Elliptic Curve Cryptography)

Provides strong security using much smaller keys.

Example:
- **256-bit ECC** provides security similar to a **3072-bit RSA** key.

---

## Why Asymmetric Encryption is Slower

Asymmetric encryption performs more complex mathematical operations than symmetric encryption.

Therefore:
- Larger keys are required.
- Encryption and decryption are slower.

---

## Mathematical Foundation

Asymmetric encryption relies on mathematical problems that are:

- Easy to perform in one direction.
- Extremely difficult to reverse without the private key.

This makes recovering the private key **practically infeasible** using current technology.

---

# Symmetric vs Asymmetric Encryption

| Feature | Symmetric Encryption | Asymmetric Encryption |
|---------|----------------------|-----------------------|
| Keys Used | One shared secret key | Public key + Private key |
| Encryption Key | Secret key | Public key |
| Decryption Key | Same secret key | Private key |
| Key Sharing | Difficult | Easy (public key is shared) |
| Speed | Faster | Slower |
| Also Called | Private Key Cryptography | Public Key Cryptography |

---

# New Terms

## Alice and Bob

Alice and Bob are fictional characters commonly used in cryptography examples.

They represent two people communicating securely.

---

## Public Key

A key that can be shared with anyone.

Used to encrypt data.

---

## Private Key

A secret key known only to its owner.

Used to decrypt data encrypted with the public key.

---

# Summary

- Encryption is divided into **Symmetric** and **Asymmetric** encryption.
- **Symmetric encryption** uses one shared secret key for both encryption and decryption.
- Its biggest challenge is securely sharing the secret key.
- Common symmetric algorithms:
  - DES
  - 3DES
  - AES
- **Asymmetric encryption** uses two keys:
  - Public Key (encrypt)
  - Private Key (decrypt)
- Common asymmetric algorithms:
  - RSA
  - Diffie-Hellman
  - ECC
- Symmetric encryption is **faster**, while asymmetric encryption is **slower but solves the key-sharing problem**.
- The **public key is shared**, while the **private key must always remain secret**.
