# Historical Ciphers

## What are Historical Ciphers?

Historical ciphers are old encryption methods developed to protect messages before modern cryptography existed.

One of the simplest and most famous historical ciphers is the **Caesar Cipher**, created during the **1st century BCE**.

Other famous historical ciphers include:
- **Caesar Cipher** (1st century BCE)
- **Vigenère Cipher** (16th century)
- **Enigma Machine** (World War II)
- **One-Time Pad** (Cold War)

---

# Caesar Cipher

The Caesar Cipher encrypts a message by shifting every letter in the alphabet by a fixed number.

### Example

**Plaintext**
```
TRYHACKME
```

**Key**
```
3
```

**Cipher**
```
Caesar Cipher
```

Each letter is shifted **3 positions to the right**.

| Original | Shift | Result |
|----------|-------|--------|
| T | → | W |
| R | → | U |
| Y | → | B |
| H | → | K |
| A | → | D |
| C | → | F |
| K | → | N |
| M | → | P |
| E | → | H |

**Ciphertext**
```
WUBKDFNPH
```

---

# Encryption

Encryption shifts each letter **to the right** by the key value.

```
Plaintext
TRYHACKME

      + Key (3)

Ciphertext
WUBKDFNPH
```

---

# Decryption

To recover the original message:

- Use the same key.
- Shift each letter **to the left** by the key value.

```
Ciphertext
WUBKDFNPH

      - Key (3)

Plaintext
TRYHACKME
```

---

# Alphabet Wrap-Around

When the shift reaches **Z**, it starts again from **A**.

Example:

```
X → A
Y → B
Z → C
```

This is called **wrapping around the alphabet**.

---

# Why Caesar Cipher is Insecure

The English alphabet has **26 letters**.

- Shifting by **26** returns the same letter.
- Therefore, there are only **25 possible encryption keys**.

An attacker can simply try every possible key until the correct plaintext appears.

This is called a **brute-force attack**.

Example:

```
Ciphertext
↓

Try Key = 1
↓

Try Key = 2
↓

Try Key = 3
↓

...

Try Key = 25
```

Eventually, the original message will be found.

Because there are so few possible keys, the Caesar Cipher is **not secure by modern standards**.

# Other Historical Ciphers

## Vigenère Cipher
- Developed in the **16th century**.
- Uses multiple letter shifts instead of a single fixed shift.

---

## Enigma Machine
- Used during **World War II**.
- An electromechanical encryption machine that produced much stronger encryption than simple substitution ciphers.

---

## One-Time Pad
- Used during the **Cold War**.
- Uses a completely random key.
- When used correctly, it provides extremely strong security.

- Historical ciphers are early encryption techniques.
- The **Caesar Cipher** shifts every letter by a fixed number.
- **Encryption:** Shift letters to the **right**.
- **Decryption:** Shift letters to the **left**.
- After **Z**, the alphabet wraps back to **A**.
- Caesar Cipher has only **25 possible keys**, making it vulnerable to **brute-force attacks**.
