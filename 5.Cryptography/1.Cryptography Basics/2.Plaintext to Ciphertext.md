# Plaintext to Ciphertext

## Basic Encryption Process

Encryption converts readable data (**plaintext**) into unreadable data (**ciphertext**) using a **cipher** and a **key**.

```
                Encryption
Plaintext + Key -----------> Ciphertext
                               |
                               |
                Decryption      |
Ciphertext + Key -------------> Plaintext
```

- **Encryption** changes readable data into unreadable data.
- **Decryption** converts the unreadable data back to its original form.

---

# Key Terms

## Plaintext

The original, readable data before encryption.

Examples:
- Text message
- Document
- Image
- Credit card information
- Medical records

**Example:**
```
Hello World
```

---

## Ciphertext

The encrypted, unreadable version of the plaintext.

- Cannot normally be understood without the correct key.
- Should not reveal any useful information about the original data (except possibly its size).

**Example:**
```
X8@!fL#92$kP
```

---

## Cipher

A mathematical algorithm used to:
- Encrypt plaintext into ciphertext.
- Decrypt ciphertext back into plaintext.

A cipher itself is **not secret**.

**Examples:**
- AES
- DES
- RSA

---

## Key

A sequence of bits used by the cipher during encryption and decryption.

- Determines how data is encrypted.
- Must remain **secret** (except for the public key used in asymmetric encryption).

Without the correct key, recovering the plaintext should be practically impossible.

---

## Encryption

The process of converting **plaintext → ciphertext** using:
- A cipher
- A key

**Formula:**
```
Plaintext + Key + Cipher
        ↓
    Ciphertext
```

---

## Decryption

The process of converting **ciphertext → plaintext** using:
- The same (or corresponding) key
- The same cipher

**Formula:**
```
Ciphertext + Key + Cipher
         ↓
     Plaintext
```

Without the correct key, decryption should be infeasible.

---

# Important Notes

- The **cipher (algorithm)** is usually public knowledge.
- The **key** is what must remain secret (except the public key in asymmetric encryption).
- Security depends on protecting the key, **not** on hiding the encryption algorithm.

---

# Encryption Workflow

```
Original Message
      │
      ▼
 Plaintext
      │
      │ + Key
      ▼
Encryption (Cipher)
      │
      ▼
 Ciphertext
      │
      │ + Correct Key
      ▼
Decryption (Cipher)
      │
      ▼
 Original Plaintext
```

---

# Summary

| Term | Meaning |
|------|---------|
| Plaintext | Original readable data before encryption. |
| Ciphertext | Encrypted unreadable data. |
| Cipher | Algorithm used to encrypt and decrypt data. |
| Key | Secret value used by the cipher during encryption and decryption. |
| Encryption | Process of converting plaintext into ciphertext. |
| Decryption | Process of converting ciphertext back into plaintext. |

---

# Quick Recap

- **Plaintext** → Readable data.
- **Cipher** → Algorithm that performs encryption/decryption.
- **Key** → Secret value used by the cipher.
- **Encryption** → Plaintext ➜ Ciphertext.
- **Decryption** → Ciphertext ➜ Plaintext.
- The **algorithm is public**, but the **key must remain secret**.
