# Piping, Filtering, and Sorting Data (PowerShell)

## What is Piping (`|`)?

**Piping (`|`)** sends the output of one command directly to another command.

Think of it like a pipeline:

```
Command 1 → Output → Command 2 → Output → Command 3
```

### Example

```powershell
Get-ChildItem | Sort-Object Length
```

What happens?

1. `Get-ChildItem` gets all files and folders.
2. `|` sends them to the next command.
3. `Sort-Object Length` sorts them by file size.

---

## Why is PowerShell Piping Powerful?

Unlike CMD, PowerShell passes **objects**, not just text.

Objects contain:
- Properties (Name, Size, Extension, Date, etc.)
- Methods (Actions)

This makes filtering and sorting much easier.

---

# Sort-Object

**Purpose:** Sorts data by a property.

### Syntax

```powershell
Sort-Object PropertyName
```

### Example

```powershell
Get-ChildItem | Sort-Object Length
```

Sorts files from **smallest to largest**.

Another example:

```powershell
Get-ChildItem | Sort-Object Name
```

Sorts files alphabetically.

---

# Where-Object (Filtering)

**Purpose:** Shows only objects that match a condition.

### Example: Show only `.txt` files

```powershell
Get-ChildItem | Where-Object Extension -eq ".txt"
```

Output:

```
notes.txt
report.txt
data.txt
```

---

## Comparison Operators

| Operator | Meaning |
|----------|---------|
| `-eq` | Equal to |
| `-ne` | Not equal to |
| `-gt` | Greater than |
| `-ge` | Greater than or equal to |
| `-lt` | Less than |
| `-le` | Less than or equal to |
| `-like` | Matches a pattern (wildcards) |

### Examples

Equal:

```powershell
Where-Object Length -eq 100
```

Only files exactly **100 bytes**.

---

Not Equal:

```powershell
Where-Object Extension -ne ".txt"
```

Shows everything except `.txt` files.

---

Greater Than:

```powershell
Where-Object Length -gt 500
```

Shows files larger than **500 bytes**.

---

Less Than:

```powershell
Where-Object Length -lt 1000
```

Shows files smaller than **1000 bytes**.

---

Pattern Matching (`-like`)

```powershell
Get-ChildItem | Where-Object Name -like "ship*"
```

Matches:

```
ship.txt
ship-flag.txt
ship-data.doc
```

The `*` means **anything after "ship"**.

---

# Select-Object

**Purpose:** Displays only the properties you want.

### Example

```powershell
Get-ChildItem | Select-Object Name, Length
```

Output:

```
Name          Length
----          ------
notes.txt      120
report.txt     560
```

Only **Name** and **Length** are shown.

---

# Select-String

**Purpose:** Searches for text inside files.

**Equivalent:**
- Linux → `grep`
- CMD → `findstr`

### Example

```powershell
Select-String -Path ".\notes.txt" -Pattern "password"
```

Searches for the word:

```
password
```

If found:

```
notes.txt:15:password=12345
```

It also supports **Regular Expressions (Regex)** for advanced searching.

---

# Combining Multiple Commands

PowerShell lets you chain many commands together.

Example:

```powershell
Get-ChildItem |
Where-Object Extension -eq ".txt" |
Sort-Object Length |
Select-Object Name, Length
```

What happens?

1. Gets all files.
2. Keeps only `.txt` files.
3. Sorts them by size.
4. Shows only Name and Length.

---

# Quick Summary

| Cmdlet | Purpose |
|---------|---------|
| `|` | Pass output to the next command |
| `Sort-Object` | Sort objects |
| `Where-Object` | Filter objects |
| `Select-Object` | Show specific properties |
| `Select-String` | Search text inside files |

- 🔄 `|` → Pass results to the next command.

- 🔍 `Where-Object` → Filter data.
- 📋 `Select-Object` → Show only what you need.
- 🔎 `Select-String` → Find text inside files.
