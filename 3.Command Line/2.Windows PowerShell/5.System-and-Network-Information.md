# System and Network Information

## 1. Get-ComputerInfo
**Purpose:** Displays detailed information about your computer.

### Syntax
```powershell
Get-ComputerInfo
```

### Shows
- Operating System (OS)
- Windows version
- Hardware information
- BIOS details
- Installed Windows edition

### Example
```powershell
Get-ComputerInfo
```

> **Easy to Remember:** Think of it as a **full report card** of your computer.

---

## 2. Get-LocalUser
**Purpose:** Lists all local user accounts on the computer.

### Syntax
```powershell
Get-LocalUser
```

### Shows
- Username
- Account status (Enabled/Disabled)
- Description

### Example
```powershell
Get-LocalUser
```

### Sample Output
```text
Name               Enabled
----               -------
Administrator      True
Guest              False
captain            True
```

### Use Cases
- View all local users.
- Check if an account is enabled.

---

## 3. Get-NetIPConfiguration
**Purpose:** Displays the current network configuration.

### Syntax
```powershell
Get-NetIPConfiguration
```

### Shows
- IP Address
- Default Gateway
- DNS Server
- Network Adapter

### Example
```powershell
Get-NetIPConfiguration
```

### Sample Output
```text
IPv4 Address : 10.10.178.209
Gateway      : 10.10.0.1
DNS Server   : 10.0.0.2
```

> **Easy to Remember:** This is the PowerShell version of **`ipconfig`**, but with more details.

---

## 4. Get-NetIPAddress
**Purpose:** Displays every IP address configured on the computer.

### Syntax
```powershell
Get-NetIPAddress
```

### Shows
- IPv4 addresses
- IPv6 addresses
- Loopback addresses
- Interface information

### Example
```powershell
Get-NetIPAddress
```

### Sample Output
```text
IPAddress         : 10.10.178.209
IPAddress         : 127.0.0.1
IPAddress         : fe80::3fef:360c:304:64e%5
IPAddress         : ::1
```

---

# Difference Between Get-NetIPConfiguration and Get-NetIPAddress

| Get-NetIPConfiguration | Get-NetIPAddress |
|-------------------------|------------------|
| Shows complete network configuration | Shows only IP addresses |
| Includes Gateway | Does not focus on Gateway |
| Includes DNS Server | Does not show DNS by default |
| Easy to read | More detailed |
| Similar to `ipconfig` | More advanced |

---

# Quick Revision

| Cmdlet | Purpose |
|---------|---------|
| `Get-ComputerInfo` | Displays complete computer information. |
| `Get-LocalUser` | Lists all local user accounts. |
| `Get-NetIPConfiguration` | Displays network configuration (IP, Gateway, DNS). |
| `Get-NetIPAddress` | Displays every IP address configured on the computer. |
