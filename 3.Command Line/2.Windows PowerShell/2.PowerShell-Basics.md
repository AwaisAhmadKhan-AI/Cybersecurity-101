# PowerShell Basics

## What is PowerShell?
PowerShell is Microsoft's **command-line tool + scripting language** used to **manage computers and automate tasks**.

Think of it like this:
- **Command Prompt (CMD)** = Basic command-line tool.
- **PowerShell** = CMD on steroids. It can perform much more powerful tasks.

It works on:
- Windows
- Linux
- macOS

---

# Why PowerShell?

PowerShell is mainly used to:

- Automate repetitive tasks.
- Manage files and folders.
- Manage users and permissions.
- Control Windows services and processes.
- Configure networks.
- Administer local or remote computers.
- Write scripts to save time.

Example:
Instead of creating 100 user accounts manually, PowerShell can create all of them with one script.

---

# How is PowerShell Different from CMD?

| CMD | PowerShell |
|------|------------|
| Older command-line tool | Modern command-line tool |
| Works mainly with text | Works with objects |
| Limited features | Much more powerful |
| Basic administration | Advanced administration and automation |

---

# What are Objects?

This is the biggest difference between CMD and PowerShell.

CMD outputs **plain text**.

PowerShell outputs **objects**.

### What is an Object?

An object is something that contains:

- **Properties** → Information about it.
- **Methods** → Actions it can perform.

### Example

Imagine a car.

Properties:
- Color = Red
- Brand = Toyota
- Fuel = 60%

Methods:
- Drive()
- Stop()
- Refuel()

PowerShell works the same way.

Example:
A file object can have:

Properties:
- Name
- Size
- Location
- Creation Date

Methods:
- Copy
- Delete
- Rename

Because PowerShell works with objects instead of text, it can manage data much more easily.

---

# What are Cmdlets?

PowerShell commands are called **Cmdlets** (pronounced *command-lets*).

Most cmdlets follow this format:

```powershell
Verb-Noun
```

Examples:

```powershell
Get-Process
```

Gets running processes.

```powershell
Get-Service
```

Shows Windows services.

```powershell
Get-Help
```

Displays help.

```powershell
Get-ChildItem
```

Lists files and folders (similar to `dir` or `ls`).

# Common Verbs

| Verb | Meaning |
|------|---------|
| Get | Retrieve something |
| Set | Change something |
| New | Create something |
| Remove | Delete something |
| Start | Start something |
| Stop | Stop something |

- Control remote computers
- Automate almost anything

---

# Quick Summary

- PowerShell is Microsoft's advanced command-line tool and scripting language.
- It is used for **automation** and **system administration**.
- Unlike CMD, it works with **objects**, not plain text.
- Objects contain **properties** (information) and **methods** (actions).
- PowerShell commands are called **cmdlets**.
- Cmdlets usually follow the **Verb-Noun** format (e.g., `Get-Process`).
- PowerShell is more powerful and flexible than Command Prompt.
