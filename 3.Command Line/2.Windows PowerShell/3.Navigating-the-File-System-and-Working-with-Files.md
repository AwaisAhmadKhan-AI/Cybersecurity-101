# Navigating the File System and Working with Files (PowerShell)

## 1. Get-ChildItem (List Files & Folders)

**Purpose:** Displays files and folders in a directory.

**Equivalent:**
- PowerShell → `Get-ChildItem`
- CMD → `dir`
- Linux → `ls`

### Syntax
```powershell
Get-ChildItem
```

### Example
```powershell
Get-ChildItem
```

**Output:** Lists all files and folders in the current directory.

You can also specify another directory:

```powershell
Get-ChildItem -Path "C:\Users"
```

---

## 2. Set-Location (Change Directory)

**Purpose:** Moves to another folder.

**Equivalent:**
- PowerShell → `Set-Location`
- CMD → `cd`

### Syntax
```powershell
Set-Location -Path "FolderName"
```

### Example
```powershell
Set-Location -Path ".\Documents"
```

Moves into the **Documents** folder.

**Note:**
- `.` = Current folder
- `..` = Parent folder (one level up)

Example:

```powershell
Set-Location ..
```

Moves back one directory.

---

## 3. New-Item (Create Files or Folders)

**Purpose:** Creates a new file or directory.

Unlike CMD, PowerShell uses **one command** for both files and folders.

### Create a Folder

```powershell
New-Item -Path ".\MyFolder" -ItemType Directory
```

Creates:

```
MyFolder/
```

---

### Create a File

```powershell
New-Item -Path ".\notes.txt" -ItemType File
```

Creates:

```
notes.txt
```

---

## 4. Remove-Item (Delete Files or Folders)

**Purpose:** Deletes files or folders.

**Equivalent:**
- PowerShell → `Remove-Item`
- CMD → `del` / `rmdir`

### Delete a File

```powershell
Remove-Item -Path ".\notes.txt"
```

---

### Delete a Folder

```powershell
Remove-Item -Path ".\MyFolder"
```

---

## 5. Copy-Item (Copy Files or Folders)

**Purpose:** Makes a copy of a file or folder.

**Equivalent:**
- PowerShell → `Copy-Item`
- CMD → `copy`

### Syntax

```powershell
Copy-Item -Path Source -Destination Destination
```

### Example

```powershell
Copy-Item -Path ".\notes.txt" -Destination ".\notes-copy.txt"
```

Result:

```
notes.txt
notes-copy.txt
```

Both files exist.

---

## 6. Move-Item (Move or Rename Files/Folders)

**Purpose:**
- Move a file/folder to another location.
- Rename a file/folder.

**Equivalent:**
- PowerShell → `Move-Item`
- CMD → `move`

### Move Example

```powershell
Move-Item -Path ".\notes.txt" -Destination ".\Backup\"
```

Moves the file into the **Backup** folder.

---

### Rename Example

```powershell
Move-Item -Path ".\notes.txt" -Destination ".\important-notes.txt"
```

Renames:

```
notes.txt
```

to

```
important-notes.txt
```

---

## 7. Get-Content (Read File Contents)

**Purpose:** Displays the contents of a text file.

**Equivalent:**
- PowerShell → `Get-Content`
- CMD → `type`
- Linux → `cat`

### Syntax

```powershell
Get-Content -Path ".\notes.txt"
```

### Example Output

```
Hello World!
Welcome to PowerShell.
```

---

# Quick Summary

| Cmdlet | Purpose | Similar CMD Command |
|---------|---------|---------------------|
| `Get-ChildItem` | List files & folders | `dir` |
| `Set-Location` | Change directory | `cd` |
| `New-Item` | Create file/folder | `mkdir`, `type nul > file` |
| `Remove-Item` | Delete file/folder | `del`, `rmdir` |
| `Copy-Item` | Copy file/folder | `copy` |
| `Move-Item` | Move or rename | `move` |
| `Get-Content` | View file contents | `type` |
