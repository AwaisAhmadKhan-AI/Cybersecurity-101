# What is PowerShell?

## What is PowerShell?

PowerShell is a **command-line tool and scripting language** developed by Microsoft for **automating tasks** and **managing computers**.

Unlike Command Prompt (`cmd`), PowerShell works with **objects** instead of plain text, making it much more powerful.

It can run on:
- Windows
- Linux
- macOS

---

# Why was PowerShell Created?

Older tools like **Command Prompt (cmd.exe)** and **batch files** were good for simple tasks but struggled with:

- Complex automation
- Managing large enterprise systems
- Interacting with modern Windows features

Microsoft created **PowerShell** to solve these problems.

It was first released in **2006**.

In **2016**, Microsoft released **PowerShell Core**, making it **open-source** and **cross-platform** (Windows, Linux, and macOS).

---

# Objects in PowerShell

The biggest difference between **Command Prompt** and **PowerShell** is how they handle data.

## Command Prompt

Works with **plain text**.

Example output:

```text
File1.txt
```

To use this output, you often have to manually process the text.

---

## PowerShell

Works with **objects**.

An object contains both:
- **Properties** → Information about something.
- **Methods** → Actions that can be performed.

### Example: Car Object

Properties:
- Color
- Model
- FuelLevel

Methods:
- Drive()
- HonkHorn()
- Refuel()

The same idea applies in PowerShell.

Example: A file object may have

Properties:
- Name
- Size
- Creation Date

Methods:
- Copy
- Move
- Delete

This makes working with files, users, and processes much easier.

---

# What is a Cmdlet?

A **cmdlet (command-let)** is a built-in PowerShell command.

Unlike normal CMD commands, **cmdlets return objects**, not plain text.

This allows PowerShell to easily pass rich information from one command to another.

---

# Why is PowerShell Powerful?

Because it:

- Automates repetitive tasks.
- Manages Windows systems efficiently.
- Works with objects instead of plain text.
- Can interact deeply with Windows and .NET.
- Also works on Linux and macOS.

---

# Command Prompt vs PowerShell

| Command Prompt (CMD) | PowerShell |
|-----------------------|------------|
| Text-based | Object-based |
| Good for simple tasks | Good for simple and complex tasks |
| Limited scripting | Powerful scripting language |
| Windows only | Windows, Linux, macOS |
| Harder to automate complex tasks | Easy to automate complex tasks |

---

# Key Points

- **PowerShell** is Microsoft's powerful command-line and scripting tool.
- It was created to overcome the limitations of **Command Prompt**.
- Released in **2006**.
- Became **cross-platform** in **2016** with PowerShell Core.
- PowerShell works with **objects**, not plain text.
- Objects contain **properties (information)** and **methods (actions)**.
- **Cmdlets** are PowerShell commands that return objects.
- PowerShell is widely used for **system administration, automation, and configuration management**.
