# PowerShell Scripting

## What is Scripting?
**Scripting** is the process of writing multiple commands in a text file (called a **script**) so the computer can execute them automatically.

Instead of typing commands one by one, you write them once in a script and run the script whenever needed.

> **Easy to Remember:** A script is simply a **to-do list for the computer**.

---

## Why Use Scripting?

### Benefits
- ⏱️ Saves time
- 🤖 Automates repetitive tasks
- ❌ Reduces human errors
- 📋 Handles complex tasks easily
- 🚀 Makes administration much faster

# Invoke-Command

## Purpose
`Invoke-Command` runs commands or PowerShell scripts on **local or remote computers**.

### Syntax
```powershell
Invoke-Command
```

> **Easy to Remember:** It tells another computer, **"Run this command for me."**

---

## Example 1: Run a Script on a Remote Computer

```powershell
Invoke-Command -FilePath C:\Scripts\Test.ps1 -ComputerName Server01
```

### What happens?
- Takes the local script (`Test.ps1`)
- Sends it to **Server01**
- Runs it there
- Returns the results

---

## Example 2: Run a Command on a Remote Computer

```powershell
Invoke-Command -ComputerName Server01 -Credential Domain01\User01 -ScriptBlock { Get-Culture }
```

### What happens?
- Connects to **Server01**
- Logs in using the specified user
- Executes:

```powershell
Get-Culture
```

- Displays the result on your computer

---

## What is `-ScriptBlock`?

A **ScriptBlock** is simply one or more PowerShell commands enclosed in `{ }`.

### Example

```powershell
-ScriptBlock { Get-Process }
```

or

```powershell
-ScriptBlock {
    Get-Service
    Get-Process
}
```

Everything inside `{ }` runs on the remote computer.

---

# Why is Invoke-Command Powerful?

It allows you to:

- Manage computers remotely
- Run scripts on many computers
- Automate administration
- Save time
- Perform remote troubleshooting

# Quick Revision

| Term / Cmdlet | Purpose |
|---------------|---------|
| **Script** | A file containing multiple PowerShell commands. |
| **Scripting** | Automating tasks by running commands from a script. |
| **Invoke-Command** | Executes commands or scripts on local or remote computers. |
| **-FilePath** | Specifies the script file to run. |
| **-ComputerName** | Specifies the target computer. |
| **-Credential** | Specifies the user account used for authentication. |
| **-ScriptBlock** | Contains the command(s) to execute remotely. |
