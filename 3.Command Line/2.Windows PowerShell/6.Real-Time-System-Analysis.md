# Real-Time System Analysis

## 1. Get-Process
**Purpose:** Displays all currently running processes (programs).

### Syntax
```powershell
Get-Process
```

### Shows
- Running processes
- Process ID (PID)
- CPU usage
- Memory usage

### Example
```powershell
Get-Process
```

### Use Cases
- Check what programs are currently running.
- Monitor CPU and memory usage.
- Troubleshoot high resource usage.

> **Easy to Remember:** Similar to **Task Manager**, but in PowerShell.

---

## 2. Get-Service
**Purpose:** Displays all Windows services and their status.

### Syntax
```powershell
Get-Service
```

### Shows
- Service name
- Display name
- Status (Running, Stopped, Paused)

### Example
```powershell
Get-Service
```

### Sample Output
```text
Status    Name
------    ----
Running   BFE
Running   AmazonSSMAgent
Stopped   AppIDSvc
```

### Use Cases
- Check whether a service is running.
- Troubleshoot Windows services.
- Detect suspicious or unexpected services.

> **Easy to Remember:** Services are background programs that run without you opening them.

---

## 3. Get-NetTCPConnection
**Purpose:** Displays all active TCP network connections.

### Syntax
```powershell
Get-NetTCPConnection
```

### Shows
- Local IP address
- Local port
- Remote IP address
- Remote port
- Connection state
- Process ID (PID)

### Example
```powershell
Get-NetTCPConnection
```

### Common Connection States
- **Listen** → Waiting for incoming connections.
- **Established** → Active connection.
- **TimeWait** → Recently closed connection.

### Use Cases
- View active network connections.
- Detect suspicious remote connections.
- Incident response and malware analysis.

> **Easy to Remember:** Similar to **netstat**, but more powerful.

---

## 4. Get-FileHash
**Purpose:** Generates a cryptographic hash of a file.

### Syntax
```powershell
Get-FileHash -Path <file>
```

### Example
```powershell
Get-FileHash -Path .\ship-flag.txt
```

### Output
- Hash Algorithm (SHA256 by default)
- Hash Value
- File Path

### Why is it Useful?
- Verify file integrity.
- Detect file modifications.
- Compare files.
- Malware analysis.

> **Easy to Remember:** A file hash acts like a **digital fingerprint**. If the file changes even slightly, the hash changes completely.

## 5. Get-Item -Stream *
**Purpose:** Displays all data streams attached to a file, including **Alternate Data Streams (ADS)**.

### Syntax
```powershell
Get-Item -Path "<file>" -Stream *
```

### Example
```powershell
Get-Item -Path "C:\House\house_log.txt" -Stream *
```

### Shows
- Normal file stream (`:$DATA`)
- Alternate Data Streams (ADS)

### Understanding the Output

#### `:$DATA`
- Default stream.
- Contains the normal file contents.
- Every NTFS file has this.

#### `housinginfo`
- An Alternate Data Stream (ADS).
- Hidden extra data attached to the file.
- Does not appear when viewing the file normally.

### Why is ADS Important?
Attackers can hide:
- Malware
- Scripts
- Secret data

inside ADS because it is hidden from normal file browsing.

> **Easy to Remember:** ADS is like a **hidden pocket** attached to a file.
