# The Locker Script

## Objective

Create a Bash script that asks the user for:

1. Username
2. Company Name
3. PIN

The user is granted access **only if** all the following are correct:

- **Username:** `John`
- **Company Name:** `Tryhackme`
- **PIN:** `7385`

Otherwise, access is denied.

---

# Complete Script

```bash
#!/bin/bash

# Variables
username=""
companyname=""
pin=""

# Ask for user information
for i in {1..3}; do

    if [ "$i" -eq 1 ]; then
        echo "Enter your Username:"
        read username

    elif [ "$i" -eq 2 ]; then
        echo "Enter your Company name:"
        read companyname

    else
        echo "Enter your PIN:"
        read pin
    fi

done

# Verify the entered information
if [ "$username" = "John" ] && \
   [ "$companyname" = "Tryhackme" ] && \
   [ "$pin" = "7385" ]; then

    echo "Authentication Successful. You can now access your locker, John."

else

    echo "Authentication Denied!!"

fi
```

---

# Step-by-Step Explanation

## 1. Shebang

```bash
#!/bin/bash
```

- `#!` → Shebang
- `/bin/bash` → Use the **Bash interpreter** to run this script.

---

## 2. Variables

```bash
username=""
companyname=""
pin=""
```

Creates three empty variables that will later store:

- Username
- Company name
- PIN

---

## 3. Loop

```bash
for i in {1..3}; do
```

Runs the loop **3 times**.

The variable `i` changes like this:

| Iteration | Value of `i` |
|-----------|--------------|
| 1st | 1 |
| 2nd | 2 |
| 3rd | 3 |

---

## 4. First Condition

```bash
if [ "$i" -eq 1 ]; then
```

Checks whether `i` equals **1**.

If true:

```bash
echo "Enter your Username:"
read username
```

- Displays a message.
- Stores the user's input in the `username` variable.

---

## 5. Second Condition

```bash
elif [ "$i" -eq 2 ]; then
```

Checks whether `i` equals **2**.

If true:

```bash
echo "Enter your Company name:"
read companyname
```

Stores the company name.

---

## 6. Else Block

When `i` is **3**, the previous conditions are false.

```bash
else
```

Runs:

```bash
echo "Enter your PIN:"
read pin
```

Stores the PIN.

---

## 7. End of Loop

```bash
done
```

Ends the `for` loop.

At this point:

- `username` contains the entered username.
- `companyname` contains the entered company name.
- `pin` contains the entered PIN.

---

## 8. Authentication Check

```bash
if [ "$username" = "John" ] &&
   [ "$companyname" = "Tryhackme" ] &&
   [ "$pin" = "7385" ]; then
```

Checks **all three conditions**.

The `&&` operator means **AND**.

This means:

- Username must be **John**
- **AND** company must be **Tryhackme**
- **AND** PIN must be **7385**

If **all three** are correct:

```bash
echo "Authentication Successful. You can now access your locker, John."
```

Otherwise:

```bash
echo "Authentication Denied!!"
```

# Commands & Keywords Summary

| Command/Keyword | Purpose |
|-----------------|---------|
| `#!/bin/bash` | Specifies Bash as the interpreter |
| `echo` | Displays text |
| `read` | Takes user input |
| `variable=""` | Creates a variable |
| `$variable` | Accesses the variable's value |
| `for` | Starts a loop |
| `do` | Begins the loop body |
| `done` | Ends the loop |
| `if` | Starts a conditional statement |
| `elif` | Else-if condition |
| `else` | Executes if previous conditions are false |
| `fi` | Ends the conditional statement |
| `=` | Compares strings |
| `-eq` | Compares numbers |
| `&&` | Logical AND (all conditions must be true) |
| `#` | Comment |

---

# Key Points for Exams

- A **Bash script** starts with `#!/bin/bash`.
- Variables store user input using `read`.
- A `for` loop repeats commands.
- `if`, `elif`, `else`, and `fi` control decision-making.
- `=` compares **strings**.
- `-eq` compares **numbers**.
- `&&` means **all conditions must be true**.
- The script grants access only when **Username = John**, **Company = Tryhackme**, and **PIN = 7385**.
