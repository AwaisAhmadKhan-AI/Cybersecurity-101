# Types of Linux Shells

Linux has different types of **shells**, just like Windows has **Command Prompt** and **PowerShell**. Each shell has its own features and is designed for different types of users.

---

# Check Your Current Shell

To see which shell you are currently using:

```bash
echo $SHELL
```

### Example Output

```bash
/bin/bash
```

**Meaning:**
- You are currently using the **Bash** shell.

---

# View All Installed Shells

Linux stores all available shells in the file:

```text
/etc/shells
```

To display them:

```bash
cat /etc/shells
```

### Example Output

```text
# /etc/shells: valid login shells
/bin/sh
/bin/bash
/usr/bin/bash
/bin/rbash
/usr/bin/rbash
/bin/dash
/usr/bin/dash
/usr/bin/tmux
/usr/bin/screen
/bin/zsh
/usr/bin/zsh
```

**Meaning:**
- Every shell listed here is installed and can be used on your system.

---

# Switch to Another Shell

If a shell is installed, simply type its name.

### Example

```bash
zsh
```

### Output

```bash
tryhackme%
```

Now your terminal is using **Zsh** instead of Bash.

> **Note:** This change is temporary. When you close the terminal, it returns to your default shell.

---

# Change the Default Shell Permanently

To make **Zsh** your default shell:

```bash
chsh -s /usr/bin/zsh
```

The next time you open the terminal, Zsh will start automatically.

# Common Linux Shells

## 1. Bash (Bourne Again Shell)

Bash is the **default shell** on most Linux distributions.

It replaced older shells like **sh**, **ksh**, and **csh**, combining many of their features while adding new ones.

### Features

- Default shell on most Linux systems.
- Supports shell scripting.
- Supports tab completion.
- Saves command history.
- Large community and documentation.
- Very stable and widely used.

### Example

Type:

```bash
cd Doc
```

Press **Tab**

It automatically becomes:

```bash
cd Documents
```

### Command History

Press:

- ↑ (Up Arrow) → Previous command
- ↓ (Down Arrow) → Next command

Or view all previous commands:

```bash
history
```

---

## 2. Fish (Friendly Interactive Shell)

Fish is designed to be easy and beginner-friendly.

It focuses on usability rather than compatibility.

### Features

- Very easy syntax.
- Auto spell correction.
- Syntax highlighting.
- Smart command suggestions.
- Beautiful customizable prompts/themes.
- Supports tab completion.
- Keeps command history.
- Supports scripting (less powerful than Bash/Zsh).

### Best For

- Beginners
- Users who like colorful terminals
- Users who want intelligent command suggestions

---

## 3. Zsh (Z Shell)

Zsh is a modern shell that combines the best features of Bash and other shells.

It is highly customizable and popular among developers and cybersecurity professionals.

### Features

- Excellent scripting support.
- Advanced tab completion.
- Auto spell correction.
- Command history.
- Supports plugins.
- Highly customizable.
- Works with **Oh My Zsh** for themes and plugins.

### Drawback

- Heavy customization may make it slightly slower.

---

# Comparison of Bash, Fish, and Zsh

| Feature | Bash | Fish | Zsh |
|----------|------|------|------|
| **Full Name** | Bourne Again Shell | Friendly Interactive Shell | Z Shell |
| **Installed by Default** | ✅ Usually Yes | ❌ Usually No | ❌ Usually No |
| **Scripting** | Excellent | Basic | Excellent |
| **Tab Completion** | Basic | Advanced | Very Advanced (plugins available) |
| **Auto Spell Correction** | ❌ No | ✅ Yes | ✅ Yes |
| **Customization** | Basic | Good | Excellent |
| **Syntax Highlighting** | ❌ No | ✅ Built-in | ✅ With plugins |
| **Command History** | ✅ Yes | ✅ Yes | ✅ Yes |
| **User Friendliness** | Medium | ⭐ Best | Very Good |

# Which Shell Should You Choose?

### Choose Bash if:
- You want maximum compatibility.
- You are learning Linux.
- You write scripts for different systems.

### Choose Fish if:
- You are a beginner.
- You want an easy and colorful terminal.
- You like smart suggestions and auto-correction.

### Choose Zsh if:
- You want lots of customization.
- You are a developer or cybersecurity professional.
- You want plugins like **Oh My Zsh**.

# Quick Command Summary

| Command | Purpose |
|----------|---------|
| `echo $SHELL` | Show current shell |
| `cat /etc/shells` | List installed shells |
| `zsh` | Switch to Zsh temporarily |
| `bash` | Switch back to Bash |
| `fish` | Switch to Fish (if installed) |
| `chsh -s /usr/bin/zsh` | Change default shell |

---

# Exam Tips ⭐

- A **shell** lets you interact with Linux using commands.
- `echo $SHELL` shows your current shell.
- `/etc/shells` contains all installed login shells.
- `cat /etc/shells` lists all installed shells.
- Typing a shell name (e.g., `zsh`) switches to it temporarily.
- `chsh -s /usr/bin/zsh` changes your default shell permanently.
- **Bash** is the default and most widely used shell.
- **Fish** is the most beginner-friendly shell.
- **Zsh** is the most customizable shell and supports powerful plugins like **Oh My Zsh**.
