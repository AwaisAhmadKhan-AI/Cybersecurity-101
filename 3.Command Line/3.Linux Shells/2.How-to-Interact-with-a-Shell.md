# How to Interact with the Linux Shell

## What is the Shell Prompt?

When you open a terminal, you will see something like:

```bash
user@tryhackme:~$
```

This is called the **shell prompt**.

It means the shell is ready to accept your commands.

---

## Default Shell

Most Linux distributions use **Bash (Bourne Again Shell)** as the default shell.

> **Note:** The shell you see may vary depending on your Linux distribution.

---

# Common Linux Shell Commands

## 1. pwd (Print Working Directory)

**Purpose:** Displays your current directory (location).

### Syntax

```bash
pwd
```

### Example

```bash
user@tryhackme:~$ pwd
/home/user
```

### Output

```text
/home/user
```

> **Easy to Remember:** `pwd` answers the question: **"Where am I?"**

---

## 2. cd (Change Directory)

**Purpose:** Moves from one directory (folder) to another.

### Syntax

```bash
cd <directory_name>
```

### Example

```bash
cd Desktop
```

### Result

```text
Current Directory:
/home/user/Desktop
```

> **Easy to Remember:** `cd` means **Change Directory**.

---

## 3. ls (List)

**Purpose:** Displays the contents of the current directory.

### Syntax

```bash
ls
```

### Example

```bash
ls
```

### Output

```text
Desktop
Documents
Downloads
Music
Pictures
Videos
```

> **Easy to Remember:** `ls` = **List files and folders**.

---

## 4. cat

**Purpose:** Displays the contents of a text file.

### Syntax

```bash
cat filename.txt
```

### Example

```bash
cat notes.txt
```

### Output

```text
This is a sample file.
This is the second line.
```

> **Easy to Remember:** `cat` lets you **read a file**.

---

## 5. grep

**Purpose:** Searches for a specific word or pattern inside a file.

### Syntax

```bash
grep <word> <filename>
```

### Example

```bash
grep THM dictionary.txt
```

### Output

```text
The flag is THM
```

### Why Use `grep`?

It helps you:
- Find specific words
- Search large files quickly
- Filter useful information

> **Easy to Remember:** `grep` = **Search inside a file**.

---

# Quick Revision

| Command | Full Form | Purpose |
|---------|-----------|---------|
| `pwd` | Print Working Directory | Shows your current location. |
| `cd` | Change Directory | Moves to another folder. |
| `ls` | List | Displays files and folders. |
| `cat` | Concatenate | Displays the contents of a file. |
| `grep` | Global Regular Expression Print | Searches for words or patterns in a file. |
