# Introduction to Linux Shells

## What is a Linux Shell?

A **shell** is a program that lets you interact with the Linux operating system by typing commands.

It acts as a **bridge (or middleman)** between **you** and the **operating system (OS)**.

> **Easy to Remember:** The shell takes your commands and tells the operating system what to do.

---

# GUI vs CLI

## GUI (Graphical User Interface)

GUI lets you interact with the computer by using:
- Mouse
- Buttons
- Icons
- Menus

### Example
To create a folder:
- Right-click
- Click **New**
- Click **Folder**

---

## CLI (Command Line Interface)

CLI lets you interact with the computer by typing commands.

### Example
```bash
mkdir MyFolder
```

This creates the same folder, but using a command.

---

# Why Use the CLI?

Compared to the GUI, the CLI is:

- ⚡ Faster
- 💻 Uses fewer system resources
- 🤖 Easier to automate tasks
- 🎯 Gives more control over the system
- 🛠️ Preferred by system administrators and cybersecurity professionals

---

# Restaurant Analogy

Imagine you're in a restaurant.

### Using the GUI
- You order food from the menu.
- The waiter brings it to you.
- Easy, but you have limited control.

### Using the CLI
- You go into the kitchen.
- You cook the food yourself.
- You have complete control over every step.

### Where does the Shell fit?

The **shell** is like a **recipe book or cooking assistant**.

It tells you **how to prepare the food (perform tasks)** and sends your instructions to the kitchen (Operating System).

---

# Why Do Hackers Use the Terminal?

In movies, hackers often use terminals because:

- It is faster than using the GUI.
- Many cybersecurity tools run in the terminal.
- It allows automation through scripts.
- It gives full control over the operating system.

> **Note:** Real cybersecurity professionals also use terminals extensively for these reasons.
