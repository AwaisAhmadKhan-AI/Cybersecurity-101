# Task and Process Management (Windows CMD)

## What is a Process?

A **process** is simply a **program that is currently running**.

Examples:
- Chrome
- Notepad
- File Explorer
- Command Prompt

Every running process has a unique **PID (Process ID)** that Windows uses to identify it.

---

# `tasklist`

Displays all currently running processes.

**Syntax**
```cmd
tasklist
```

Example:
```cmd
tasklist
```

Output shows:
- Process name
- PID (Process ID)
- Session
- Memory usage

Example:

```
Image Name      PID
------------   -----
chrome.exe     4321
notepad.exe    2180
explorer.exe   1556
```

---

# Filtering Processes

Since `tasklist` can display many processes, you can filter the results.

## `tasklist /FI`

`/FI` stands for **Filter**.

**Syntax**
```cmd
tasklist /FI "imagename eq process_name"
```

Example:
```cmd
tasklist /FI "imagename eq sshd.exe"
```

Output:

```
Image Name      PID
------------   -----
sshd.exe       2116
sshd.exe       2712
```

This shows **only** the `sshd.exe` processes.

---

# `tasklist /?`

Displays the help page for the `tasklist` command.

**Syntax**
```cmd
tasklist /?
```

Use it to see:
- Available filters
- Command options
- Usage examples

---

# `taskkill`

Stops (kills) a running process.

**Syntax**
```cmd
taskkill /PID PID_Number
```

Example:
```cmd
taskkill /PID 4567
```

This stops the process whose PID is **4567**.

---

# Why use PID?

Sometimes multiple processes have the same name.

Example:

```
chrome.exe   PID 3200
chrome.exe   PID 5400
chrome.exe   PID 8712
```

Instead of killing all Chrome processes, you can stop only the one you want by using its PID.

---

# Quick Command Summary

| Command | Purpose |
|----------|---------|
| `tasklist` | Show all running processes |
| `tasklist /FI "imagename eq name.exe"` | Show only a specific process |
| `tasklist /?` | Display help for `tasklist` |
| `taskkill /PID PID` | Stop a process using its PID |

---

# Key Points

- A **process** is a running program.
- Every process has a unique **PID (Process ID)**.
- **`tasklist`** shows all running processes.
- **`/FI`** filters the results.
- **`taskkill /PID`** stops a process using its PID.
- Use **`tasklist /?`** to view all available options.
