# Windows Command Prompt (CMD) - Introduction

## What is CMD?

**Command Prompt (CMD)** is the default **Command-Line Interface (CLI)** in Windows.

Instead of clicking buttons (GUI), you type commands to perform tasks.

---

# GUI vs CLI

| GUI | CLI |
|------|-----|
| Uses windows, icons, and mouse | Uses text commands |
| Easy for beginners | Faster after practice |
| More resource usage | Less resource usage |
| Harder to automate | Easy to automate with scripts |

---

# Advantages of CLI

### 🚀 Faster

- Perform tasks quickly by typing commands.
- No need to navigate through multiple windows.

### 💻 Uses Fewer Resources

- Consumes less RAM and CPU than a graphical interface.
- Works well on older or low-powered systems.

### 🤖 Easy Automation

- Commands can be saved into scripts or batch files.
- Repetitive tasks can be automated.

### 🌐 Remote Management

- Easily manage remote systems using **SSH**.
- Useful for servers, routers, and IoT devices.
