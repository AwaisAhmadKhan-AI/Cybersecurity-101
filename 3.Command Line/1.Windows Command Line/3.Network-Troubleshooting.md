# Network Troubleshooting (Windows CMD)

## Overview

Windows CMD provides several networking commands to:

- View network configuration.
- Test internet or network connectivity.
- Troubleshoot network issues.
- Check DNS information.
- View active network connections and listening ports.

---

# 1. `ipconfig` – View Network Configuration

Displays basic network information.

```cmd
ipconfig
```

### Shows:

- IPv4 Address
- IPv6 Address
- Subnet Mask
- Default Gateway

### Example

```text
IPv4 Address : 10.10.230.237
Subnet Mask  : 255.255.0.0
Default Gateway : 10.10.0.1
```

---

# 2. `ipconfig /all` – Detailed Network Information

Displays complete network configuration.

```cmd
ipconfig /all
```

### Shows:

- Network adapter description
- MAC (Physical) Address
- IPv4 & IPv6 addresses
- DHCP status
- DNS servers
- Default gateway
- Lease obtained & expiry times
- NetBIOS status

### Why use it?

Useful when troubleshooting DHCP, DNS, or adapter-related problems.

---

# 3. `ping` – Test Network Connectivity

Checks whether another device or website is reachable.

```cmd
ping target
```

### Example

```cmd
ping example.com
```

### How it works

- Sends **ICMP Echo Request** packets.
- Waits for **ICMP Echo Reply** packets.
- If replies are received, the target is reachable.

### Output includes

- Packets sent
- Packets received
- Packet loss
- Response time (latency)

Example:

```text
Packets: Sent = 4
Received = 4
Lost = 0
Average = 78ms
```

### Uses

- Check internet connectivity.
- Verify a server is online.
- Measure network delay.

---

# 4. `tracert` – Trace the Network Route

Shows every router (hop) between your computer and the destination.

```cmd
tracert target
```

### Example

```cmd
tracert example.com
```

### What it does

- Displays each router the packet passes through.
- Uses the **TTL (Time To Live)** value.
- Helps identify where a network problem occurs.

Example:

```text
Hop 1
Hop 2
Hop 3
...
Hop 16
Destination reached
```

### Uses

- Diagnose slow networks.
- Find where packets stop.
- Troubleshoot routing issues.

---

# 5. `nslookup` – DNS Lookup

Converts a domain name into its IP address.

### Default DNS server

```cmd
nslookup example.com
```

### Use a specific DNS server

```cmd
nslookup example.com 1.1.1.1
```

### Shows

- DNS server used
- Domain name
- IPv4/IPv6 address

### Uses

- Verify DNS is working.
- Troubleshoot DNS problems.
- Check if different DNS servers return the same IP.

---

# 6. `netstat` – View Network Connections

Displays current network connections.

```cmd
netstat
```

### Shows

- Protocol (TCP/UDP)
- Local address
- Remote address
- Connection state

Example:

```text
TCP
10.10.230.237:22
ESTABLISHED
```

This indicates an active SSH connection on **port 22**.

---

# 7. `netstat -abon` – Detailed Connection Information

```cmd
netstat -abon
```

### Options

| Option | Meaning |
|---------|----------|
| `-a` | Show all connections and listening ports |
| `-b` | Show the program using each connection |
| `-o` | Show Process ID (PID) |
| `-n` | Display IP addresses and port numbers numerically |

### Example

```text
TCP 0.0.0.0:22 LISTENING 2116
[sshd.exe]
```

This tells us:

- Port **22** is listening.
- Program: **sshd.exe**
- PID: **2116**

---

# Common Networking Commands

| Command | Purpose |
|---------|---------|
| `ipconfig` | Show basic network configuration |
| `ipconfig /all` | Show complete network details |
| `ping <host>` | Test connectivity to another host |
| `tracert <host>` | Show the route packets take |
| `nslookup <domain>` | Find a domain's IP address |
| `netstat` | View active network connections |
| `netstat -abon` | View ports, processes, PIDs, and connections |

---

# Key Points

- **`ipconfig`** shows your IP configuration.
- **`ipconfig /all`** provides detailed adapter information.
- **`ping`** checks whether a host is reachable and measures latency.
- **`tracert`** displays every hop between you and the destination.
- **`nslookup`** converts domain names into IP addresses using DNS.
- **`netstat`** displays active network connections.
- **`netstat -abon`** helps identify which program and process is using a specific network port.
