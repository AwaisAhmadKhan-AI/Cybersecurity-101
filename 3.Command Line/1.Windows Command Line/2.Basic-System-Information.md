# Windows CMD - Basic System Information

## Windows PATH

Windows can only run commands that are located in its **PATH**.

To view the PATH and other environment variables, use:

```cmd
set
```

Example output:

```text
Path=C:\Windows\system32;C:\Windows;...
```

**Note:** The line starting with `Path=` shows the directories where Windows searches for commands.

---

# Check Windows Version

Use the following command to see the Windows version:

```cmd
ver
```

Example:

```text
Microsoft Windows [Version 10.0.17763.1821]
```

---

# View Detailed System Information

To display detailed information about your computer, use:

```cmd
systeminfo
```

This shows information such as:

- Host name
- Operating System (OS)
- Windows version
- OS manufacturer
- System configuration
- Processor details
- Memory (RAM)
- Much more

Example:

```text
Host Name: WIN-SRV-2019
OS Name: Microsoft Windows Server 2019 Datacenter
OS Version: 10.0.17763
```

---

# Display Long Output Page by Page

Some commands produce a lot of output.

You can use the **pipe (`|`)** with **more** to read one page at a time.

Example:

```cmd
driverquery | more
```

Without `more`:

```cmd
driverquery
```

The output scrolls quickly.

With `more`:

```cmd
driverquery | more
```

- Press **Space** → Next page
- Press **Ctrl + C** → Exit

# Useful CMD Commands

## `help`

Shows help information for commands.

```cmd
help
```

You can also get help for a specific command:

```cmd
help systeminfo
```

---

## `cls`

Clears the Command Prompt screen.

```cmd
cls
```

---

# Key Points

- `set` → Displays environment variables, including the **PATH**.
- `ver` → Shows the Windows version.
- `systeminfo` → Displays detailed system information.
- `| more` → Shows long output one page at a time.
- `help` → Displays command help.
- `cls` → Clears the CMD screen.
