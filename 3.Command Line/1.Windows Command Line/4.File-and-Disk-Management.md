# File and Disk Management (Windows CMD)

## 1. Working with Directories (Folders)

Directories = Folders.

### `cd` (Change Directory)
- Shows your current directory if used without arguments.
- Used to move between folders.

**Syntax:**
```cmd
cd
cd folder_name
cd ..
```

**Examples:**
```cmd
cd Users
```
➡️ Move into the **Users** folder.

```cmd
cd ..
```
➡️ Go back **one folder**.

---

### `dir`
Lists files and folders inside the current directory.

**Syntax:**
```cmd
dir
```

Example:
```cmd
dir
```

Shows:
- Files
- Folders
- Free disk space

#### Useful Options

```cmd
dir /a
```
Shows **hidden + system files**.

```cmd
dir /s
```
Shows files in:
- Current folder
- All subfolders

---

### `tree`
Displays the folder structure like a tree.

**Syntax**
```cmd
tree
```

Example:

```
C:
├── Desktop
├── Documents
├── Downloads
└── Pictures
```

Useful when you want to understand the folder hierarchy.

---

## 2. Creating and Removing Folders

### `mkdir`
Creates a new folder.

**Syntax**
```cmd
mkdir folder_name
```

Example:
```cmd
mkdir backup_files
```

Creates:

```
backup_files
```

---

### `rmdir`
Deletes a folder.

**Syntax**
```cmd
rmdir folder_name
```

Example:
```cmd
rmdir backup_files
```

Deletes the folder.

> The folder usually needs to be empty before it can be removed.

---

# Working with Files

## `type`
Displays the contents of a text file.

**Syntax**
```cmd
type filename
```

Example:
```cmd
type notes.txt
```

Use it for **small text files**.

---

## `more`
Displays long text one page at a time.

**Syntax**
```cmd
more filename
```

Example:
```cmd
more notes.txt
```

Controls:
- **Space** → Next page
- **Enter** → Next line

Useful when the file is too long to fit on one screen.

---

## `copy`
Copies a file.

**Syntax**
```cmd
copy source destination
```

Example:
```cmd
copy test.txt test2.txt
```

Result:

```
test.txt
test2.txt
```

Both files now exist.

---

## `move`
Moves a file or renames it.

**Syntax**
```cmd
move source destination
```

Example:
```cmd
move test2.txt ..
```

Moves **test2.txt** to the parent folder.

You can also rename a file:

```cmd
move old.txt new.txt
```

---

## `del` / `erase`
Deletes a file.

Both commands do the same thing.

**Syntax**
```cmd
del filename
```

or

```cmd
erase filename
```

Example:
```cmd
erase test2.txt
```

Deletes **test2.txt**.

---

# Wildcards

Wildcard `*` means **"all matching files."**

Example:

```cmd
copy *.md C:\Markdown
```

Meaning:
- Copy **every `.md` file**
- To the folder **C:\Markdown**

Examples:

```cmd
del *.txt
```

Deletes all `.txt` files.

```cmd
copy *.jpg D:\Photos
```

Copies all `.jpg` images.

# Quick Command Summary

| Command | Purpose |
|----------|---------|
| `cd` | Change folder |
| `cd ..` | Go back one folder |
| `dir` | List files and folders |
| `dir /a` | Show hidden/system files |
| `dir /s` | Show all files recursively |
| `tree` | Display folder structure |
| `mkdir` | Create a folder |
| `rmdir` | Delete a folder |
| `type` | View a text file |
| `more` | Read long files page by page |
| `copy` | Copy files |
| `move` | Move or rename files |
| `del` / `erase` | Delete files |
| `*` | Wildcard (matches multiple files) |

---

# Key Points

- **`cd`** → Move between folders.
- **`dir`** → List files and folders.
- **`tree`** → Show folder hierarchy.
- **`mkdir`** → Create a folder.
- **`rmdir`** → Delete a folder.
- **`type`** → Read small text files.
- **`more`** → Read large text files page by page.
- **`copy`** → Duplicate files.
- **`move`** → Move or rename files.
- **`del` / `erase`** → Delete files.
- **`*`** → Match multiple files at once.
