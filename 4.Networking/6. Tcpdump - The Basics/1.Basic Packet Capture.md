# Basic Packet Capture (tcpdump)

## What is tcpdump?

**tcpdump** is a command-line packet capture tool used to monitor, capture, and analyze network traffic. It can display packets in real time or save them to a file for later analysis in tools like Wireshark.

---

# Common tcpdump Options

## 1. Capture on a Specific Network Interface (`-i`)

Before capturing traffic, choose the network interface you want to monitor.

### List Available Interfaces

```bash
ip a
```

or

```bash
ip address show
```

Example output:

- `lo` → Loopback interface
- `eth0`, `ens5` → Ethernet interface
- `wlan0`, `wlo1` → Wireless interface

### Capture on an Interface

```bash
sudo tcpdump -i eth0
```

**Example:**

```bash
sudo tcpdump -i ens5
```

---

## 2. Save Captured Packets (`-w`)

Save captured traffic into a **.pcap** file.

```bash
sudo tcpdump -i eth0 -w capture.pcap
```

### Why save packets?

- Analyze traffic later
- Open the capture in Wireshark
- Keep evidence during investigations
- Share captures with others

> **Note:** When using `-w`, packets are saved to the file instead of being displayed on the screen.

---

## 3. Read Packets from a File (`-r`)

Open and display packets from an existing capture file.

```bash
tcpdump -r capture.pcap
```

Useful for:

- Learning network protocols
- Reviewing previous captures
- Analyzing attacks after they occurred

---

## 4. Capture a Specific Number of Packets (`-c`)

Stop capturing automatically after a specified number of packets.

```bash
sudo tcpdump -i eth0 -c 20
```

This command captures **20 packets** and then exits.

Without `-c`, tcpdump continues capturing until you stop it manually using **Ctrl + C**.

---

## 5. Disable Name Resolution (`-n` and `-nn`)

By default, tcpdump tries to make output easier to read by converting:

- IP addresses → Domain names
- Port numbers → Service names

This can slow analysis and generate extra DNS traffic.

### Disable DNS Resolution

```bash
tcpdump -n
```

Example:

Instead of

```
google.com
```

you'll see

```
142.250.190.78
```

---

### Disable DNS and Port Resolution

```bash
tcpdump -nn
```

Instead of

```
ssh
http
https
```

you'll see

```
22
80
443
```

This is the preferred option during packet analysis.

---

## 6. Verbose Output (`-v`)

Display more information about each packet.

```bash
tcpdump -v
```

More verbosity:

```bash
tcpdump -vv
```

Maximum verbosity:

```bash
tcpdump -vvv
```

Higher verbosity provides additional details such as:

- Time To Live (TTL)
- Packet length
- Packet ID
- TCP options
- Other protocol-specific information

---

# Common tcpdump Commands

| Command | Purpose |
|----------|---------|
| `tcpdump -i eth0` | Capture packets on interface `eth0` |
| `tcpdump -w file.pcap` | Save packets to a capture file |
| `tcpdump -r file.pcap` | Read packets from a capture file |
| `tcpdump -c 50` | Capture only 50 packets |
| `tcpdump -n` | Don't resolve IP addresses |
| `tcpdump -nn` | Don't resolve IP addresses or port names |
| `tcpdump -v` | Show verbose packet information |
| `tcpdump -vv` | More verbose output |
| `tcpdump -vvv` | Maximum verbosity |

---

# Example Commands

### Capture 50 packets on `eth0`

```bash
sudo tcpdump -i eth0 -c 50
```

---

### Capture with verbose output

```bash
sudo tcpdump -i eth0 -c 50 -v
```

---

### Capture Wi-Fi traffic and save it

```bash
sudo tcpdump -i wlo1 -w data.pcap
```

---

### Capture from all interfaces

```bash
sudo tcpdump -i any
```

---

### Capture from all interfaces without resolving names

```bash
sudo tcpdump -i any -nn
```

---

### Read a capture file

```bash
tcpdump -r data.pcap
```

---

# Key Points

- **`-i`** → Select the network interface.
- **`-w`** → Save captured packets to a **.pcap** file.
- **`-r`** → Read packets from a capture file.
- **`-c`** → Capture only a specified number of packets.
- **`-n`** → Disable DNS (hostname) resolution.
- **`-nn`** → Disable both DNS and port name resolution.
- **`-v`, `-vv`, `-vvv`** → Increase the amount of packet details shown.
- `.pcap` files can be opened later in **Wireshark** for deeper analysis.
- Using **`-nn`** is a common practice because it shows the actual IP addresses and port numbers without unnecessary name lookups.
