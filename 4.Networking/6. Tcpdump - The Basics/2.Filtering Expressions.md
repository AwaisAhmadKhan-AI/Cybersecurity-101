# Filtering Expressions (tcpdump)

## Why Use Filtering?

Capturing every packet on a network quickly becomes overwhelming. **Filtering** allows you to capture only the traffic you're interested in, making analysis faster and more efficient.

Common filtering methods include:

- Filtering by **Host**
- Filtering by **Port**
- Filtering by **Protocol**
- Combining filters with **Logical Operators**

---

# Filter by Host

Capture packets sent **to or from** a specific IP address or hostname.

### Syntax

```bash
tcpdump host <IP>
```

or

```bash
tcpdump host <HOSTNAME>
```

### Example

```bash
sudo tcpdump host example.com
```

Capture and save packets exchanged with `example.com`:

```bash
sudo tcpdump host example.com -w http.pcap
```

---

## Source Host

Capture packets **coming from** a specific host.

```bash
tcpdump src host <IP>
```

Example:

```bash
tcpdump src host 192.168.1.10
```

---

## Destination Host

Capture packets **going to** a specific host.

```bash
tcpdump dst host <IP>
```

Example:

```bash
tcpdump dst host 8.8.8.8
```

---

# Filter by Port

Capture traffic using a specific port.

### Syntax

```bash
tcpdump port <PORT_NUMBER>
```

Example (DNS):

```bash
sudo tcpdump port 53 -n
```

This captures both **TCP** and **UDP** traffic on port **53**.

---

## Source Port

Capture packets originating from a specific port.

```bash
tcpdump src port <PORT_NUMBER>
```

Example:

```bash
tcpdump src port 80
```

---

## Destination Port

Capture packets sent to a specific port.

```bash
tcpdump dst port <PORT_NUMBER>
```

Example:

```bash
tcpdump dst port 443
```

---

# Filter by Protocol

Capture packets belonging to a specific protocol.

### Syntax

```bash
tcpdump <PROTOCOL>
```

Common protocols:

- `tcp`
- `udp`
- `icmp`
- `ip`
- `ip6`
- `arp`

Example:

```bash
sudo tcpdump icmp -n
```

This captures only ICMP traffic, such as:

- Ping requests
- Ping replies
- ICMP error messages
- Traceroute packets

---

# Logical Operators

You can combine multiple filters using logical operators.

---

## AND

Both conditions must be true.

### Syntax

```bash
tcpdump <condition1> and <condition2>
```

Example:

```bash
tcpdump host 1.1.1.1 and tcp
```

Captures only **TCP traffic** involving `1.1.1.1`.

---

## OR

At least one condition must be true.

### Syntax

```bash
tcpdump <condition1> or <condition2>
```

Example:

```bash
tcpdump udp or icmp
```

Captures:

- UDP traffic
- ICMP traffic

---

## NOT

Excludes matching traffic.

### Syntax

```bash
tcpdump not <condition>
```

Example:

```bash
tcpdump not tcp
```

Captures everything except TCP traffic.

Possible results include:

- UDP
- ICMP
- ARP
- Other non-TCP protocols

---

# Common Filtering Commands

| Command | Description |
|----------|-------------|
| `tcpdump host <IP>` | Capture packets to or from a specific host |
| `tcpdump src host <IP>` | Capture packets from a specific source host |
| `tcpdump dst host <IP>` | Capture packets sent to a specific destination host |
| `tcpdump port <PORT>` | Capture packets using a specific port |
| `tcpdump src port <PORT>` | Capture packets from a specific source port |
| `tcpdump dst port <PORT>` | Capture packets sent to a specific destination port |
| `tcpdump tcp` | Capture only TCP packets |
| `tcpdump udp` | Capture only UDP packets |
| `tcpdump icmp` | Capture only ICMP packets |

# Practical Examples

### Capture SSH Traffic

```bash
sudo tcpdump -i any tcp port 22
```

Captures SSH traffic on all interfaces.

---

### Capture NTP Traffic

```bash
sudo tcpdump -i wlo1 udp port 123
```

Captures Network Time Protocol (NTP) traffic on the Wi-Fi interface.

---

### Capture HTTPS Traffic for a Specific Website

```bash
sudo tcpdump -i eth0 host example.com and tcp port 443 -w https.pcap
```

This command:

- Listens on `eth0`
- Captures traffic involving `example.com`
- Filters only HTTPS (TCP port 443)
- Saves packets to `https.pcap`

---

# Read a Capture File with Filters

Instead of capturing live traffic, you can filter packets from an existing **.pcap** file.

### Read a Capture File

```bash
tcpdump -r traffic.pcap
```

---

### Display Only the First 5 Packets

```bash
tcpdump -r traffic.pcap -c 5 -n
```

---

### Filter Packets by Source Host

```bash
tcpdump -r traffic.pcap src host 192.168.124.1 -n
```

---

### Count Matching Packets

Use `wc` (Word Count) to count matching packets.

```bash
tcpdump -r traffic.pcap src host 192.168.124.1 -n | wc
```

This displays how many packets match the filter.

---

# Key Points

- **`host`** → Capture traffic to or from a specific host.
- **`src host`** → Capture traffic originating from a host.
- **`dst host`** → Capture traffic sent to a host.
- **`port`** → Capture traffic using a specific port.
- **`src port`** → Filter by source port.
- **`dst port`** → Filter by destination port.
- **`tcp`**, **`udp`**, **`icmp`**, etc., filter traffic by protocol.
- Use **`and`**, **`or`**, and **`not`** to create more precise filters.
- Use **`-r`** to analyze saved packet captures instead of live traffic.
- Combine filters to focus only on the packets relevant to your investigation.
