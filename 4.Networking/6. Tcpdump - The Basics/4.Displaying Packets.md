# Tcpdump – Displaying Packets

## Displaying Packets
Tcpdump provides several options to control how captured packets are displayed. These options help you view packet information in a format that best suits your analysis.

---

## Quick Output (`-q`)

Displays only brief packet information.

### Syntax
```bash
tcpdump -q
```

### Shows
- Timestamp
- Source IP
- Destination IP
- Protocol
- Packet length

### Example
```bash
tcpdump -r TwoPackets.pcap -q
```

**Use Case**
- Quickly review captured traffic.
- Best for large packet captures.

---

## Display Link-Layer Header (`-e`)

Displays Ethernet (Layer 2) information.

### Syntax
```bash
tcpdump -e
```

### Shows
- Source MAC address
- Destination MAC address
- Ethernet type
- Packet length

### Example
```bash
tcpdump -r TwoPackets.pcap -e
```

**Use Case**
- Analyze Ethernet communication.
- Useful for ARP, DHCP, MAC address investigations.

---

## Display Packet as ASCII (`-A`)

Shows printable packet contents as ASCII text.

### Syntax
```bash
tcpdump -A
```

### Example
```bash
tcpdump -r TwoPackets.pcap -A
```

**Use Case**
- Read HTTP requests/responses.
- View plain-text protocols.
- Inspect usernames, commands, or messages.

> **Note:** Encrypted or compressed traffic will mostly appear as unreadable characters.

---

## Display Packet in Hexadecimal (`-xx`)

Shows every packet byte in hexadecimal.

### Syntax
```bash
tcpdump -xx
```

### Example
```bash
tcpdump -r TwoPackets.pcap -xx
```

**Shows**
- Complete packet bytes
- IP header
- TCP/UDP header
- Payload

**Use Case**
- Low-level packet analysis.
- Inspect protocol headers and raw packet data.

---

## Display Packet in Hex + ASCII (`-X`)

Displays packet contents in both hexadecimal and ASCII.

### Syntax
```bash
tcpdump -X
```

### Example
```bash
tcpdump -r TwoPackets.pcap -X
```

### Output
- Left side → Hexadecimal bytes
- Right side → ASCII representation

**Use Case**
- Best option for packet analysis.
- View raw bytes while simultaneously reading printable text.

---

# Display Options Summary

| Option | Purpose |
|---------|---------|
| `-q` | Quick output (brief packet information) |
| `-e` | Display Ethernet/MAC header |
| `-A` | Show packet data as ASCII text |
| `-xx` | Show packet data in hexadecimal |
| `-X` | Show packet data in both hexadecimal and ASCII |

---

# Common Examples

### Quick packet overview
```bash
tcpdump -i eth0 -q
```

---

### Include MAC addresses
```bash
tcpdump -i eth0 -e
```

---

### Read packets as plain text
```bash
tcpdump -A -r capture.pcap
```

---

### Display hexadecimal output
```bash
tcpdump -xx -r capture.pcap
```

---

### Display hexadecimal + ASCII (Most Useful)
```bash
tcpdump -X -r capture.pcap
```

---

# Key Points

- `-q` provides a short summary of packets.
- `-e` includes Ethernet (MAC) header information.
- `-A` displays printable ASCII text from packet payloads.
- `-xx` shows raw packet bytes in hexadecimal.
- `-X` combines hexadecimal and ASCII views, making it the most informative option for packet inspection.
- Use `-A` for plain-text protocols (HTTP, FTP, Telnet).
- Use `-xx` or `-X` for encrypted traffic or detailed protocol analysis.
