# SMTPS, POP3S, and IMAPS

Just as **HTTP becomes HTTPS** by adding **TLS encryption**, other email protocols can also be secured in the same way.

Adding TLS protects communication between the client and the server by encrypting all transmitted data. This prevents attackers from reading sensitive information such as usernames, passwords, and email contents.

## Secure Versions of Email Protocols

| Standard Protocol | Secure Version |
|-------------------|----------------|
| SMTP | SMTPS |
| POP3 | POP3S |
| IMAP | IMAPS |

These secure protocols work the same way as their original versions, but all communication is encrypted using **TLS**.

---

# Default Port Numbers

## Standard (Unencrypted) Ports

| Protocol | Default TCP Port | Purpose |
|----------|:----------------:|---------|
| HTTP | 80 | Web browsing |
| SMTP | 25 | Sending emails |
| POP3 | 110 | Downloading emails |
| IMAP | 143 | Synchronizing emails |

## Secure (TLS-Encrypted) Ports

| Protocol | Default TCP Port | Purpose |
|----------|:----------------:|---------|
| HTTPS | 443 | Secure web browsing |
| SMTPS | 465, 587 | Secure email sending |
| POP3S | 995 | Secure email retrieval |
| IMAPS | 993 | Secure email synchronization |

---

# Why Use TLS?

Adding TLS provides several security benefits:

- Encrypts all transmitted data.
- Protects usernames and passwords from being intercepted.
- Keeps emails and other sensitive information private.
- Ensures data is not modified while in transit.
- Verifies the identity of the server using digital certificates.

---

# Key Point

TLS is not limited to web traffic. It can secure many application-layer protocols by encrypting the communication between the client and the server.

Examples:

- **HTTP → HTTPS**
- **SMTP → SMTPS**
- **POP3 → POP3S**
- **IMAP → IMAPS**

The protocol's functionality remains the same—the only difference is that **TLS adds an encrypted layer**, making communication secure.

---

# Quick Revision

- **SMTPS** = Secure SMTP (**Ports 465 or 587**) → Sends encrypted emails.
- **POP3S** = Secure POP3 (**Port 995**) → Securely downloads emails.
- **IMAPS** = Secure IMAP (**Port 993**) → Securely synchronizes emails across multiple devices.
- **HTTPS** = Secure HTTP (**Port 443**) → Secure web communication.
- **TLS** provides **Confidentiality, Integrity, and Authentication (CIA)** by encrypting network communication.
