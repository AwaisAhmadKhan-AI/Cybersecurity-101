# SFTP and FTPS

Both **SFTP** and **FTPS** are secure protocols used for transferring files over a network. Although their names are similar, they work differently and use different security technologies.

---

# SFTP (SSH File Transfer Protocol)

**SFTP (SSH File Transfer Protocol)** is a secure file transfer protocol built on top of **SSH (Secure Shell)**.

Since it uses SSH, all communication—including file transfers, usernames, passwords, and commands—is encrypted.

**Default TCP Port:** **22**

## Common SFTP Commands

| Command | Description |
|---------|-------------|
| `get filename` | Downloads a file from the server. |
| `put filename` | Uploads a file to the server. |

SFTP commands are similar to Unix/Linux commands and may differ from traditional FTP commands.

---

# FTPS (File Transfer Protocol Secure)

**FTPS (File Transfer Protocol Secure)** is the secure version of **FTP**.

Instead of using SSH, FTPS secures file transfers by adding **TLS (Transport Layer Security)** encryption, just like **HTTPS** secures HTTP.

**Default TCP Port:** **990**

FTPS requires a valid **TLS/SSL certificate** to establish a secure connection.

---

# SFTP vs FTPS

| Feature | SFTP | FTPS |
|---------|------|-------|
| Full Name | SSH File Transfer Protocol | File Transfer Protocol Secure |
| Security | SSH | TLS/SSL |
| Default Port | 22 | 990 |
| Requires TLS Certificate | ❌ No | ✅ Yes |
| Uses SSH | ✅ Yes | ❌ No |
| Connection Type | Single encrypted connection | Separate control and data connections |

---

# Advantages of SFTP

- Uses SSH encryption for secure communication.
- Easy to configure if an SSH server (such as OpenSSH) is already installed.
- Transfers files and commands through a single encrypted connection.
- Works well through firewalls because only one port is typically required.

---

# Advantages of FTPS

- Uses TLS encryption to secure file transfers.
- Compatible with existing FTP infrastructure.
- Supports digital certificates for server authentication.

---

# Key Differences

- **SFTP** is part of the **SSH protocol suite** and uses **Port 22**.
- **FTPS** is an extension of **FTP** that uses **TLS/SSL encryption** and typically uses **Port 990**.
- SFTP uses a **single encrypted connection**, while FTPS uses **separate connections** for control and data transfer.
- FTPS requires a **TLS certificate**, whereas SFTP only requires an SSH server.

---

# Quick Revision

- **SFTP** = Secure file transfer using **SSH** (**Port 22**).
- **FTPS** = Secure file transfer using **TLS/SSL** (**Port 990**).
- **SFTP** is generally easier to configure because it is built into SSH.
- **FTPS** requires **TLS certificates** and separate control/data connections.
- Both protocols provide secure file transfer by encrypting communication.
