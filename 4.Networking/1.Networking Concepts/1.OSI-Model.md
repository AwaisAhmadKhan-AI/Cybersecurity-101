# OSI Model (Open Systems Interconnection)

## What is the OSI Model?

The **OSI (Open Systems Interconnection) Model** is a **7-layer conceptual framework** developed by the **ISO (International Organization for Standardization)** that explains **how data travels from one computer to another over a network**.

It helps us understand:
- How network communication works
- How different networking protocols interact
- How to troubleshoot network problems

> **Note:** The OSI model is theoretical, but it is extremely important for understanding computer networking.

# Layer 1 – Physical Layer

## Purpose

The **Physical Layer** is responsible for the **physical transmission of bits (0s and 1s)** between devices.

It defines:
- Cables
- Connectors
- Wireless signals
- Electrical signals
- Optical signals

### Examples

- Ethernet cable
- Fiber optic cable
- Wi-Fi (2.4 GHz, 5 GHz, 6 GHz)
- Radio signals

### Devices

- Hub
- Repeater
- Cables

### Data Unit

**Bits (0 and 1)**

---

# Layer 2 – Data Link Layer

## Purpose

The **Data Link Layer** transfers data **between devices on the same local network (LAN)**.

It:
- Detects errors
- Controls access to the network
- Uses **MAC addresses**

### MAC Address

A **MAC (Media Access Control) Address** is a **48-bit (6-byte)** unique hardware address assigned to every network interface.

Example:

```
00:1A:2B:3C:4D:5E
```

The first **3 bytes** identify the manufacturer.

### Protocols

- Ethernet (802.3)
- Wi-Fi (802.11)

### Devices

- Switch
- Bridge

### Data Unit

**Frame**

---

# Layer 3 – Network Layer

## Purpose

The **Network Layer** moves data **between different networks**.

Its responsibilities:

- Logical addressing
- Routing
- Finding the best path

Instead of MAC addresses, this layer uses **IP addresses**.

### Protocols

- IP
- ICMP
- IPSec
- VPN

### Devices

- Router
- Layer 3 Switch

### Data Unit

**Packet**

---

# Layer 4 – Transport Layer

## Purpose

Provides **end-to-end communication** between two devices.

Responsibilities:

- Reliable communication
- Error checking
- Data segmentation
- Flow control

### Protocols

- TCP
- UDP

### TCP

- Reliable
- Connection-oriented
- Guarantees delivery

Examples:
- HTTP
- HTTPS
- FTP
- SSH

### UDP

- Faster
- Connectionless
- No guarantee of delivery

Examples:
- Streaming
- DNS
- VoIP
- Online games

### Data Unit

**Segment (TCP)**

**Datagram (UDP)**

---

# Layer 5 – Session Layer

## Purpose

Manages communication sessions between two applications.

Responsibilities:

- Start a session
- Maintain a session
- End a session
- Synchronize communication

### Protocols

- NFS
- RPC

### Example

When two computers communicate continuously, this layer manages that session until it ends.

---

# Layer 6 – Presentation Layer

## Purpose

Ensures that data is in a format the receiving application can understand.

Responsibilities:

- Data encoding
- Data encryption
- Data compression

### Examples

Encoding

- ASCII
- Unicode

Compression

- JPEG
- PNG
- MPEG

Email Attachment Encoding

- MIME

### Example

Before sending an image by email:

Image → JPEG → MIME Encoding → Network

---

# Layer 7 – Application Layer

## Purpose

Provides network services directly to applications used by users.

This is the layer users interact with.

### Protocols

- HTTP
- HTTPS
- FTP
- DNS
- SMTP
- POP3
- IMAP

### Examples

- Opening a website
- Sending emails
- Downloading files
- DNS lookups

# OSI Data Flow

```
Application
      │
Presentation
      │
Session
      │
Transport
      │
Network
      │
Data Link
      │
Physical
```

When sending data:

```
Application
↓
Presentation
↓
Session
↓
Transport
↓
Network
↓
Data Link
↓
Physical
```

The receiving computer processes it in the reverse order.

---

# Encapsulation

As data moves **down** the OSI model, each layer adds its own header.

```
Application Data
        ↓
Transport Header
        ↓
Network Header
        ↓
Data Link Header
        ↓
Bits Sent
```

At the receiving end, each layer removes its corresponding header.

# Important Exam Points

- OSI has **7 layers**.
- Layer **1** = Physical.
- Layer **7** = Application.
- **MAC Address** belongs to **Layer 2**.
- **IP Address** belongs to **Layer 3**.
- **TCP** and **UDP** work at **Layer 4**.
- **HTTP**, **FTP**, **DNS**, **SMTP** work at **Layer 7**.
- **JPEG**, **PNG**, **Unicode**, and **MIME** belong to **Layer 6**.
- Routers work at **Layer 3**.
- Switches work at **Layer 2**.
- Hubs operate at **Layer 1**.
- Data Units:
  - Layer 1 → **Bits**
  - Layer 2 → **Frames**
  - Layer 3 → **Packets**
  - Layer 4 → **Segments (TCP)** / **Datagrams (UDP)**
