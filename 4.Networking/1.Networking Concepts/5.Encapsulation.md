# Encapsulation

## What is Encapsulation?

**Encapsulation** is the process of **adding protocol information (headers and sometimes trailers)** to data as it moves **down the networking layers** before being sent over the network.

Each layer adds its own information without changing the data created by the layer above.

Think of it like **packing a gift**:

- The **gift** = Your original data.
- The **small box** = Transport Layer.
- The **shipping box** = Network Layer.
- The **delivery package** = Data Link Layer.

Each layer wraps the data with its own information.

---

# Why is Encapsulation Important?

Encapsulation allows each network layer to perform its own job independently.

Benefits:

- Modular communication
- Easier troubleshooting
- Standardized communication
- Different protocols can work together
- Data can travel correctly across networks

---

# Encapsulation Process

Data moves **from the top layer down to the bottom layer**.

```
Application
      ↓
Transport
      ↓
Network (Internet)
      ↓
Data Link
      ↓
Physical
```

Each layer adds its own header.

---

# Step 1: Application Layer

The user creates data.

Example:

- Sending an email
- Visiting a website
- Sending a chat message

Example:

```
Hello TryHackMe!
```

This is called:

```
Application Data
```

---

# Step 2: Transport Layer

The Transport Layer receives the application data.

It adds either a:

- TCP Header
- UDP Header

Now the data becomes:

### TCP

```
TCP Segment
```

or

### UDP

```
UDP Datagram
```

The TCP/UDP header contains information such as:

- Source Port
- Destination Port
- Sequence Number (TCP)
- ACK Number (TCP)

---

# Step 3: Network (Internet) Layer

The Network Layer receives the TCP Segment or UDP Datagram.

It adds an:

```
IP Header
```

The IP header contains:

- Source IP Address
- Destination IP Address
- TTL
- Protocol

Now it becomes an:

```
IP Packet
```

---

# Step 4: Data Link Layer

The Data Link Layer receives the IP Packet.

It adds:

- MAC Header
- Trailer (Error Checking)

Now it becomes a:

```
Frame
```

Examples:

- Ethernet Frame
- WiFi Frame

The frame contains:

- Source MAC Address
- Destination MAC Address
- Error Detection (FCS)

---

# Step 5: Physical Layer

The frame is converted into:

- Electrical signals
- Optical signals
- Radio signals

These signals travel across:

- Ethernet cable
- Fiber optic cable
- WiFi

---

# Encapsulation Flow

```text
Application
    Data
      │
      ▼
Transport
TCP Header + Data
      │
      ▼
Network
IP Header + TCP Segment
      │
      ▼
Data Link
MAC Header + IP Packet + Trailer
      │
      ▼
Physical
Bits (0s and 1s)
```

---

# Data Unit Names

| Layer | Data Unit |
|---------|-----------|
| Application | Data |
| Transport | Segment (TCP) / Datagram (UDP) |
| Network | Packet |
| Data Link | Frame |
| Physical | Bits |

---

# Decapsulation

The receiving computer performs the **reverse process**.

This is called:

> **Decapsulation**

Each layer removes its own header until the original data reaches the application.

```
Bits
   ↑
Frame
   ↑
Packet
   ↑
Segment
   ↑
Application Data
```

# Life of a Packet (Example)

Suppose you search for a room on **TryHackMe**.

---

## Step 1

You type:

```
Windows Fundamentals
```

and press **Enter**.

---

## Step 2

Your browser creates an:

```
HTTP Request
```

---

## Step 3

The Transport Layer (TCP):

- Creates a connection using the Three-Way Handshake.
- Adds the TCP Header.

Result:

```
TCP Segment
```

---

## Step 4

The Network Layer:

Adds the:

- Source IP
- Destination IP

Result:

```
IP Packet
```

---

## Step 5

The Data Link Layer:

Adds:

- Source MAC
- Destination MAC
- Trailer

Result:

```
Ethernet/WiFi Frame
```

---

## Step 6

The Physical Layer:

Converts the frame into:

- Electrical signals
- Radio signals
- Optical signals

The data is transmitted over the network.

---

## Step 7

The Router

Every router:

1. Removes the old Data Link header and trailer.
2. Reads the Destination IP.
3. Decides the best route.
4. Creates a new Data Link frame.
5. Sends the packet to the next router.

This process repeats until the packet reaches the destination network.

---

## Step 8

Destination Computer

The destination computer performs **Decapsulation**:

```
Frame
   ↓
Packet
   ↓
TCP Segment
   ↓
HTTP Request
```

Finally, the web server receives your request.

---

# Encapsulation vs Decapsulation

| Encapsulation | Decapsulation |
|---------------|---------------|
| Sender Side | Receiver Side |
| Adds Headers | Removes Headers |
| Moves Down the Layers | Moves Up the Layers |
| Prepares Data for Transmission | Restores Original Data |

# Quick Revision

- **Encapsulation** = Adding headers (and sometimes trailers) as data moves **down** the networking stack.
- **Decapsulation** = Removing headers as data moves **up** the networking stack.
- Data Units:
  - **Application:** Data
  - **Transport:** Segment (TCP) / Datagram (UDP)
  - **Network:** Packet
  - **Data Link:** Frame
  - **Physical:** Bits
- **TCP** adds the Transport header.
- **IP** adds the Network header.
- **Ethernet/WiFi** adds the Data Link header and trailer.
- Routers inspect the **IP header** to forward packets.
- The destination removes each header until the original application data is delivered.
