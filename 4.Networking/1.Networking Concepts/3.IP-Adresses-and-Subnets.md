# IP Addresses and Subnets

## What is an IP Address?
- An **IP (Internet Protocol) address** is a unique identifier assigned to every device on a network.
- It allows devices to communicate with each other.
- Think of an IP address like your **home address**:
  - Just as mail is delivered to your home address,
  - Data is delivered to your device using its IP address.

> Example IPv4 Addresses:
```
192.168.0.1
172.16.159.243
```

---

# IPv4 Address Structure

An IPv4 address consists of:

- **4 octets (4 bytes)**
- Total **32 bits**
- Each octet contains **8 bits**
- Each octet ranges from **0 to 255**

Example:

```
192.168.66.89

192   168   66   89
 |      |     |    |
Octet Octet Octet Octet
```

---

# Network and Broadcast Address

In a subnet:

- **Network Address**
  - Identifies the network itself.
  - Usually ends in **0**.

Example:
```
192.168.1.0
```

- **Broadcast Address**
  - Sends data to **every device** on the network.
  - Usually ends in **255**.

Example:
```
192.168.1.255
```

Therefore:

```
Usable Hosts:
192.168.1.1
to
192.168.1.254
```

# Viewing Your IP Address

## Windows

```powershell
ipconfig
```

Shows:

- IP Address
- Subnet Mask
- Default Gateway

---

## Linux

### Method 1

```bash
ifconfig
```

Example:

```
inet 192.168.66.89
netmask 255.255.255.0
broadcast 192.168.66.255
```

Shows:

- IP Address
- Subnet Mask
- Broadcast Address

---

### Method 2

```bash
ip a s
```

Example:

```
inet 192.168.66.89/24
brd 192.168.66.255
```

---

# What Does "/24" Mean?

Example:

```
192.168.66.89/24
```

The **/24** is called **CIDR notation**.

It means:

- First **24 bits** are the **network portion**.
- Remaining **8 bits** identify the host.

Equivalent subnet mask:

```
255.255.255.0
```

So:

```
Network:
192.168.66.0

Usable Hosts:
192.168.66.1
to
192.168.66.254

Broadcast:
192.168.66.255
```

# Public vs Private IP Addresses

There are two main types of IP addresses:

## 1. Public IP Address

- Accessible over the Internet.
- Assigned by your ISP.
- Globally unique.
- Used to communicate with external networks.

Example:

```
8.8.8.8
```

---

## 2. Private IP Address

- Used inside local networks (LAN).
- Cannot be accessed directly from the Internet.
- Requires **NAT (Network Address Translation)** to communicate with the Internet.

Think of it like:

- Public IP = Home address
- Private IP = Apartment number inside a building

---

# Private IP Address Ranges (Memorize)

### Class A

```
10.0.0.0
to
10.255.255.255
```

CIDR:

```
10.0.0.0/8
```

---

### Class B

```
172.16.0.0
to
172.31.255.255
```

CIDR:

```
172.16.0.0/12
```

---

### Class C

```
192.168.0.0
to
192.168.255.255
```

CIDR:

```
192.168.0.0/16
```

---

## Easy Way to Remember

```
10.x.x.x

172.16.x.x
to
172.31.x.x

192.168.x.x
```

If an IP starts with one of these ranges, it is **Private**.

# Routing

A **Router** connects different networks together.

Imagine a **Post Office**:

- You give it a parcel.
- It checks the destination.
- It forwards the parcel toward the correct city.

A router works the same way.

Instead of letters, it forwards:

- Network packets

Instead of addresses, it uses:

- IP addresses

---

## Router Responsibilities

- Reads destination IP address.
- Chooses the best path.
- Sends packets toward the destination.
- Connects different networks together.

---

# OSI Layer

Routers operate at:

```
Layer 3
(Network Layer)
```

Because they work with **IP addresses**.
