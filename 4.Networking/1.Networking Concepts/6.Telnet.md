# Telnet

## What is Telnet?

**TELNET (Teletype Network)** is a network protocol used to create a **remote terminal connection**.

In simple words:

- It lets you connect to another computer over a network.
- After connecting, you can send **text commands** to that remote system.
- Although it was originally used for **remote administration**, it can connect to **any service listening on a TCP port**.

> **Syntax:**
```bash
telnet <IP_ADDRESS> <PORT>
```

---

# Services Used in This Lab

The target machine has three services running:

| Service | Default Port | Purpose |
|----------|-------------|---------|
| Echo Server | 7 | Sends back (echoes) whatever you type |
| Daytime Server | 13 | Displays the current date and time |
| HTTP Server | 80 | Serves web pages |

> **Note:** Echo and Daytime servers are considered security risks today and are normally disabled. They are only enabled in this lab for learning purposes.

---

# 1. Echo Server (Port 7)

### Connect

```bash
telnet MACHINE_IP 7
```

### Example

```text
Trying MACHINE_IP...
Connected to MACHINE_IP.
Escape character is '^]'.

Hi
Hi

How are you?
How are you?

Bye
Bye
```

### Explanation

Whatever you type is sent back to you.

If you type:

```text
Hello
```

The server replies:

```text
Hello
```

This is why it's called an **Echo Server**.

---

## Closing the Connection

Press:

```
CTRL + ]
```

You'll enter Telnet mode.

Then type:

```bash
quit
```

Output:

```text
Connection closed.
```

---

# 2. Daytime Server (Port 13)

### Connect

```bash
telnet MACHINE_IP 13
```

### Example

```text
Trying MACHINE_IP...
Connected to MACHINE_IP.
Escape character is '^]'.

Thu Jun 20 12:36:32 PM UTC 2024

Connection closed by foreign host.
```

### Explanation

- The server immediately sends the **current date and time**.
- After sending it, the server automatically closes the connection.

---

# 3. HTTP Server (Port 80)

Since **HTTP works over TCP**, Telnet can manually communicate with a web server.

### Connect

```bash
telnet MACHINE_IP 80
```

After connecting, type:

```http
GET / HTTP/1.1
Host: telnet.thm

```

> **Important:** Press **Enter twice** after `Host:`. The second Enter creates a blank line that tells the web server your request is complete.

---

### Example Response

```http
HTTP/1.1 200 OK
Content-Type: text/html
...
```

The server then sends the webpage and closes the connection.

---

# Understanding the HTTP Request

```http
GET / HTTP/1.1
```

### GET

Requests data from the server.

---

### /

Means:

> "Give me the homepage (root page)."

---

### HTTP/1.1

Specifies the HTTP version.

---

```http
Host: telnet.thm
```

Tells the web server which website you're requesting.

---

# Why Press Enter Twice?

HTTP requests end with a **blank line**.

Example:

```http
GET / HTTP/1.1
Host: telnet.thm

```

The empty line tells the server:

> "I'm done sending my request."

Without it, the server keeps waiting.

---

# Why Use Telnet?

Telnet is useful for:

- Testing whether a TCP port is open.
- Manually talking to network services.
- Understanding how protocols like HTTP work.
- Troubleshooting network services.

Although Telnet is insecure (it sends data in plain text), it is still useful for learning and testing.

---

# Telnet Summary

| Command | Purpose |
|----------|---------|
| `telnet IP PORT` | Connect to a TCP service |
| `telnet MACHINE_IP 7` | Connect to Echo Server |
| `telnet MACHINE_IP 13` | Connect to Daytime Server |
| `telnet MACHINE_IP 80` | Connect to HTTP Server |
| `CTRL + ]` | Enter Telnet command mode |
| `quit` | Close the Telnet session |

---

# Key Points to Remember

- **Telnet** creates a remote TCP connection.
- It can connect to **any TCP port**, not just remote terminals.
- **Port 7** → Echo Server (returns whatever you type).
- **Port 13** → Daytime Server (shows current date and time).
- **Port 80** → HTTP Server (serves webpages).
- To manually request a webpage:
  ```http
  GET / HTTP/1.1
  Host: telnet.thm

  ```
- Press **Enter twice** after the `Host` line to complete the HTTP request.
- Exit Telnet using **CTRL + ]**, then type `quit`.
