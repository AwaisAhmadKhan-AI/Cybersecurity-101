# TCP/IP Model

## What is the TCP/IP Model?

**TCP/IP (Transmission Control Protocol / Internet Protocol)** is the networking model that powers the Internet. It was developed in the **1970s** by the **U.S. Department of Defense (DoD)**.

### Why was it created?
- To build a **reliable** and **fault-tolerant** network.
- If one part of the network fails (e.g., due to damage or attack), data can still travel through another path.
- Routing protocols automatically find new paths when the network changes.

> **Remember:**  
> - **OSI Model** = Theoretical (used for learning networking concepts).  
> - **TCP/IP Model** = Practical (used on the Internet).

---

# TCP/IP Layers

Unlike the OSI model (7 layers), the traditional TCP/IP model has **4 layers**.

## 1. Application Layer

### Purpose
Provides network services directly to applications used by users.

### Combines these OSI layers
- Layer 7 - Application
- Layer 6 - Presentation
- Layer 5 - Session

### Responsibilities
- Communication between applications
- Data formatting
- Encryption
- Compression
- Session management

### Common Protocols
- HTTP
- HTTPS
- FTP
- SMTP
- POP3
- IMAP
- DNS
- SSH
- Telnet

### Examples
- Opening a website
- Sending an email
- Downloading files
- Remote login

---

## 2. Transport Layer

### Purpose
Provides **end-to-end communication** between devices.

### Responsibilities
- Splits data into segments
- Error checking
- Reliable delivery (TCP)
- Fast delivery (UDP)
- Flow control

### Common Protocols
- TCP
- UDP

### Examples
- Video calls
- Web browsing
- Online gaming
- File transfers

---

## 3. Internet Layer

### Purpose
Moves data between different networks.

### Responsibilities
- Logical addressing (IP addresses)
- Routing packets
- Finding the best path to the destination

### Common Protocols
- IP
- ICMP
- IPSec

### Examples
- Sending packets across the Internet
- Ping (ICMP)
- VPN communication (IPSec)

---

## 4. Link Layer

### Purpose
Transfers data between devices on the same local network.

### Responsibilities
- Uses MAC addresses
- Creates frames
- Sends data over Ethernet or Wi-Fi

### Common Technologies
- Ethernet (802.3)
- Wi-Fi (802.11)

---

# TCP/IP vs OSI Mapping

| TCP/IP Layer | OSI Layer(s) | Common Protocols |
|--------------|--------------|------------------|
| Application | 7, 6, 5 | HTTP, HTTPS, FTP, SMTP, DNS, SSH |
| Transport | 4 | TCP, UDP |
| Internet | 3 | IP, ICMP, IPSec |
| Link | 2 | Ethernet, Wi-Fi |

> **Note:**  
> In the traditional 4-layer TCP/IP model, the **Physical Layer (OSI Layer 1)** is included within the **Link Layer**.

---

# Modern 5-Layer Internet Model

Many networking books (such as **Computer Networking: A Top-Down Approach**) use **5 layers** instead of 4.

1. Application
2. Transport
3. Network
4. Link
5. Physical

The only difference is that the **Physical Layer** is separated from the Link Layer.

---

# OSI vs TCP/IP

| Feature | OSI Model | TCP/IP Model |
|----------|-----------|--------------|
| Number of Layers | 7 | 4 (or 5 in modern books) |
| Type | Theoretical | Practical |
| Created By | ISO | U.S. Department of Defense |
| Used Today | Mainly for learning | Used on the Internet |

# Easy Memory Trick

### TCP/IP Layers (Top → Bottom)

**A → T → I → L**

- **A** = Application
- **T** = Transport
- **I** = Internet
- **L** = Link

# Quick Revision

- TCP/IP is the **real networking model** used on the Internet.
- Developed by the **U.S. Department of Defense**.
- Designed to keep communication working even if part of the network fails.
- Has **4 layers**:
  1. Application
  2. Transport
  3. Internet
  4. Link
- Many modern books add the **Physical Layer**, making it a **5-layer model**.
- TCP/IP is simpler than the 7-layer OSI model and is the foundation of modern Internet communication.
