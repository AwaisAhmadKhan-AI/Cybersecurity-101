# FTP (File Transfer Protocol)

## What is FTP?

**FTP (File Transfer Protocol)** is an application-layer protocol used to **transfer files between a client and a server** over a network.

Unlike HTTP, which is mainly designed to deliver web pages, FTP is specifically built for **uploading and downloading files**, making it an efficient choice for file transfers.

> **Simple Explanation:**  
> FTP acts like a file manager over the network, allowing you to browse directories, upload files, and download files from a remote server.

---

# Why FTP is Used

FTP is commonly used to:

- Upload files to a remote server
- Download files from a server
- Share files between systems
- Manage website files
- Transfer large amounts of data efficiently

---

# How FTP Works

FTP follows a **client-server model**.

1. The client connects to the FTP server.
2. The user authenticates with a username and password (or anonymously if allowed).
3. The client can browse directories.
4. Files can be uploaded or downloaded as needed.

```
FTP Client  ─────►  FTP Server
       Browse, Upload, Download Files
```

---

# Default Port

FTP uses **TCP** because reliable file transfer is important.

| Protocol | Default Port |
|----------|-------------:|
| FTP Control Connection | **21** |

> FTP uses **two separate TCP connections**:
>
> - **Control Connection** → Sends commands and receives responses (Port 21)
> - **Data Connection** → Transfers files and directory listings

This separation allows commands and file transfers to occur independently.

---

# Common FTP Commands

## USER

Specifies the username for login.

Example:

```text
USER john
```

---

## PASS

Provides the password for authentication.

Example:

```text
PASS MyPassword123
```

---

## RETR (Retrieve)

Downloads a file from the FTP server.

Example:

```text
RETR report.pdf
```

---

## STOR (Store)

Uploads a file to the FTP server.

Example:

```text
STOR backup.zip
```

---

## LIST

Displays the contents of the current directory.

Example:

```text
LIST
```

> Many FTP clients use the familiar command:

```text
ls
```

Internally, the client sends the **LIST** command to the server.

---

# Example FTP Session

Connect to a server:

```bash
ftp example.com
```

Login:

```text
Name: anonymous
Password:
```

List available files:

```text
ftp> ls
```

Download a file:

```text
ftp> get notes.txt
```

Upload a file:

```text
ftp> put report.pdf
```

Disconnect:

```text
ftp> quit
```

---

# FTP Transfer Modes

FTP supports different transfer modes depending on the file type.

## ASCII Mode

Used for:

- Text files
- Configuration files
- Source code

Example:

```text
type ascii
```

---

## Binary Mode

Used for:

- Images
- Videos
- PDFs
- ZIP files
- Executable programs

Example:

```text
type binary
```

Using the correct mode helps prevent file corruption during transfer.

---

# Anonymous FTP

Some FTP servers allow users to log in without creating an account.

Example:

```text
Username: anonymous
Password: (usually left blank or any email address)
```

This is commonly used for sharing public files.

---

# FTP Traffic

When monitoring FTP traffic with packet analysis tools (such as Wireshark), you'll notice:

- Login requests
- Authentication responses
- Directory listing commands
- File upload/download commands

An important observation is that:

- Commands are exchanged over the **control connection**.
- Files and directory listings are transferred over a **separate data connection**.

---

# Advantages of FTP

- Fast file transfers
- Easy upload and download of files
- Supports transferring large files
- Allows remote file management
- Widely supported by operating systems and FTP clients

---

# Limitations of FTP

Standard FTP has a major security weakness:

- Usernames and passwords are transmitted **in plain text**.
- Files are transferred **without encryption**.
- Attackers can intercept sensitive information if they capture the network traffic.

Because of this, secure alternatives such as **SFTP** and **FTPS** are preferred for transferring sensitive data.

# Interview Questions

### What is FTP?

FTP (File Transfer Protocol) is an application-layer protocol used to transfer files between a client and a server over a TCP network.

---

### Which port does FTP use?

FTP uses **TCP port 21** for its control connection.

---

### What is the purpose of the USER command?

The **USER** command specifies the username used for authentication.

---

### What is the RETR command?

The **RETR** (Retrieve) command downloads a file from the FTP server to the client.

---

### What is the STOR command?

The **STOR** (Store) command uploads a file from the client to the FTP server.

---

### Why does FTP use two connections?

FTP separates communication into:

- A **control connection** for commands.
- A **data connection** for transferring files and directory listings.

This design allows file transfers without interrupting command communication.

---

### Why is FTP considered insecure?

Standard FTP does not encrypt usernames, passwords, or transferred files, making it vulnerable to interception and packet sniffing.
