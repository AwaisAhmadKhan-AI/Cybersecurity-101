# POP3 (Post Office Protocol Version 3)

## What is POP3?

**POP3 (Post Office Protocol Version 3)** is an application layer protocol used to **retrieve (download) emails** from a mail server to a local email client.

- **SMTP** is used to **send emails**.
- **POP3** is used to **receive/download emails**.

### Simple Analogy

- 📤 **SMTP** = Dropping a letter into the post office mailbox.
- 📥 **POP3** = Opening your personal mailbox and collecting your letters.

---

# Default Port

| Protocol | Default Port | Transport Protocol |
|----------|-------------:|-------------------|
| POP3 | **110** | TCP |

---

# How POP3 Works

1. The email client connects to the POP3 server.
2. The user logs in with a username and password.
3. The client checks how many emails are available.
4. The client downloads the required email(s).
5. The connection is closed.

---

# Common POP3 Commands

| Command | Purpose |
|----------|---------|
| `USER <username>` | Specifies the username |
| `PASS <password>` | Provides the password |
| `STAT` | Displays the number of emails and total mailbox size |
| `LIST` | Lists all emails with their sizes |
| `RETR <message_number>` | Downloads a specific email |
| `DELE <message_number>` | Marks an email for deletion |
| `QUIT` | Ends the session and applies changes |

# Example POP3 Session

```bash
telnet MACHINE_IP 110
```

After connecting:

```text
USER linda
PASS Pa$$123
STAT
LIST
RETR 1
QUIT
```

Example:

```text
USER linda
PASS Pa$$123
STAT
+OK 3 1264

LIST
+OK
1 407
2 412
3 445

RETR 3
```

The server then returns the contents of email **#3**.

---

# Important Points

- POP3 uses **TCP** for reliable communication.
- The default port is **110**.
- It requires **authentication** (username and password).
- It allows users to download emails from the mail server.
- Emails can optionally be deleted from the server after download (depending on the client settings).
- POP3 is simpler than IMAP because it mainly focuses on downloading emails rather than synchronizing them.

---

# Security Concern

Basic POP3 **does not encrypt** communication.

This means:

- Username can be intercepted.
- Password can be intercepted.
- Email contents can be read by anyone capturing the network traffic.

For secure email retrieval, **POP3S (POP3 over SSL/TLS)** should be used instead.

# POP3 Workflow

```text
Mail Server
      │
      │ (Stores Emails)
      ▼
POP3 Client Connects
      │
      ▼
Login (USER + PASS)
      │
      ▼
View Mailbox (STAT / LIST)
      │
      ▼
Download Email (RETR)
      │
      ▼
(Optional) Delete Email (DELE)
      │
      ▼
Quit Session (QUIT)
```

# Quick Revision

- **Full Form:** Post Office Protocol Version 3 (POP3)
- **OSI Layer:** Application Layer (Layer 7)
- **Transport Protocol:** TCP
- **Default Port:** **110**
- **Purpose:** Download emails from a mail server
- **Authentication:** Username and Password
- **Main Commands:** `USER`, `PASS`, `STAT`, `LIST`, `RETR`, `DELE`, `QUIT`
- **Security:** Plain POP3 is **not encrypted**; use **POP3S** for secure communication.

> **Interview Tip:** Remember the difference:
>
> - **SMTP → Sending emails**
> - **POP3 → Receiving/downloading emails**
> - **IMAP → Receiving and synchronizing emails across multiple devices**
