# DNS (Domain Name System)

## What is DNS?

**DNS (Domain Name System)** is like the **phonebook of the Internet**.

Instead of remembering IP addresses like:

```
93.184.215.14
```

you simply remember domain names like:

```
www.example.com
```

DNS translates (resolves) the domain name into its corresponding IP address.

### Real-Life Example

Imagine you want to call your friend.

You search for **"John"** in your phone contacts instead of memorizing his phone number.

Similarly:

- **Domain Name** = Contact Name
- **IP Address** = Phone Number
- **DNS** = Phone Contacts

---

# Why Do We Need DNS?

Computers communicate using **IP addresses**, not names.

Humans find names much easier to remember.

Without DNS:

```
https://www.google.com
```

would become something like:

```
http://142.250.190.14
```

You would have to remember the IP address of every website.

---

# OSI Layer

DNS operates at the:

**Application Layer (Layer 7)**

---

# Ports Used by DNS

| Protocol | Port | Purpose |
|----------|------|---------|
| UDP | 53 | Default DNS queries |
| TCP | 53 | Used when UDP cannot be used (fallback) |

### Why UDP?

DNS queries are usually:

- Small
- Fast
- Do not require a connection

So UDP is preferred.

### Why TCP?

TCP is used when:

- DNS response is too large.
- Zone transfers occur between DNS servers.
- UDP fails.

# Common DNS Records

DNS stores different types of records.

The four most common are:

---

## 1. A Record (Address Record)

Maps a **domain name** to an **IPv4 address**.

### Example

```text
example.com
        ↓
172.17.2.172
```

Whenever you visit:

```
www.example.com
```

your browser asks the DNS server:

> "What is the IPv4 address of this website?"

The DNS server replies with the A record.

---

## 2. AAAA Record (Quad-A Record)

Maps a **domain name** to an **IPv6 address**.

### Example

```text
example.com
       ↓
2606:2800:21f:cb07:6820:80da:af6b:8b2c
```

### Important

It is pronounced:

> **Quad-A**

Not:

- AA
- AAA

---

## 3. CNAME Record (Canonical Name)

Maps one domain name to another domain name.

### Example

```text
www.example.com
        ↓
example.com
```

Or

```text
shop.example.com
        ↓
store.example.org
```

Instead of storing multiple IP addresses, one domain simply points to another.

---

## 4. MX Record (Mail Exchange)

Specifies which mail server handles emails for a domain.

### Example

When sending an email to:

```
john@example.com
```

The mail server asks DNS:

> "Which mail server is responsible for example.com?"

DNS replies with the MX record.

---

# DNS Query Example

Suppose you type:

```
www.example.com
```

into your browser.

The browser sends a DNS query asking for the **A Record**.

DNS replies:

```
93.184.215.14
```

Now your browser knows where the website is located.

---

# Using nslookup

You can manually query DNS using:

```bash
nslookup www.example.com
```

Example output:

```text
Server: 127.0.0.53
Address: 127.0.0.53#53

Non-authoritative answer:

Name: www.example.com
Address: 93.184.215.14

Name: www.example.com
Address: 2606:2800:21f:cb07:6820:80da:af6b:8b2c
```

---

# Understanding the Output

```text
Server: 127.0.0.53
```

This is the DNS server that answered your request.

---

```text
Address: 93.184.215.14
```

This is the **IPv4 address** (A Record).

---

```text
Address: 2606:2800:...
```

This is the **IPv6 address** (AAAA Record).

---

# Real-Life Analogy

Suppose you want to visit a friend.

You know their name:

```
John
```

but not their address.

You ask someone:

> "Where does John live?"

They reply:

```
123 Main Street
```

- Person Giving Address → DNS Server

# Key Points to Remember

- DNS stands for **Domain Name System**.
- DNS converts **domain names into IP addresses**.
- DNS works at the **Application Layer (Layer 7)**.
- DNS normally uses **UDP port 53**.
- DNS uses **TCP port 53** when UDP is not suitable.
- **A Record** maps a domain to an **IPv4 address**.
- **AAAA Record** maps a domain to an **IPv6 address**.
- **CNAME Record** maps one domain name to another domain name.
- **MX Record** tells email servers where to deliver emails.
- You can query DNS manually using:

```bash
nslookup domain_name
```

Example:

```bash
nslookup www.example.com
```
