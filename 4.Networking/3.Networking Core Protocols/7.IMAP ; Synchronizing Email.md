# IMAP (Internet Message Access Protocol)

## What is IMAP?

**IMAP (Internet Message Access Protocol)** is an application layer protocol used to **access and synchronize emails** between a mail server and multiple devices.

Unlike **POP3**, which usually downloads emails to a single device, **IMAP keeps emails on the server**, allowing all your devices to stay synchronized.

### Simple Analogy

Imagine your email inbox is a cloud-based notebook:

- 📱 Read an email on your phone → It appears as **read** on your laptop.
- 💻 Delete an email on your computer → It is **deleted** on your tablet too.
- 📂 Move an email to another folder → The change appears on every connected device.

This synchronization is what makes IMAP different from POP3.

---

# Default Port

| Protocol | Default Port | Transport Protocol |
|----------|-------------:|-------------------|
| IMAP | **143** | TCP |

> **Secure IMAP (IMAPS)** uses **TCP port 993**.

---

# Why Use IMAP?

IMAP is ideal when you:

- Access email from multiple devices.
- Want emails to remain stored on the mail server.
- Need folders, read status, and deleted messages to stay synchronized.
- Prefer cloud-based email management.

---

# How IMAP Works

1. The email client connects to the IMAP server.
2. The user logs in.
3. The client selects a mailbox (Inbox, Sent, Drafts, etc.).
4. The client retrieves the required emails.
5. Any changes (read, move, delete) are synchronized with the server.
6. The session is closed.

---

# Common IMAP Commands

| Command | Purpose |
|----------|---------|
| `LOGIN <username> <password>` | Authenticates the user |
| `SELECT <mailbox>` | Opens a mailbox (e.g., Inbox) |
| `FETCH <mail_number> <data_item>` | Retrieves an email |
| `MOVE <sequence_set> <mailbox>` | Moves emails to another folder |
| `COPY <sequence_set> <mailbox>` | Copies emails to another folder |
| `LOGOUT` | Ends the IMAP session |

# Example IMAP Session

```bash
telnet MACHINE_IP 143
```

Example commands:

```text
LOGIN linda Pa$$123
SELECT inbox
FETCH 3 body[]
LOGOUT
```

Example session:

```text
LOGIN linda Pa$$123

```

The server returns the complete contents of email **#3**.

# IMAP vs POP3

| Feature | IMAP | POP3 |
|---------|------|------|
| Default Port | 143 | 110 |
| Transport Protocol | TCP | TCP |
| Stores emails on server | ✅ Yes | ❌ Usually No |
| Supports multiple devices | ✅ Yes | ❌ Limited |
| Synchronizes changes | ✅ Yes | ❌ No |
| Offline access | Limited (unless cached) | Excellent (emails downloaded locally) |
| Best For | Multiple devices | Single device |

---

# Advantages of IMAP

- Synchronizes emails across all devices.
- Keeps emails safely stored on the server.
- Supports multiple folders (Inbox, Sent, Drafts, Trash, etc.).
- Synchronizes:
  - Read/Unread status
  - Deleted emails
  - Moved emails
  - Flags and labels
- Perfect for smartphones, tablets, and laptops used together.

---

# Disadvantages

- Uses more server storage because emails remain on the server.
- Requires an internet connection for full synchronization.
- More complex than POP3.

# Quick Revision

- **Full Form:** Internet Message Access Protocol (IMAP)
- **OSI Layer:** Application Layer (Layer 7)
- **Transport Protocol:** TCP
- **Default Port:** **143**
- **Secure Port (IMAPS):** **993**
- **Purpose:** Access and synchronize emails across multiple devices.
- **Main Commands:** `LOGIN`, `SELECT`, `FETCH`, `MOVE`, `COPY`, `LOGOUT`
- **Stores Emails:** On the **mail server**
- **Best For:** Users who check email from multiple devices.

# POP3 vs IMAP (Interview Tip)

| POP3 | IMAP |
|------|------|
| Downloads emails | Synchronizes emails |
| Best for one device | Best for multiple devices |
| Emails usually removed from server | Emails remain on server |
| Simpler | More feature-rich |
| Less server storage | More server storage |

>
> - **SMTP** → Send emails 📤
