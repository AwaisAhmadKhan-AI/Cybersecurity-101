# SMTP (Simple Mail Transfer Protocol)

## What is SMTP?

**SMTP (Simple Mail Transfer Protocol)** is the standard protocol used to **send emails** over a network. It defines how:

- An email client (such as Outlook or Thunderbird) sends an email to a mail server.
- One mail server forwards emails to another mail server.

> **Note:** SMTP is used only for **sending** emails. Retrieving emails is handled by protocols like **POP3** or **IMAP**.

---

# Real-World Analogy

Think of SMTP like sending a parcel through a post office:

1. You identify yourself.
2. You provide the sender's address.
3. You provide the recipient's address.
4. You hand over the package.
5. The post office delivers it.

SMTP follows a very similar process when sending emails.

---

# Default Port

- **TCP Port:** `25`

> Modern email services may also use **587** (submission) or **465** (SMTPS), but **25** is the traditional SMTP port.

---

# Common SMTP Commands

## HELO / EHLO

Starts the SMTP session and introduces the client to the mail server.

**Example:**

```text
HELO client.example.com
```

or

```text
EHLO client.example.com
```

> `EHLO` is the newer version and supports additional SMTP features.

---

## MAIL FROM

Specifies the sender's email address.

**Example:**

```text
MAIL FROM:<alice@example.com>
```

---

## RCPT TO

Specifies the recipient's email address.

**Example:**

```text
RCPT TO:<bob@example.com>
```

---

## DATA

Tells the server that the email content is about to be sent.

After this command, you can write:

- Sender
- Recipient
- Subject
- Message body

Example:

```text
DATA
From: alice@example.com
To: bob@example.com
Subject: Hello

Hi Bob!
How are you?
```

---

## .

A single period (`.`) on its own line tells the server that the email has finished.

Example:

```text
.
```

---

# Basic SMTP Workflow

```text
Client
   │
   ├── HELO / EHLO
   │
   ├── MAIL FROM
   │
   ├── RCPT TO
   │
   ├── DATA
   │
   ├── Email Content
   │
   ├── .
   │
   └── QUIT
```

# Example SMTP Session

```text
telnet <server-ip> 25

220 mail.example.com ESMTP

HELO client.example.com
250 OK

MAIL FROM:<alice@example.com>
250 OK

RCPT TO:<bob@example.com>
250 OK

DATA
354 Enter message

From: alice@example.com
To: bob@example.com
Subject: Test Email

Hello Bob!
This is a test email.

.
250 Message accepted

QUIT
221 Connection closed
```

# SMTP in Wireshark

When capturing SMTP traffic in Wireshark, you will typically see:

- Client commands (HELO, MAIL FROM, RCPT TO, DATA)
- Server responses (220, 250, 354, etc.)
- The email content being transmitted
- The session ending with `QUIT`

This makes SMTP relatively easy to analyze because it is a **text-based protocol**.

---

# Key Points

- SMTP stands for **Simple Mail Transfer Protocol**.
- Used to **send emails** between clients and mail servers.
- Uses **TCP** for reliable communication.
- Default port is **25**.
- Main commands include:
  - `HELO` / `EHLO`
  - `MAIL FROM`
  - `RCPT TO`
  - `DATA`
  - `.`
  - `QUIT`
- Email retrieval is performed by **POP3** or **IMAP**, not SMTP.
- SMTP is a **text-based protocol**, making it easy to inspect using tools like **Telnet** or **Wireshark**.

# Quick Revision

| Command | Purpose |
|----------|---------|
| **HELO / EHLO** | Starts the SMTP session |
| **MAIL FROM** | Specifies the sender's email address |
| **RCPT TO** | Specifies the recipient's email address |
| **DATA** | Begins sending the email content |
| **.** | Marks the end of the email message |
| **QUIT** | Ends the SMTP session |

# Interview Tips

### Q1: What is SMTP?

**Answer:**
SMTP (Simple Mail Transfer Protocol) is a protocol used to send emails between email clients and mail servers or between mail servers.

---

### Q2: Which port does SMTP use?

**Answer:**
By default, SMTP uses **TCP port 25**.

---

### Q3: Is SMTP used to receive emails?

**Answer:**
No. SMTP is used only for **sending** emails. **POP3** and **IMAP** are used to receive emails.

---

### Q4: Why does SMTP use TCP instead of UDP?

**Answer:**
SMTP uses **TCP** because email delivery must be reliable. TCP guarantees packet delivery, maintains the correct order, and retransmits lost packets if necessary.

---

### Q5: What does the DATA command do?

**Answer:**
The `DATA` command tells the SMTP server that the client is about to send the email's content, including the headers and message body.
