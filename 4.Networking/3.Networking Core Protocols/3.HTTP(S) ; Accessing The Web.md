# HTTP and HTTPS

## What are HTTP and HTTPS?

**HTTP (Hypertext Transfer Protocol)** is the protocol used by web browsers and web servers to exchange web content such as HTML pages, images, videos, and other resources.

**HTTPS (Hypertext Transfer Protocol Secure)** is the secure version of HTTP. It encrypts communication between the client and the server using **TLS (Transport Layer Security)**, protecting sensitive information from being intercepted or modified.

> **Simple Explanation:**  
> - **HTTP** = Transfers web data.
> - **HTTPS** = Transfers web data securely through encryption.

---

# How HTTP Works

When you enter a website address into your browser:

1. Your browser sends an **HTTP request** to the web server.
2. The server processes the request.
3. The server sends back an **HTTP response**.
4. Your browser displays the webpage.

Example:

```text
Browser ── HTTP Request ──► Web Server
Browser ◄── HTTP Response ── Web Server
```

---

# HTTP vs HTTPS

| HTTP | HTTPS |
|------|--------|
| Hypertext Transfer Protocol | Hypertext Transfer Protocol Secure |
| Data is sent in plain text. | Data is encrypted using TLS. |
| Less secure. | Highly secure. |
| Default port: **80** | Default port: **443** |

---

# Common HTTP Methods

HTTP uses different **methods (or verbs)** to tell the server what action should be performed.

## 1. GET

Retrieves data from the server.

Common uses:

- Open a webpage
- Download an image
- Retrieve a file

Example:

```http
GET /index.html HTTP/1.1
```

---

## 2. POST

Sends new data to the server.

Common uses:

- Submit a login form
- Upload a file
- Create a new record

Example:

```http
POST /login HTTP/1.1
```

---

## 3. PUT

Creates a new resource or completely replaces an existing one.

Common uses:

- Update user information
- Replace stored data

Example:

```http
PUT /users/15 HTTP/1.1
```

---

## 4. DELETE

Removes a resource from the server.

Example:

```http
DELETE /users/15 HTTP/1.1
```

---

# Common Ports

| Protocol | Default Port |
|----------|-------------:|
| HTTP | **80** |
| HTTPS | **443** |

Other ports that may be used:

- **8080** (alternative HTTP)
- **8443** (alternative HTTPS)

# HTTP Communication

Every time you visit a website, your browser and the server exchange two things:

## HTTP Request

Sent by the client (browser).

It contains information such as:

- HTTP method (GET, POST, etc.)
- Requested file or page
- HTTP version
- Host name
- Other request headers

Example:

```http
GET / HTTP/1.1
Host: example.com
```

---

## HTTP Response

Sent by the server.

It contains:

- Status code
- Response headers
- Requested content (HTML, image, JSON, etc.)

Example:

```http
HTTP/1.1 200 OK
Content-Type: text/html

<html>
...
</html>
```

---

# Common HTTP Status Codes

| Code | Meaning |
|------|----------|
| **200 OK** | Request completed successfully. |
| **301 Moved Permanently** | Resource has been permanently moved. |
| **302 Found** | Temporary redirect. |
| **403 Forbidden** | Access denied. |
| **404 Not Found** | Requested resource does not exist. |
| **500 Internal Server Error** | Server encountered an error. |

# Viewing HTTP Traffic

Tools like **Wireshark** can capture HTTP traffic between a browser and a web server.

Captured traffic may include:

- Request method
- Requested URL
- HTTP headers
- Server software
- Content type
- Response status code
- Last modification time

This information is valuable when troubleshooting web applications or analyzing network traffic.

---

# Accessing a Web Server Manually

Since HTTP is a text-based protocol, you can communicate directly with a web server using tools like **Telnet** or **Netcat**.

Example:

```bash
telnet example.com 80
```

After connecting, send:

```http
GET / HTTP/1.1
Host: example.com
```

Press **Enter** twice to send the request.

The server responds with the webpage and HTTP headers.

To request a specific file:

```http
GET /file.html HTTP/1.1
Host: example.com
```

This method is useful for:

- Troubleshooting
- Learning how HTTP works
- Testing web servers manually

---

# Why HTTPS is Preferred

HTTPS protects communication by encrypting all transmitted data.

Benefits include:

- Protects usernames and passwords
- Secures payment information
- Prevents data interception
- Prevents attackers from modifying transmitted data
- Verifies the identity of the web server through digital certificates

Most modern websites use HTTPS by default.
