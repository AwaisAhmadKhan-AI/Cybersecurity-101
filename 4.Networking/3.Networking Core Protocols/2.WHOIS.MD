# WHOIS

## What is WHOIS?

**WHOIS** is a protocol and lookup service that provides information about the registration of a domain name. It allows you to find out **who owns a domain**, **when it was registered**, **when it expires**, and **which registrar manages it**.

When someone registers a domain (such as `example.com`), they gain the authority to manage its DNS records (A, AAAA, MX, CNAME, etc.) and control how the domain behaves on the Internet.

> **Think of it this way:**  
> - **DNS** tells you **where** a domain points (its IP address).  
> - **WHOIS** tells you **who** registered and manages that domain.

---

# Why WHOIS is Important

WHOIS is widely used by:

- Security researchers
- Penetration testers
- Incident responders
- System administrators

It helps during **reconnaissance (information gathering)** by revealing publicly available registration details about a domain.

Common uses include:

- Identifying the domain owner
- Finding the domain registrar
- Checking when a domain was created
- Verifying expiration dates
- Investigating suspicious or malicious websites

---

# Domain Registration

Before a domain can be used on the Internet, it must be registered through a **domain registrar**.

During registration, the owner typically provides:

- Full name
- Organization (optional)
- Email address
- Phone number
- Physical address

This information is stored in the WHOIS database unless privacy protection is enabled.

> Domain registration usually requires paying a registration fee and renewing the domain periodically (often every year).

---

# Information Available in a WHOIS Record

A WHOIS lookup may include:

- Domain name
- Domain status
- Registrar
- Creation date
- Last updated date
- Expiration date
- Registrant name
- Organization
- Email address
- Phone number
- Physical address
- Name servers

---

# WHOIS Privacy Protection

Many domain owners choose to hide their personal information using **WHOIS Privacy Protection**.

Instead of displaying the owner's real details, the WHOIS record shows information from a privacy service.

Example:

Without privacy protection:

```text
Registrant Name: John Smith
Email: john@example.com
Phone: +1xxxxxxxxxx
```

With privacy protection:

```text
Registrant Name: Registration Private
Registrant Organization: Privacy Protection Service
```

This protects the owner's personal information from being publicly accessible.

---

# Using the `whois` Command

Most Linux distributions provide the **whois** command for performing domain lookups.

### Basic Syntax

```bash
whois domain_name
```

### Example

```bash
whois example.com
```

---

# Example WHOIS Output

```text
Domain Name: EXAMPLE.COM

Registrar: Example Registrar

Creation Date: 1993-04-02

Updated Date: 2024-01-15

Registry Expiry Date: 2027-04-02

Registrant Name: Registration Private

Registrant Organization: Privacy Protection Service
```

---

# Understanding Common Fields

| Field | Description |
|--------|-------------|
| **Domain Name** | The registered domain. |
| **Registrar** | The company through which the domain was registered. |
| **Creation Date** | When the domain was first registered. |
| **Updated Date** | The last time the registration details were modified. |
| **Expiry Date** | When the registration expires unless renewed. |
| **Registrant Name** | The owner of the domain (or privacy service). |
| **Registrant Organization** | Organization that owns the domain, if applicable. |

---

# WHOIS vs DNS

| WHOIS | DNS |
|--------|-----|
| Provides domain ownership information. | Converts domain names into IP addresses. |
| Used for registration lookups. | Used for locating servers on the Internet. |
| Shows registrar, owner, and registration dates. | Returns records like A, AAAA, MX, and CNAME. |
| Helpful during reconnaissance. | Essential for normal Internet communication. |

---

# Security Perspective

During reconnaissance, cybersecurity professionals often perform a WHOIS lookup to:

- Discover domain ownership
- Identify the hosting or registrar
- Check how old a domain is
- Investigate suspicious infrastructure
- Gather publicly available intelligence before further analysis

Keep in mind that WHOIS data alone does **not** confirm malicious activity—it simply provides registration information that can support an investigation.

# Interview Questions

### What is WHOIS?

**Answer:**

WHOIS is a protocol and lookup service used to retrieve registration information about a domain name, including the registrar, owner (if public), creation date, expiration date, and contact details.

---

### What information does a WHOIS record contain?

It may include:

- Domain name
- Registrar
- Creation date
- Expiration date
- Updated date
- Registrant details
- Name servers

---

### Why is WHOIS useful in cybersecurity?

WHOIS helps security professionals gather publicly available information about a domain during reconnaissance, such as ownership details, registration dates, and registrar information.

---

### What is WHOIS Privacy Protection?

WHOIS Privacy Protection hides the domain owner's personal information by replacing it with details from a privacy protection service.
