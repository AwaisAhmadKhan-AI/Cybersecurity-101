# Version Detection (Extract More Information)

After discovering **live hosts** and **open ports**, the next step is gathering more information about the target, such as:

- Operating System (OS)
- Running services
- Service versions

---

# OS Detection (`-O`)

The `-O` option attempts to identify the **target's operating system**.

Nmap analyzes various network characteristics (such as TCP/IP behavior) and makes its **best guess** about the OS.

> **Note:** OS detection is **not 100% accurate**. It provides an educated guess based on the target's responses.

## Syntax

```bash
nmap -O <target>
```

### Example

```bash
nmap -sS -O 192.168.124.211
```

### Example Output

```
Running: Linux 4.X|5.X
OS details: Linux 4.15 - 5.8
```

This means Nmap believes the target is running a Linux kernel between versions **4.15 and 5.8**.

---

# Service & Version Detection (`-sV`)

The `-sV` option identifies:

- Running service
- Software name
- Software version
- Sometimes the operating system

This helps determine exactly **what software is running** on an open port.

## Syntax

```bash
nmap -sV <target>
```

### Example

```bash
nmap -sS -sV 192.168.124.211
```

### Example Output

```
PORT   STATE SERVICE VERSION
22/tcp open  ssh     OpenSSH 8.9p1 Ubuntu 3ubuntu0.10
```

From this output we learn:

- Port **22** is open.
- The service is **SSH**.
- The software is **OpenSSH**.
- The version is **8.9p1** running on Ubuntu.

This information is useful for identifying outdated software and known vulnerabilities.

---

# Aggressive Scan (`-A`)

Instead of using multiple options separately, Nmap provides the **Aggressive Scan** option.

The `-A` flag enables several advanced detection features at once.

It includes:

- OS Detection (`-O`)
- Service & Version Detection (`-sV`)
- Traceroute
- Default NSE (Nmap Scripting Engine) scripts

## Syntax

```bash
nmap -A <target>
```

### Example

```bash
nmap -A 192.168.124.211
```

Use this when you want to gather **as much information as possible** with a single command.

> **Note:** Since it performs several scans, it generates **more network traffic** and is easier to detect than basic scans.

---

# Force Scanning a Host (`-Pn`)

Normally, Nmap first performs **host discovery** (ping scan).

If the target **does not respond** to host discovery probes (such as ICMP Echo Requests), Nmap assumes the host is **down** and skips the port scan.

The `-Pn` option tells Nmap:

> "Assume the host is online and scan it anyway."

This is useful when:

- ICMP is blocked by a firewall.
- The target ignores ping requests.
- Host discovery fails even though the system is actually online.

## Syntax

```bash
nmap -Pn <target>
```

### Example

```bash
nmap -Pn 192.168.124.211
```

Nmap skips the host discovery phase and directly scans the ports.

---

# Summary

| Option | Description |
|---------|-------------|
| `-O` | Detect the target operating system |
| `-sV` | Detect running services and their versions |
| `-A` | Enables OS detection, version detection, traceroute, and default NSE scripts |
| `-Pn` | Skip host discovery and assume the target is online |

---

# Common Examples

```bash
# Detect the operating system
nmap -O 192.168.1.10

# Detect service versions
nmap -sV 192.168.1.10

# SYN scan with version detection
nmap -sS -sV 192.168.1.10

# Aggressive scan
nmap -A 192.168.1.10

# Scan a host even if it doesn't respond to ping
nmap -Pn 192.168.1.10
```
