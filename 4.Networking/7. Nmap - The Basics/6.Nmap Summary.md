# Nmap Summary

Nmap is a powerful network scanning tool used to:

- Discover live hosts.
- Find open TCP/UDP ports.
- Detect running services and their versions.
- Identify the target operating system.
- Control scan speed.
- Save scan results in different formats.

> **Note:** For full functionality, run Nmap with **`sudo`** or as the **root** user. Some scan types (such as SYN scans) require root privileges.

---

# Why Run Nmap with `sudo`?

Running Nmap as a normal user limits some advanced features.

For example:

- **With `sudo`** → Nmap can perform **SYN scans (`-sS`)**.
- **Without `sudo`** → Nmap automatically falls back to **TCP Connect scans (`-sT`)**.

This happens because creating raw TCP packets requires root privileges.

# Quick Reference

## Host Discovery

| Option | Description |
|---------|-------------|
| `-sL` | List targets without scanning |
| `-sn` | Discover live hosts only (Ping Scan) |

---

## Port Scanning

| Option | Description |
|---------|-------------|
| `-sT` | TCP Connect Scan (completes three-way handshake) |
| `-sS` | TCP SYN (Stealth) Scan |
| `-sU` | UDP Scan |
| `-F` | Scan the 100 most common ports |
| `-p<range>` | Scan specific port(s) or ranges (`-p-` scans all 65,535 ports) |
| `-Pn` | Treat all hosts as online and skip host discovery |

---

## Service Detection

| Option | Description |
|---------|-------------|
| `-O` | Detect the operating system |
| `-sV` | Detect running services and software versions |
| `-A` | Aggressive scan (OS detection, version detection, traceroute, default NSE scripts) |

---

## Timing

| Option | Description |
|---------|-------------|
| `-T0` | Paranoid (slowest) |
| `-T1` | Sneaky |
| `-T2` | Polite |
| `-T3` | Normal (default) |
| `-T4` | Aggressive |
| `-T5` | Insane (fastest) |
| `--min-parallelism <num>` | Minimum number of parallel probes |
| `--max-parallelism <num>` | Maximum number of parallel probes |
| `--min-rate <num>` | Minimum packets per second |
| `--max-rate <num>` | Maximum packets per second |
| `--host-timeout <time>` | Maximum time to wait for a host |

---

## Real-Time Output

| Option | Description |
|---------|-------------|
| `-v` | Enable verbose output |
| `-vv`, `-vvvv` | Increase verbosity |
| `-d` | Enable debug output |
| `-d9` | Maximum debugging level |

---

## Saving Scan Results

| Option | Description |
|---------|-------------|
| `-oN <file>` | Save normal (human-readable) output |
| `-oX <file>` | Save XML output |
| `-oG <file>` | Save grepable output |
| `-oA <basename>` | Save all output formats (`.nmap`, `.xml`, `.gnmap`) |

---

# Common Examples

```bash
# Discover live hosts
nmap -sn 192.168.1.0/24

# SYN scan
sudo nmap -sS 192.168.1.10

# UDP scan
sudo nmap -sU 192.168.1.10

# Scan all ports
sudo nmap -p- 192.168.1.10

# Detect service versions
sudo nmap -sV 192.168.1.10

# Detect operating system
sudo nmap -O 192.168.1.10

# Aggressive scan
sudo nmap -A 192.168.1.10

# Skip host discovery
sudo nmap -Pn 192.168.1.10

# Aggressive timing
sudo nmap -T4 192.168.1.10

# Save all output formats
sudo nmap -oA scan 192.168.1.10
```

---

# Key Takeaways

- Always start with **host discovery** (`-sn`) to identify live systems.
- Use **SYN scans (`-sS`)** for faster and relatively stealthier TCP scanning.
- Use **UDP scans (`-sU`)** to detect UDP services like DNS and NTP.
- Use **`-sV`** to identify service versions and **`-O`** to detect the operating system.
- Use **`-A`** when you want to gather comprehensive information in a single scan.
- Adjust scan speed using **`-T0` to `-T5`** based on your requirements.
- Save scan results using **`-oN`**, **`-oX`**, **`-oG`**, or **`-oA`** for future analysis.
- Run Nmap with **`sudo`** whenever possible to access its full set of features.
