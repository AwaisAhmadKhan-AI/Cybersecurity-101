# Nmap – Host Discovery (Who Is Online)

## Host Discovery

Host discovery is the process of identifying which devices (hosts) are currently **online (alive)** on a network before scanning them for open ports or services.

Nmap provides the **`-sn` (Ping Scan)** option to discover live hosts **without performing a port scan**.

### Syntax
```bash
nmap -sn <target>
```

---

# Ways to Specify Targets

## 1. IP Range (`-`)

Scan a range of IP addresses.

### Example
```bash
nmap -sn 192.168.0.1-10
```

Scans:
- 192.168.0.1
- 192.168.0.2
- ...
- 192.168.0.10

---

## 2. IP Subnet (`/`)

Scan an entire subnet.

### Example
```bash
nmap -sn 192.168.0.1/24
```

Equivalent to:

```text
192.168.0.0 - 192.168.0.255
```

Scans all 256 IP addresses in the subnet.

---

## 3. Hostname

You can scan using a hostname instead of an IP address.

### Example

```bash
nmap -sn example.thm
```

---

# Ping Scan (`-sn`)

The `-sn` option tells Nmap:

- Discover which hosts are online.
- Do **not** perform a port scan.
- Faster and less noisy than full scans.

### Example

```bash
sudo nmap -sn 192.168.66.0/24
```

Possible output:

```text
Host is up.
MAC Address: 44:DF:65:D8:FE:6C
```

---

# Scanning a Local Network

A **local network** is a network directly connected to your computer, such as:

- Ethernet
- Wi-Fi

Example:

```bash
sudo nmap -sn 192.168.66.0/24
```

### How Nmap Detects Hosts

On a local network, Nmap sends:

- **ARP Requests**

If a device replies to the ARP request, Nmap marks it as:

```text
Host is up
```

---

## Why MAC Addresses Are Shown

Since devices are on the same local network, Nmap can also discover:

- MAC Address
- Network card manufacturer (Vendor)

Example:

```text
MAC Address: 7C:DF:A1:D3:8C:5C (Espressif)
```

This helps identify the type of device, such as:

- Router
- Laptop
- Smart TV
- IoT device
- Printer

---

# Scanning a Remote Network

A **remote network** is separated from your computer by one or more routers.

Example:

```bash
sudo nmap -sn 192.168.11.0/24
```

Since ARP only works on the local network, Nmap uses other techniques.

---

## How Nmap Detects Remote Hosts

Nmap sends multiple probes, such as:

- ICMP Echo Request (Ping)
- ICMP Timestamp Request
- TCP SYN packets (commonly to port 443)
- TCP ACK packets (commonly to port 80)

If the target responds, Nmap marks it as:

```text
Host is up
```

If there is no response, the host is considered down or filtered.

---

# Example

```bash
sudo nmap -sn 192.168.11.0/24
```

Output:

```text
Host is up
Host is up
Host is up

Nmap done: 256 IP addresses (5 hosts up)
```

This means:

- Total IPs scanned: **256**
- Online devices found: **5**

---

# Advanced Host Discovery Options

Nmap provides additional host discovery methods:

| Option | Purpose |
|---------|----------|
| `-PS[ports]` | TCP SYN Ping |
| `-PA[ports]` | TCP ACK Ping |
| `-PU[ports]` | UDP Ping |

These allow more control over how Nmap checks whether a host is alive.

---

# List Scan (`-sL`)

The **List Scan** only displays the targets that would be scanned.

It **does not send any packets** to the targets.

### Syntax

```bash
nmap -sL <target>
```

### Example

```bash
nmap -sL 192.168.0.1/24
```

Output:

```text
Nmap scan report for 192.168.0.0
Nmap scan report for 192.168.0.1
Nmap scan report for 192.168.0.2
...
```

**Use Case**

- Verify target IP addresses before starting a scan.
- Safe because no actual scanning occurs.

# Common Commands

### Discover live hosts on a subnet

```bash
sudo nmap -sn 192.168.1.0/24
```

---

### Discover a range of hosts

```bash
sudo nmap -sn 192.168.1.10-20
```

---

### Discover a single host

```bash
sudo nmap -sn 192.168.1.50
```

---

### Scan using a hostname

```bash
sudo nmap -sn example.thm
```

---

### List targets without scanning

```bash
nmap -sL 192.168.1.0/24
```

---

# Key Points

- Host discovery identifies which devices are currently online.
- `-sn` performs a **Ping Scan** without scanning ports.
- Targets can be specified using an IP range, subnet, or hostname.
- On a **local network**, Nmap uses **ARP Requests** to discover hosts.
- On a **remote network**, Nmap uses probes such as **ICMP**, **TCP SYN**, and **TCP ACK**.
- Local scans can reveal **MAC addresses** and **device vendors**.
- `-sL` lists scan targets without sending any packets.
- Host discovery is often the first step before performing service or port scans.
