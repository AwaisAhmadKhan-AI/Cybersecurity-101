# Output (Controlling What You See)

Nmap provides options to:

- Display more information while a scan is running.
- Save scan results in different file formats.

---

# Verbose Output (`-v`)

By default, Nmap displays only the final scan results.

The `-v` option (**verbose mode**) shows additional information during the scan, such as:

- Scan progress
- Current scan phase
- Hosts being scanned
- Open ports discovered
- Packet statistics

This is useful when:

- The scan takes a long time.
- You want to monitor the scan in real time.
- You are learning how Nmap works.

## Syntax

```bash
nmap -v <target>
```

### Example

```bash
nmap -v 192.168.1.0/24
```

---

## Increase Verbosity

You can make Nmap even more verbose.

### Examples

```bash
nmap -vv 192.168.1.10
```

```bash
nmap -vvvv 192.168.1.10
```

Or specify the level directly:

```bash
nmap -v2 192.168.1.10
```

```bash
nmap -v4 192.168.1.10
```

> **Tip:** While a scan is running, press **`v`** to increase the verbosity level without restarting the scan.

---

# Debugging (`-d`)

Debug mode displays **internal debugging information** about how Nmap performs the scan.

It is mainly used for:

- Troubleshooting
- Understanding Nmap's internal behavior
- Advanced users and developers

## Syntax

```bash
nmap -d <target>
```

### Increase Debug Level

```bash
nmap -dd 192.168.1.10
```

```bash
nmap -d4 192.168.1.10
```

Maximum debug level:

```bash
-d9
```

> **Note:** Higher debug levels produce a large amount of output.

---

# Saving Scan Results

Instead of viewing the results only on the terminal, you can save them to a file.

---

## Normal Output (`-oN`)

Saves the scan in a human-readable format.

### Syntax

```bash
nmap -oN <filename> <target>
```

### Example

```bash
nmap -oN scan.txt 192.168.1.10
```

---

## XML Output (`-oX`)

Saves the results in XML format.

Useful for:

- Automation
- Scripts
- Other security tools

### Syntax

```bash
nmap -oX <filename> <target>
```

### Example

```bash
nmap -oX scan.xml 192.168.1.10
```

---

## Grepable Output (`-oG`)

Saves the results in a format suitable for tools like:

- `grep`
- `awk`

This makes it easier to search and process scan results.

### Syntax

```bash
nmap -oG <filename> <target>
```

### Example

```bash
nmap -oG scan.gnmap 192.168.1.10
```

---

## Save in All Formats (`-oA`)

Creates all major output formats at once.

Generated files:

- `.nmap` → Normal output
- `.xml` → XML output
- `.gnmap` → Grepable output

### Syntax

```bash
nmap -oA <basename> <target>
```

### Example

```bash
nmap -oA gateway 192.168.1.10
```

Generated files:

```
gateway.nmap
gateway.xml
gateway.gnmap
```

---

# Summary

| Option | Description |
|---------|-------------|
| `-v` | Enable verbose output |
| `-vv`, `-vvvv` | Increase verbosity |
| `-v2`, `-v4` | Specify verbosity level directly |
| `-d` | Enable debug output |
| `-dd`, `-d4`, `-d9` | Increase debug level |
| `-oN <file>` | Save normal (human-readable) output |
| `-oX <file>` | Save XML output |
| `-oG <file>` | Save grepable output |
| `-oA <basename>` | Save output in all major formats |

---

# Common Examples

```bash
# Verbose scan
nmap -v 192.168.1.10

# Highly verbose scan
nmap -vv 192.168.1.10

# Enable debugging
nmap -d 192.168.1.10

# Save normal output
nmap -oN scan.txt 192.168.1.10

# Save XML output
nmap -oX scan.xml 192.168.1.10

# Save grepable output
nmap -oG scan.gnmap 192.168.1.10

# Save all output formats
nmap -oA fullscan 192.168.1.10
```
