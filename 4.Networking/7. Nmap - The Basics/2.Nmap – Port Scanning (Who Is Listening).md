# Nmap – Port Scanning (Who Is Listening)

## Port Scanning

After discovering which hosts are online, the next step is to identify **which network services are running** on those hosts.

A **network service** is any application that listens for incoming connections on a **TCP or UDP port**.

Examples:

| Service | Default Port |
|---------|-------------:|
| HTTP | TCP 80 |
| HTTPS | TCP 443 |
| SSH | TCP 22 |
| DNS | UDP/TCP 53 |

Since both TCP and UDP have **65,535 ports**, Nmap helps identify which ports are open.

---

# TCP Connect Scan (`-sT`)

A **TCP Connect Scan** attempts to complete the **entire TCP three-way handshake**.

### How It Works

1. Nmap sends a **SYN** packet.
2. If the port is open, the target replies with **SYN-ACK**.
3. Nmap sends **ACK**, completing the connection.
4. Nmap immediately closes the connection using **RST-ACK**.

If the port is closed, the target responds with **RST-ACK**.

### Syntax

```bash
nmap -sT <target>
```

### Example

```bash id="mt4w92"
sudo nmap -sT 192.168.1.10
```

### Advantages

- Reliable scan.
- Works without root privileges.

### Disadvantages

- Completes the TCP connection.
- Easier to detect and generates more logs.

---

# TCP SYN Scan (Stealth Scan) (`-sS`)

A **SYN Scan** is the most commonly used Nmap scan.

Instead of completing the TCP handshake, it only performs the **first step**.

### How It Works

1. Nmap sends a **SYN** packet.
2. If the port is open, the target replies with **SYN-ACK**.
3. Nmap immediately sends **RST**, terminating the connection.

The handshake is **never completed**.

If the port is closed, the target responds with **RST-ACK**.

### Syntax

```bash
nmap -sS <target>
```

### Example

```bash id="g5cz5h"
sudo nmap -sS 192.168.1.10
```

### Advantages

- Faster than Connect Scan.
- Generates fewer logs.
- Considered more stealthy.
- Most popular TCP scan.

### Disadvantages

- Usually requires root/administrator privileges.

---

# UDP Scan (`-sU`)

Many services use **UDP** instead of TCP.

Common UDP services include:

- DNS
- DHCP
- NTP
- SNMP
- VoIP

Since UDP is connectionless, there is **no three-way handshake**.

### How It Works

- Nmap sends a UDP packet.
- If the port is closed, the target usually replies with:
  - **ICMP Port Unreachable**
- If there is no response, the port may be:
  - Open
  - Filtered

### Syntax

```bash
nmap -sU <target>
```

### Example

```bash id="rfn1ot"
sudo nmap -sU 192.168.1.10
```

### Notes

- Slower than TCP scans.
- Less reliable because many UDP services do not respond.

---

# Limiting the Ports to Scan

By default, Nmap scans the **1,000 most common ports**.

You can customize which ports to scan.

---

## Fast Scan (`-F`)

Scans only the **100 most common ports**.

### Syntax

```bash
nmap -F <target>
```

### Example

```bash id="mfmjlwm"
sudo nmap -F 192.168.1.10
```

**Use Case**

- Faster scan.
- Good for quick reconnaissance.

---

## Scan a Port Range (`-p`)

Specify exactly which ports to scan.

### Scan ports 10–1024

```bash id="h5x2rb"
sudo nmap -p10-1024 192.168.1.10
```

---

### Scan ports 1–25

```bash id="m6ckf7"
sudo nmap -p-25 192.168.1.10
```

---

### Scan all ports

```bash id="c0bx3g"
sudo nmap -p- 192.168.1.10
```

Equivalent to:

```text
-p1-65535
```

This scans every TCP port.

---

## Scan Well-Known Ports

Well-known ports range from **1–1023**.

These are commonly used by standard network services.

### Example

```bash id="vulkgq"
sudo nmap -p1-1023 192.168.1.10
```

# Scan Types Summary

| Option | Purpose |
|---------|---------|
| `-sT` | TCP Connect Scan (completes three-way handshake) |
| `-sS` | TCP SYN Scan (Stealth Scan) |
| `-sU` | UDP Scan |
| `-F` | Scan the 100 most common ports |
| `-p<range>` | Scan a specific range of ports |
| `-p-` | Scan all 65,535 ports |

---

# Key Points

- Port scanning identifies which services are listening on a host.
- TCP and UDP each have **65,535 ports**.
- `-sT` performs a full TCP three-way handshake.
- `-sS` sends only a SYN packet, making it faster and more stealthy.
- `-sU` scans UDP services such as DNS, DHCP, and NTP.
- `-F` scans only the 100 most common ports for faster results.
- `-p<range>` lets you scan specific ports, while `-p-` scans every port.
- Ports **1–1023** are known as **well-known ports** and are commonly used by standard network services.
