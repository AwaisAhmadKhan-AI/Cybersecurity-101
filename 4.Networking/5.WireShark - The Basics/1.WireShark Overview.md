# Wireshark Overview

## What is Wireshark?

**Wireshark** is one of the most popular **network protocol analyzers** used to capture and inspect network traffic.

It helps analysts view packets in detail to understand how devices communicate over a network.

> **Note:** Wireshark is **not an Intrusion Detection System (IDS)**. It only captures and analyzes packets—it does **not** block, modify, or prevent network attacks.

---

# Common Use Cases

Wireshark is commonly used for:

- Troubleshooting network issues.
- Detecting suspicious or abnormal network traffic.
- Analyzing network protocols.
- Learning how network communication works.
- Investigating security incidents.

---

# Main Components of the Wireshark Interface

When Wireshark starts, its interface is divided into several sections.

| Component | Purpose |
|-----------|---------|
| **Toolbar** | Provides shortcuts for capturing, filtering, exporting, and managing packets. |
| **Display Filter Bar** | Filters displayed packets using search expressions. |
| **Recent Files** | Shows recently opened capture files (PCAPs). |
| **Capture Interfaces** | Lists available network interfaces for capturing traffic. |
| **Status Bar** | Displays capture status, selected interface, and packet statistics. |

---

# Loading a PCAP File

A **PCAP (Packet Capture)** file stores captured network traffic.

You can open a PCAP file by:

- **File → Open**
- Dragging and dropping the file into Wireshark.
- Double-clicking the PCAP file (if associated with Wireshark).

---

# Packet Analysis Panes

Once a PCAP file is loaded, Wireshark displays packet information in three main panes.

## 1. Packet List Pane

Displays a summary of every captured packet.

Information includes:

- Packet Number
- Time
- Source IP
- Destination IP
- Protocol
- Packet Information

Selecting a packet displays its detailed information below.

---

## 2. Packet Details Pane

Shows the protocol hierarchy and detailed information for the selected packet.

Examples:

- Ethernet Header
- IP Header
- TCP/UDP Header
- HTTP Data
- DNS Information

---

## 3. Packet Bytes Pane

Displays the raw packet data in:

- **Hexadecimal**
- **ASCII (decoded text)**

Selecting a field in the Packet Details Pane highlights its corresponding bytes.

---

# Packet Coloring

Wireshark automatically colors packets based on protocol or predefined rules.

Coloring helps quickly identify different types of traffic.

Examples:

- TCP
- UDP
- HTTP
- DNS
- Errors or unusual packets

Packet coloring makes large captures easier to analyze.

---

# Types of Coloring Rules

## Temporary Rules

- Active only during the current Wireshark session.
- Disappear when Wireshark is closed.

---

## Permanent Rules

- Saved in the Wireshark profile.
- Available every time Wireshark is opened.

Users can create custom coloring rules to highlight important traffic.

---

# Capturing Network Traffic

Wireshark provides simple controls for packet capture.

| Button | Function |
|---------|----------|
| 🟦 Blue Shark | Start capturing packets |
| 🟥 Red Square | Stop capturing |
| 🟩 Green Arrow | Restart packet capture |

The **Status Bar** shows:

- Active network interface
- Number of captured packets
- Capture status

---

# Merging PCAP Files

Wireshark can combine multiple packet capture files into a single capture.

Steps:

1. Open the first PCAP.
2. Go to **File → Merge**.
3. Select another PCAP file.
4. Save the merged capture as a new file.

This is useful when traffic has been captured in multiple sessions.

---

# Viewing Capture File Details

Wireshark provides information about each capture file.

Navigate to:

```text
Statistics → Capture File Properties
```

or click the **PCAP icon** in the lower-left corner.

Useful information includes:

- File name
- File size
- File hash
- Capture start and end time
- Network interface used
- Packet statistics
- Capture comments

This information helps identify and organize multiple capture files.

---

# Key Points

- **Wireshark** captures and analyzes network packets.
- It is **not** an IDS and does not block attacks.
- Traffic is displayed in **three analysis panes**:
  - Packet List
  - Packet Details
  - Packet Bytes
- Packet coloring helps quickly identify protocols and suspicious traffic.
- Wireshark can:
  - Capture live traffic
  - Open PCAP files
  - Merge multiple PCAP files
  - Display detailed capture file information
