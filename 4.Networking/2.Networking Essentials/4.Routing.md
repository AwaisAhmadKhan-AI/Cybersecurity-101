# Routing

## Overview

* Routing = process of forwarding packets between networks
* Routers determine the best path for data transmission
* Internet consists of:

  * Millions of routers
  * Billions of connected devices

---

# Why Routing is Needed

* Different networks must communicate with each other
* Routers help transfer packets between networks
* Multiple paths may exist between source and destination

Example:

* Network 1 communicates with Network 2 or Network 3 through routers

---

# Router Responsibilities

Routers:

* Receive packets
* Examine destination IP addresses
* Choose the best route
* Forward packets through appropriate links

---

# Multiple Paths

* More than one route can exist between devices
* Routers use routing algorithms to determine:

  * Fastest path
  * Most efficient path
  * Best available route

---

# Routing Protocols

Routing protocols help routers exchange network information and build routing tables.

---

# OSPF (Open Shortest Path First)

## Overview

* Dynamic routing protocol
* Open standard protocol
* Commonly used in enterprise networks

## Features

* Routers share network topology information
* Calculates shortest and most efficient path
* Maintains a map of the network

## Benefits

* Fast convergence
* Efficient routing decisions
* Scalable for large networks

---

# EIGRP (Enhanced Interior Gateway Routing Protocol)

## Overview

* Cisco proprietary routing protocol
* Combines features of multiple routing algorithms

## Features

* Shares route information between routers
* Considers metrics such as:

  * Bandwidth
  * Delay
  * Reliability

## Benefits

* Fast routing updates
* Efficient path selection
* Optimized for Cisco environments

---

# BGP (Border Gateway Protocol)

## Overview

* Main routing protocol of the Internet
* Used between different organizations and ISPs

## Features

* Exchanges routing information between large networks
* Determines paths across multiple autonomous systems

## Importance

* Enables global Internet communication
* Handles large-scale routing

---

# RIP (Routing Information Protocol)

## Overview

* Simple dynamic routing protocol
* Common in small networks

## Features

* Uses hop count as routing metric
* Chooses route with the fewest hops

## Limitations

* Slower convergence
* Less scalable
* Limited efficiency in large networks

---

# Key Points

* Routing enables communication between different networks
* Routers forward packets using routing tables
* Multiple routes may exist between devices
* Routing protocols help routers exchange path information

Common routing protocols:

* OSPF → enterprise dynamic routing
* EIGRP → Cisco optimized routing
* BGP → Internet-wide routing
* RIP → simple small-network routing
