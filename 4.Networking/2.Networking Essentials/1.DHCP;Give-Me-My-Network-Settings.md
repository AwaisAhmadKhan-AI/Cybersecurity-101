# DHCP: Give Me My Network Settings

## Overview

* DHCP stands for:

```text
Dynamic Host Configuration Protocol
```

* DHCP automatically assigns network settings to devices connected to a network.

* Common example:

  * Connecting laptop or smartphone to WiFi
  * Device automatically receives network configuration
  * No manual setup required

---

# Network Settings Required

For a device to communicate on a network, it needs:

* IP Address
* Subnet Mask
* Default Gateway (Router)
* DNS Server

Example:

| Setting | Purpose |
|---|---|
| IP Address | Identifies device on network |
| Subnet Mask | Defines network range |
| Gateway | Routes traffic outside local network |
| DNS Server | Resolves domain names to IPs |

---

# Why DHCP is Important

## Advantages

### Automatic Configuration

* No need to manually configure devices

---

### Prevents IP Conflicts

* Avoids duplicate IP addresses on the same network

---

### Easy for Mobile Devices

* Devices can move between networks easily

---

### Centralized Management

* Network settings controlled from DHCP server

---

# Static vs Dynamic Configuration

## Static Configuration

Manual configuration of:

* IP address
* Gateway
* DNS

Usually used for:

* Servers
* Routers
* Network devices

Reason:

* Devices need fixed IP addresses

---

## Dynamic Configuration

Automatic configuration using DHCP.

Usually used for:

* Laptops
* Smartphones
* User computers

---

# DHCP Protocol

## Protocol Details

* Application layer protocol
* Uses UDP

Ports used:

| Device | Port |
|---|---|
| DHCP Server | UDP 67 |
| DHCP Client | UDP 68 |

---

# DHCP Process (DORA)

DHCP works in four steps called:

```text
DORA
```

Which stands for:

* Discover
* Offer
* Request
* Acknowledge

---

# Step 1: DHCP Discover

## Overview

* Client searches for DHCP server
* Broadcasts request on network

Message:

```text
DHCPDISCOVER
```

---

## Important Points

* Client has no IP address yet
* Uses source IP:

```text
0.0.0.0
```

* Sends to broadcast IP:

```text
255.255.255.255
```

* Uses broadcast MAC address:

```text
ff:ff:ff:ff:ff:ff
```

---

# Step 2: DHCP Offer

## Overview

* DHCP server responds with available IP address

Message:

```text
DHCPOFFER
```

---

## Information Sent

Server provides:

* Offered IP address
* Subnet mask
* Gateway
* DNS server
* Lease information

---

# Step 3: DHCP Request

## Overview

* Client accepts offered IP address

Message:

```text
DHCPREQUEST
```

---

## Purpose

* Tells DHCP server:

  * Client wants to use offered IP

---

# Step 4: DHCP Acknowledge

## Overview

* Server confirms IP assignment

Message:

```text
DHCPACK
```

---

## Result

* Client can now use network
* Configuration becomes active

---

# DHCP Packet Flow Example

## Packet Capture

```bash
tshark -r DHCP-G5000.pcap -n
```

Output:

```text
1   0.000000      0.0.0.0 → 255.255.255.255 DHCP Discover

4   4.228117 192.168.66.1 → 192.168.66.133 DHCP ACK
```

# DHCP Communication Analysis

## Before Getting an IP

Client uses:

```text
Source IP: 0.0.0.0
Destination IP: 255.255.255.255
```

Reason:

* Client has no IP configuration yet

---

## Broadcast Communication

Client broadcasts packets because:

* It does not know DHCP server address

Broadcast MAC:

```text
ff:ff:ff:ff:ff:ff
```

---

## DHCP Server Response

Server replies with:

* Available IP address
* Network settings
* Lease duration

---

# Information Provided by DHCP

At the end of the process, client receives:

## IP Address

Used to identify device on network.

---

## Subnet Mask

Defines local network range.

---

## Default Gateway

Routes traffic outside local network.

---

## DNS Server

Used to resolve domain names.

Example:

```text
google.com → 142.250.x.x
```

---

# DHCP Lease

## Overview

* DHCP assigns IP addresses temporarily.
* This is called a lease.

---

## Lease Renewal

* Client must renew lease periodically.
* Prevents permanent IP allocation.
