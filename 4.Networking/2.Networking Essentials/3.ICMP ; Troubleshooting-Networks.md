# ICMP (Internet Control Message Protocol)

## Overview

* ICMP = Internet Control Message Protocol
* Mainly used for:

  * Network diagnostics
  * Error reporting
  * Troubleshooting connectivity

* Works alongside IP protocol

---

# Main ICMP Commands

Two common tools use ICMP:

| Command | Purpose |
|---|---|
| `ping` | Tests connectivity and measures response time |
| `traceroute` / `tracert` | Discovers path packets take across network |

---

# Ping Command

## Purpose

`ping` checks whether a target system is reachable.

It helps determine:

* If target host is online
* If network connection exists
* Round-Trip Time (RTT)

---

# How Ping Works

Ping uses:

```text
ICMP Echo Request  → Type 8
ICMP Echo Reply    → Type 0
```

Process:

1. Sender sends ICMP Echo Request
2. Target replies with ICMP Echo Reply
3. RTT is measured

---

# Ping Example

Command:

```bash
ping 192.168.11.1 -c 4
```

Explanation:

* `-c 4` sends only 4 packets

# RTT Values

Ping calculates:

| Metric | Meaning |
|---|---|
| Minimum RTT | Fastest response |
| Average RTT | Average response time |
| Maximum RTT | Slowest response |
| mdev | Standard deviation |

---

# Reasons Ping Might Fail

Ping may not receive replies because:

* Target system is offline
* Firewall blocks ICMP traffic
* Network connectivity issue exists
* Router blocks packets

---

# Traceroute / Tracert

## Purpose

Traceroute discovers:

* Route packets take to destination
* Routers between source and target

Linux:

```bash
traceroute
```

Windows:

```cmd
tracert
```

---

# TTL (Time To Live)

Traceroute relies on:

```text
TTL = Time To Live
```

TTL represents:

* Maximum number of routers packet can pass through

Each router:

1. Decreases TTL by 1
2. Forwards packet

When TTL becomes 0:

* Router drops packet
* Sends ICMP Time Exceeded message

---

# ICMP Time Exceeded

Traceroute uses:

```text
ICMP Type 11
```

This reveals each router in the path.

---

# How Traceroute Works

Traceroute sends packets with gradually increasing TTL values:

| TTL | Result |
|---|---|
| 1 | First router responds |
| 2 | Second router responds |
| 3 | Third router responds |

This continues until destination is reached.

---

# Traceroute Example

Command:

```bash
traceroute example.com
```

---

# Understanding `* * *`

Asterisks mean:

* Router did not respond
* ICMP message blocked
* Packet filtered by firewall

---

# Information Revealed by Traceroute

Traceroute may reveal:

* Private IP addresses
* Public IP addresses
* ISP routers
* Domain names
* Geographic locations

---

# Route Changes

Traceroute results may differ because:

* Internet routing changes dynamically
* Different paths may be selected

# ICMP Packet Types

| ICMP Type | Purpose |
|---|---|
| Type 0 | Echo Reply |
| Type 8 | Echo Request |
| Type 11 | Time Exceeded |

---

# ICMP in Networking

ICMP is essential for:

* Network troubleshooting
* Connectivity testing
* Path discovery
* Error reporting

---

# Key Points

* ICMP = Internet Control Message Protocol
* Used for diagnostics and troubleshooting
* `ping` tests connectivity
* `traceroute` discovers network path
* Ping uses:

  * ICMP Echo Request (Type 8)
  * ICMP Echo Reply (Type 0)

* Traceroute uses:

  * ICMP Time Exceeded (Type 11)

* TTL determines packet lifetime
* Routers decrease TTL by 1
* Traceroute reveals routers between source and target
* Firewalls may block ICMP traffic
