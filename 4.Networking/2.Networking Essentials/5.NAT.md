# NAT (Network Address Translation)

## Overview

* NAT = Network Address Translation
* Used to conserve public IPv4 addresses
* Allows multiple private devices to share a single public IP address

---

# Why NAT is Needed

## IPv4 Address Limitation

* IPv4 supports around 4 billion addresses
* Rapid growth of Internet-connected devices caused address exhaustion

Examples of connected devices:

* Computers
* Smartphones
* Security cameras
* Smart appliances
* IoT devices

---

# Main Idea of NAT

* Many private IP addresses use one public IP address for Internet access

Example:

* A company with 20 computers can access the Internet using:

  * 1 public IP address
  * instead of 20 public IP addresses

---

# Private vs Public IP Addresses

## Private IP Addresses

Used inside local networks.

Examples:

* `192.168.x.x`
* `10.x.x.x`
* `172.16.x.x – 172.31.x.x`

These addresses are:

* Not routable on the Internet
* Used internally within organizations

---

## Public IP Addresses

* Used on the Internet
* Assigned by ISPs
* Globally unique

---

# How NAT Works

## NAT Router Responsibilities

A NAT-enabled router:

* Translates private IP addresses into public IP addresses
* Tracks active connections
* Maintains a translation table

---

# NAT Translation Table

The router stores:

* Internal IP address
* Internal port number
* External/public IP address
* External port number

This allows returning traffic to reach the correct internal device.

---

# Example of NAT Translation

## Internal Connection

Laptop initiates connection:

* Private IP: `192.168.0.129`
* Source Port: `15401`

---

## External View

Web server sees connection from:

* Public IP: `212.3.4.5`
* Source Port: `19273`

The router performs translation automatically.

---

# NAT Process

## Step 1

Internal device sends packet to NAT router.

---

## Step 2

Router replaces:

* Private IP address
* Private source port

with:

* Public IP address
* New external port

---

## Step 3

Router stores mapping in NAT table.

---

## Step 4

Responses from Internet return to router.

---

## Step 5

Router checks translation table and forwards packet to correct internal device.

---

# Advantages of NAT

## Conserves Public IP Addresses

* Multiple devices share one public IP

---

## Adds Basic Privacy

* Internal IP addresses are hidden from the Internet

---

## Reduces IPv4 Exhaustion

* Helps delay depletion of IPv4 addresses

---

# Limitations of NAT

* Adds processing overhead on router
* Complicates some peer-to-peer connections
* Can cause issues with certain applications/services

---

# Key Points

* NAT = Network Address Translation
* Solves IPv4 address exhaustion problem
* Allows multiple private devices to use one public IP
* NAT routers maintain translation tables
* Internal private IPs remain hidden from the Internet
* Commonly used in homes and organizations
