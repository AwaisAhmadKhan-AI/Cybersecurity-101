# Device Security

## Overview

**Device Security** protects your computer using **hardware-based security features**. These features help defend your system from advanced attacks.

---

# Core Isolation

**Core Isolation** protects important parts of the Windows operating system from malware.

### Memory Integrity

- Prevents malicious code from being injected into high-security processes.
- Adds an extra layer of protection against advanced attacks.

> ⚠️ **Recommendation:** Leave this setting enabled unless you know exactly what you're doing.

---

# Security Processor (TPM)

A **Trusted Platform Module (TPM)** is a special security chip built into many computers.

It:

- Securely stores encryption keys and passwords.
- Performs cryptographic operations.
- Protects sensitive data from being tampered with.

Because TPM is hardware-based, malware cannot easily access or modify its security functions.

---

# Why TPM is Important

TPM helps:

- Protect encryption keys.
- Improve device security.
- Support features like **BitLocker** and **Windows Hello**.
- Prevent attackers from tampering with sensitive security data.

---

# Key Points

- **Device Security** uses hardware features to protect your computer.
- **Core Isolation** protects critical parts of Windows.
- **Memory Integrity** blocks malicious code from entering secure processes.
- **TPM (Trusted Platform Module)** is a dedicated security chip.
- TPM securely stores encryption keys and performs cryptographic operations.
- Keep the default security settings enabled unless you fully understand the changes.
