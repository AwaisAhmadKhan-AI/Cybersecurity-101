# Windows Security

## Overview

**Windows Security** is a built-in security application provided by **Microsoft**.

It acts as a central place to manage the tools that protect:

* Your computer (device)
* Your personal data

You can use Windows Security to monitor your device's security status and manage different protection features.

---

# Where to Find Windows Security

You can open Windows Security by going to:

**Settings → Update & Security → Windows Security**

Then click **Open Windows Security**.

---

# Main Protection Areas

Windows Security is divided into several **Protection Areas**, each responsible for a different part of your computer's security.

## 1. Virus & Threat Protection

Protects your computer from:

* Viruses
* Malware
* Ransomware
* Other malicious software

It also lets you:

* Run virus scans
* View detected threats
* Update antivirus protection

---

## 2. Firewall & Network Protection

Helps protect your computer from unauthorized network access.

It:

* Monitors incoming and outgoing network traffic
* Blocks suspicious connections
* Helps prevent hackers from accessing your computer

---

## 3. App & Browser Control

Protects you while using:

* Applications
* Web browsers

It helps:

* Block dangerous apps
* Warn about unsafe websites
* Prevent harmful downloads

---

## 4. Device Security

Protects the hardware and core system of your computer.

It includes security features that help defend against low-level attacks targeting the operating system or hardware.

---

# Windows Security Status Icons

Windows Security uses colored icons to quickly show your device's security status.

## 🟢 Green

Your device is **properly protected**.

* No immediate action is needed.
* All important protections are working.

---

## 🟡 Yellow

A **security recommendation** is available.

This is not an emergency, but Microsoft recommends reviewing the suggested action.

---

## 🔴 Red

A **serious security issue** requires immediate attention.

For example:

* Antivirus is turned off.
* Firewall is disabled.
* A critical protection feature needs fixing.

You should resolve red warnings as soon as possible.

# Windows Server vs Windows 10

The TryHackMe lab uses **Windows Server 2019**.

Because of this:

* The Windows Security interface looks slightly different.
* However, the security features work in a similar way to **Windows 10** and **Windows 11**.

So don't worry if your own computer looks different.

# Why Windows Security Is Important

Windows Security helps keep your computer safe by:

* Detecting malware
* Blocking cyber threats
* Protecting your network
* Securing your hardware
* Warning you when something needs attention

Since it is built into Windows, you don't need to install extra software for basic protection.

---

# Key Points

* **Windows Security** is Microsoft's built-in security application.
* It protects both your **device** and **data**.
* It can be opened from **Settings**.
* It contains four main protection areas:

  * Virus & Threat Protection
  * Firewall & Network Protection
  * App & Browser Control
  * Device Security
* Status colors:

  * 🟢 Green = Everything is secure.
  * 🟡 Yellow = Review recommended actions.
  * 🔴 Red = Immediate attention required.
* Windows Server 2019 may look different from Windows 10/11, but the security features are largely the same.
