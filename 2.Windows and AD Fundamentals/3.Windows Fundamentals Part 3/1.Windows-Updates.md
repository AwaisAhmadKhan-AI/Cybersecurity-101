# Windows Updates

## Overview

**Windows Update** is a service provided by **Microsoft** that keeps Windows and other Microsoft products secure and up to date.

It downloads and installs:

* Security updates
* Bug fixes (patches)
* New features
* Performance improvements

It also updates Microsoft products like **Microsoft Defender**.

---

# Why Are Windows Updates Important?

Windows updates help:

* Fix security vulnerabilities
* Protect your computer from hackers and malware
* Improve system stability and performance
* Add new features and improvements
* Keep your operating system secure

Without regular updates, your computer becomes more vulnerable to cyber attacks.

---

# Patch Tuesday

Microsoft usually releases updates on the **second Tuesday of every month**.

This day is called **Patch Tuesday**.

However, if a serious security issue is discovered, Microsoft does **not** wait until Patch Tuesday. Instead, it releases an **emergency update** immediately.

---

# Where to Find Windows Update

You can access Windows Update from:

**Settings → Windows Update**

### Another Method

Open **Run** (`Win + R`) or **Command Prompt (CMD)** and type:

```cmd
control /name Microsoft.WindowsUpdate
```

This opens the Windows Update settings directly.

# Windows Update in the Lab Machine

In the TryHackMe lab machine:

* Windows Update settings are **managed** (common in organizations).
* No updates are available because the lab machine **does not have Internet access**, so it cannot communicate with Microsoft's update servers.

---

# Managed Updates

In many companies or schools, Windows Update is managed by the organization's IT department.

This means:

* Users cannot freely change update settings.
* IT administrators decide when updates are installed.
* This ensures all computers stay secure and follow company policies.

Home users usually **do not** see these managed settings.

---

# Restart After Updates

Many Windows updates require a **restart**.

This is because some system files cannot be replaced while Windows is running.

After the update:

* Windows asks you to restart.
* You can usually restart immediately or schedule the restart for later.

---

# Can You Ignore Updates?

Older versions of Windows allowed users to ignore updates for a long time.

Starting with **Windows 10**, Microsoft changed this behavior.

Now:

* Updates can only be **postponed** for a limited time.
* Eventually, Windows installs the updates automatically.
* A restart will happen when required.

This helps keep devices protected from newly discovered security threats.

---

# Why Microsoft Forces Updates

Microsoft enforces updates because they:

* Close newly discovered security holes
* Protect users from malware and ransomware
* Improve system reliability
* Keep Windows stable and secure

Delaying updates for too long can leave your computer vulnerable to attacks.

---

# Key Points

* **Windows Update** keeps Windows and Microsoft products secure and up to date.
* It installs **security patches, bug fixes, performance improvements, and new features**.
* Updates are usually released on the **second Tuesday of every month (Patch Tuesday)**.
* Critical security updates can be released at **any time**.
* Windows Update can be opened from **Settings** or by running:

```cmd
control /name Microsoft.WindowsUpdate
```

* Many updates require a **restart**.
* Since **Windows 10**, updates cannot be ignored forever—they can only be delayed.
* Organizations often manage Windows Update through their IT department.
* Regular updates are essential for protecting your computer against security threats.

---

# Quick Summary

* **Windows Update** = Keeps Windows secure and updated.
* **Patch Tuesday** = Second Tuesday of every month.
* **Critical updates** = Released immediately if needed.
* **Restart required** = Many updates need a reboot.
* **Windows 10+** = Updates can be delayed but not permanently ignored.
* **Managed updates** = Common in businesses and schools where IT controls updates.
