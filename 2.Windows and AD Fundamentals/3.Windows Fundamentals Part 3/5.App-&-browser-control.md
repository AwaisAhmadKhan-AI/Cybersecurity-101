# App & Browser Control

## Overview

**App & Browser Control** helps protect your computer from:

- Malicious websites
- Phishing attacks
- Dangerous downloads
- Untrusted applications

It mainly uses **Microsoft Defender SmartScreen**.

---

# Microsoft Defender SmartScreen

**SmartScreen** checks websites, apps, and downloaded files before you open them.

It helps protect you from:

- Phishing websites (fake websites that steal information)
- Malware
- Suspicious or unknown applications
- Harmful file downloads

---

# SmartScreen Protection Levels

You can choose how SmartScreen responds to threats:

- **Warn** (Default) → Warns you before opening suspicious apps or websites.
- **Block** → Automatically blocks dangerous apps or websites.
- **Off** → Disables SmartScreen protection (Not recommended).

---

# Check Apps and Files

SmartScreen scans apps and files downloaded from the internet.

If a file is:

- Recognized as safe → It opens normally.
- Unknown or suspicious → Windows displays a warning before opening it.

---

# Exploit Protection

**Exploit Protection** is built into Windows.

It helps protect your computer from attacks that try to exploit (take advantage of) software vulnerabilities.

It works automatically in the background to improve system security.

---

# Recommendation

> ⚠️ It is recommended to **keep the default settings** unless you fully understand what you are changing.

Disabling SmartScreen or Exploit Protection can make your computer more vulnerable to cyber attacks.

---

# Key Points

- **App & Browser Control** protects against malicious websites, apps, and downloads.
- **Microsoft Defender SmartScreen** checks websites, apps, and files before they run.
- SmartScreen modes:
  - **Warn** → Shows a warning.
  - **Block** → Blocks the threat.
  - **Off** → Disables protection (not recommended).
- **Exploit Protection** defends against attacks that exploit software vulnerabilities.
- Keep the **default settings** for the best security.
