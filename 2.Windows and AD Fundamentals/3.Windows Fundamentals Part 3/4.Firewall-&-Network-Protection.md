# Firewall & Network Protection

## What is a Firewall?

A **firewall** is a security feature that monitors **incoming and outgoing network traffic**.

Think of it as a **security guard** at a door:
- ✅ Allows safe connections.
- ❌ Blocks unauthorized or suspicious connections.

It protects your computer from hackers and unwanted network access.

---

# Firewall Profiles

Windows Defender Firewall has **3 network profiles**.

### 1. Domain

- Used in **organizations or companies**.
- The computer is connected to a **domain controller**.

---

### 2. Private

- Used for **trusted networks** like:
  - Home Wi-Fi
  - Personal networks

---

### 3. Public

- Used for **untrusted public networks**, such as:
  - Coffee shops
  - Airports
  - Hotels
  - Public Wi-Fi

This profile has the **strictest security settings**.

---

# Firewall Options

For each network profile, you can:

- Turn the firewall **On/Off**
- **Block all incoming connections**

> ⚠️ **Recommendation:** Keep Windows Defender Firewall **enabled** unless you know exactly what you're doing.

---

# Allow an App Through Firewall

Some applications need network access.

Windows lets you choose which apps are allowed through the firewall.

You can:
- Allow an app on **Private** networks.
- Allow an app on **Public** networks.
- View additional information using the **Details** button (if available).

---

# Advanced Settings

Advanced Settings allow experienced users to:

- Create custom firewall rules.
- Control incoming and outgoing traffic.
- Configure advanced security settings.

> ⚠️ This section is intended for advanced users or system administrators.

---

# Open Firewall from Run

You can open Windows Defender Firewall by running:

```cmd
WF.msc
```

---

# Key Points

- A **firewall** monitors and controls network traffic.
- It acts like a **security guard** for your computer.
- Windows has **3 firewall profiles**:
  - **Domain** → Organization networks.
  - **Private** → Trusted home networks.
  - **Public** → Untrusted public Wi-Fi.
- Keep the firewall **enabled** for better security.
- You can allow trusted apps through the firewall.
- **WF.msc** opens Windows Defender Firewall.
