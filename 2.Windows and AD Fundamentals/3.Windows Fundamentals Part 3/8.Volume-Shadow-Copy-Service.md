# Volume Shadow Copy Service (VSS)

## Overview

**Volume Shadow Copy Service (VSS)** is a Windows feature that creates **snapshots (point-in-time copies)** of files and system data.

These snapshots allow you to restore your system or files if something goes wrong.

---

# Where Are Shadow Copies Stored?

Shadow copies are stored in the:

```text
System Volume Information
```

folder on drives where **System Protection** is enabled.

---

# What Can You Do with VSS?

If **System Protection** is turned on, you can:

- Create a **Restore Point**.
- Restore your system to a previous state.
- Configure restore settings.
- Delete old restore points.

---

# Why Is VSS Important?

VSS helps recover your system after problems like:

- Software failures
- Bad updates
- Accidental changes
- Some malware attacks

It lets you roll your system back to a working state.

---

# Security Risk

Many **ransomware** attacks try to **delete Shadow Copies**.

Why?

Because if Shadow Copies are deleted:

- You cannot restore your files using System Restore.
- Recovery becomes much harder unless you have an **offline or off-site backup**.

---

# Key Points

- **VSS (Volume Shadow Copy Service)** creates snapshots of files and system data.
- Snapshots are stored in the **System Volume Information** folder.
- VSS allows you to:
  - Create Restore Points.
  - Restore your system.
  - Manage restore settings.
- Ransomware often deletes Shadow Copies to prevent recovery.
- Always keep **offline or off-site backups** for better protection.
