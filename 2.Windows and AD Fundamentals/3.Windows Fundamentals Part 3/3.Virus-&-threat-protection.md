# Virus & Threat Protection

## Overview

**Virus & Threat Protection** is a feature of **Windows Security** that helps protect your computer from:

* Viruses
* Malware
* Ransomware
* Spyware
* Other security threats

It has two main sections:

1. **Current Threats**
2. **Virus & Threat Protection Settings**

---

# 1. Current Threats

This section lets you scan your computer for malware and view information about detected threats.

---

## Scan Options

Windows Defender provides different types of scans depending on what you want to check.

### Quick Scan

* Scans the most common places where malware is usually found.
* Fastest scan.
* Best for regular security checks.

---

### Full Scan

* Scans **every file** and all running programs on your hard drive.
* Much more thorough than a Quick Scan.
* Can take **more than one hour**, depending on your system.

---

### Custom Scan

* Lets you choose specific files or folders to scan.
* Useful if you only want to check one location.

---

# Threat History

This section shows information about previous scans and detected threats.

### Last Scan

Shows details of the most recent antivirus scan performed by Windows Defender.

Windows Defender automatically scans your device to help keep it secure.

---

### Quarantined Threats

If malware is detected, Windows Defender can move it into **Quarantine**.

**Quarantine** is a safe, isolated area where the malicious file cannot run or harm your computer.

Windows will remove quarantined threats automatically after some time.

---

### Allowed Threats

Sometimes Windows Defender may detect a file as dangerous, but you choose to allow it.

These files appear under **Allowed Threats**.

> **Warning:** Only allow a detected threat if you are **100% sure** it is safe. Allowing malicious software can compromise your computer.

---

# 2. Virus & Threat Protection Settings

This section lets you configure how Windows Defender protects your computer.

---

## Real-Time Protection

* Continuously monitors your computer.
* Detects and blocks malware as soon as it tries to run or install.
* Provides immediate protection without waiting for a manual scan.

> **Recommendation:** Keep Real-Time Protection **enabled** on your personal computer.

---

## Cloud-Delivered Protection

Windows Defender connects to Microsoft's cloud services to:

* Receive the latest threat information
* Detect new malware faster
* Improve protection against newly discovered threats

This provides quicker and more accurate protection.

---

## Automatic Sample Submission

If Windows Defender finds a suspicious file, it can automatically send a sample to Microsoft.

Microsoft analyzes the sample to:

* Improve malware detection
* Protect other Windows users from new threats

---

## Controlled Folder Access

This feature helps protect your important files from **ransomware**.

When enabled:

* Only trusted applications can modify protected folders.
* Unknown or malicious programs are blocked from changing your files.

This helps prevent ransomware from encrypting your personal documents.

---

## Exclusions

Sometimes administrators or advanced users don't want Windows Defender to scan certain files or folders.

These can be added to the **Exclusions** list.

Excluded items are ignored during antivirus scans.

Common reasons include:

* Preventing false positives
* Avoiding conflicts with trusted software
* Improving performance

> **Warning:** Excluding the wrong file or folder can leave your computer vulnerable to malware. Only add exclusions if you are completely sure they are safe.

---

## Notifications

Windows Defender displays important security notifications, such as:

* Threats detected
* Scan results
* Security recommendations
* Protection status

These alerts help you stay informed about your device's security.

---

# Virus & Threat Protection Updates

Windows Defender uses **security definitions** to recognize the latest malware.

You can manually click **Check for updates** to download the newest virus definitions.

Keeping these definitions updated helps Defender detect the newest threats.

---

# Ransomware Protection

Windows Defender includes protection against ransomware.

This feature depends on:

* **Controlled Folder Access**
* **Real-Time Protection**

Both should be enabled for ransomware protection to work properly.

---

# Note About the TryHackMe Lab

In the TryHackMe virtual machine:

* **Real-Time Protection is turned off.**

This is safe because:

* The VM has **no Internet connection**.
* There are **no threats inside the lab machine**.
* Turning it off improves VM performance.

> **Important:** On your personal computer, Real-Time Protection should always remain **enabled**, unless another trusted antivirus program is providing the same protection.

---

# On-Demand Scan

You can manually scan any file or folder.

Simply:

1. Right-click the file or folder.
2. Select **Scan with Microsoft Defender**.

This is useful if you download a file and want to check it before opening it.

---

# Key Points

* **Virus & Threat Protection** protects against malware, viruses, ransomware, and other threats.
* It has two main sections:

  * Current Threats
  * Virus & Threat Protection Settings
* Scan options:

  * **Quick Scan** → Common locations.
  * **Full Scan** → Entire computer.
  * **Custom Scan** → Selected files or folders.
* **Quarantine** safely isolates malicious files.
* **Allowed Threats** should only be used when you are completely sure the file is safe.
* **Real-Time Protection** continuously blocks threats and should normally stay enabled.
* **Cloud-Delivered Protection** provides faster detection using Microsoft's cloud.
* **Automatic Sample Submission** helps Microsoft improve malware detection.
* **Controlled Folder Access** protects important files from ransomware.
* **Exclusions** prevent selected files or folders from being scanned but should be used carefully.
* **Notifications** inform you about your computer's security status.
* Regularly update Defender's virus definitions for the best protection.
* You can manually scan any file by right-clicking it and choosing **Scan with Microsoft Defender**.

---
