# Windows Domains

# Overview

* Windows Domain = group of users & computers managed centrally
* Uses **Active Directory (AD)** for centralized management
* Server running AD services = **Domain Controller (DC)**

---

# Why Windows Domains are Needed

Managing few computers manually is easy.

Example:

* 5 computers
* 5 employees

Admin can:

* Configure users manually
* Manage each PC individually
* Fix systems directly

---

As business grows:

* 157 computers
* 320 users
* Multiple offices

Manual management becomes difficult.

Windows Domains solve this problem through centralized administration.

---

# Active Directory (AD)

## Purpose

* Central repository for managing:

  * Users
  * Computers
  * Policies
  * Authentication

---

## Domain Controller (DC)

* Server running Active Directory services
* Handles:

  * Authentication
  * User management
  * Security policies

---

# Main Advantages of Windows Domains

## 1. Centralized Identity Management

* Manage all users from one place
* Create/edit/delete users easily
* Credentials work across domain computers

---

## 2. Centralized Security Policies

Admins can apply policies to:

* Users
* Computers
* Entire network

Examples:

* Disable Control Panel
* Restrict software installation
* Enforce password policies

---

# Real-World Example

## Schools / Universities

Students receive:

* Username
* Password

These credentials work on all campus computers.

---

## How Authentication Works

1. User enters credentials
2. Computer sends authentication request to Active Directory
3. AD verifies credentials
4. User gets access

Credentials don't need to exist locally on every machine.

---

# Policy Management Example

Administrators can restrict users from:

* Accessing Control Panel
* Installing software
* Changing system settings

Policies are deployed network-wide using Active Directory.

# Important Terms

| Term | Meaning |
|---|---|
| Domain | Centralized Windows network |
| Active Directory | Directory service for management |
| Domain Controller (DC) | Server running AD |
| Authentication | Verifying user identity |
| Policy | Rules applied to users/computers |

---

# Key Points

* Windows Domains centralize network management
* Active Directory manages users & systems
* Domain Controller runs AD services
* Users can log into any domain computer
* Policies can be applied across entire network
* Domains are essential for large organizations
