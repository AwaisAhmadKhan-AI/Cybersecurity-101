# Managing Users in Active Directory

# Overview

As a Domain Administrator, tasks include:

* Managing OUs
* Creating/deleting users
* Delegating permissions
* Resetting passwords

---

# Organizational Changes

## Scenario

* Company structure changed
* AD must match updated organizational chart

Tasks:

* Remove unnecessary OUs
* Add/delete users
* Configure delegation

---

# Deleting Extra OUs

## Problem

Trying to delete an OU gives error because:

* OUs are protected from accidental deletion by default

---

# Enable Advanced Features

To remove protection:

```txt
View → Advanced Features
```

This enables advanced AD options.

---

# Disable Deletion Protection

Steps:

1. Right-click OU
2. Select Properties
3. Open Object tab
4. Uncheck:

```txt
Protect object from accidental deletion
```

5. Apply changes
6. Delete OU

---

# Important Warning

Deleting an OU also deletes:

* Users
* Groups
* Child OUs

inside that OU.

---

# Managing Users

After removing extra OU:

* Compare AD users with organizational chart
* Create missing users
* Delete unnecessary users

---

# Delegation in Active Directory

## Overview

Delegation = giving limited administrative control to users.

Benefits:

* Reduces Domain Admin workload
* Allows IT support to manage users

---

# Example Delegation

## Scenario

Phillip manages IT support.

Goal:

* Allow Phillip to reset passwords for:

  * Sales
  * Marketing
  * Management

---

# Delegating Control

## Steps

1. Right-click OU
2. Select:

```txt
Delegate Control
```

3. Add user:

```txt
phillip
```

4. Click:

```txt
Check Names
```

5. Select task:

```txt
Reset user passwords and force password change at next logon
```

6. Finish wizard

---

# Result

Phillip can now:

* Reset passwords
* Force password changes

for users in delegated OU.

---

# Phillip's Credentials

```txt
Username: phillip
Password: Claire2008
```

---

# RDP Login Format

```txt
THM\phillip
```

---

# Important Note

Phillip cannot open:

```txt
Active Directory Users and Computers
```

because he lacks full admin privileges.

Instead, PowerShell is used.

---

# Resetting Password with PowerShell

## Command

```powershell
Set-ADAccountPassword sophie -Reset -NewPassword (Read-Host -AsSecureString -Prompt 'New Password') -Verbose
```

---

# What This Does

* Resets Sophie's password
* Prompts securely for new password
* Shows verbose output

---

# Force Password Change at Next Login

## Command

```powershell
Set-ADUser -ChangePasswordAtLogon $true -Identity sophie -Verbose
```

---

# Purpose

Forces user to:

* Change password after login

Improves security.

---

# Sophie's Login

## RDP Username Format

```txt
THM\sophie
```

Use:

* Sophie's account
* Newly reset password

---

# Key Concepts

| Term | Meaning |
|---|---|
| OU | Organizational Unit |
| Delegation | Giving limited admin rights |
| ADUC | Active Directory Users and Computers |
| Security Principal | Object that can authenticate |
| PowerShell | Command-line management tool |

---

# Key Points

* OUs are protected from accidental deletion
* Advanced Features must be enabled to remove protection
* Delegation allows limited administrative control
* PowerShell can manage AD users without full admin access
* `Set-ADAccountPassword` resets passwords
* `Set-ADUser` forces password change at login
* Delegation improves administration efficiency
