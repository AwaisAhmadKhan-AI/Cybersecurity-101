# Managing Computers in Active Directory (AD)

# Overview

* By default, all domain-joined machines are placed in the:

```text
Computers
```

container.

* Keeping all devices in one container is poor practice.
* Machines should be organized based on their role.

---

# Main Types of Devices in AD

## 1. Workstations

### Description

* Computers used by employees daily
* Used for:

  * Work
  * Browsing
  * Office tasks

### Important Notes

* Regular users log into these systems
* Privileged/admin accounts should NOT be used here

### Examples

* Employee PCs
* Laptops

---

## 2. Servers

### Description

* Systems that provide services across the network

### Used For

* Hosting applications
* File sharing
* Databases
* Web services

### Examples

* File servers
* Web servers
* Application servers

---

## 3. Domain Controllers (DCs)

### Description

* Most sensitive systems in the domain
* Manage Active Directory services

### Important Functions

* Authenticate users
* Store domain information
* Manage policies

### Security Importance

* Contain password hashes for all users
* Critical infrastructure systems

---

# Why Organize Computers into OUs?

Benefits:

* Easier management
* Better security
* Apply different Group Policies
* Separate workstations from servers

---

# Creating New OUs

## Required OUs

Create these under:

```text
thm.local
```

### OUs to Create

* Workstations
* Servers

> Note:
> Domain Controllers already have their own default OU.

---

# Final OU Structure

```text
thm.local
│
├── Workstations
├── Servers
└── Domain Controllers
```

---

# Moving Computers to Correct OUs

## Move to Workstations OU

Move:

* Personal computers
* Employee laptops

---

## Move to Servers OU

Move:

* Server systems

---

# Why This Separation Matters

This structure allows administrators to:

* Apply different security policies
* Manage systems efficiently
* Restrict permissions properly
* Improve domain organization

Example:

* Workstations may have stricter user restrictions
* Servers may require different security configurations

---

# Key Points

* Default joined machines go into:

```text
Computers
```

* Main device categories:

  * Workstations
  * Servers
  * Domain Controllers

* Create separate OUs for better management
* Move computers into appropriate OUs
* Helps with policy management and security
