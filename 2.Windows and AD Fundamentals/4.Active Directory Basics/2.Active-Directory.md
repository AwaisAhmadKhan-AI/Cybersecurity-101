# Active Directory (AD DS)

# Overview

* Active Directory Domain Services (AD DS) = core of Windows Domain
* Works as a central catalogue/database
* Stores information about all network objects

---

# Objects in Active Directory

AD stores many object types:

* Users
* Groups
* Machines (Computers)
* Printers
* Shared folders
* Services

---

# Users

## Overview

* Most common AD object
* Considered a **Security Principal**

Security Principals can:

* Authenticate in domain
* Access network resources
* Receive permissions

---

# Types of Users

## 1. People Users

Represent actual employees/users.

Examples:

* Staff members
* Students
* Administrators

---

## 2. Service Users

Used by applications/services.

Examples:

* IIS
* MSSQL

Characteristics:

* Limited privileges
* Only enough permissions to run service

---

# Machines (Computer Objects)

## Overview

* Every computer joining domain gets a machine account
* Machines are also Security Principals

---

# Machine Accounts

Characteristics:

* Have domain account
* Limited permissions
* Local administrator on their own machine

---

## Machine Account Naming

Format:

```txt
COMPUTERNAME$
```

Example:

```txt
DC01$
```

---

## Machine Passwords

* Automatically rotated
* Usually 120 random characters
* Generally not accessed manually

---

# Security Groups

## Purpose

Groups simplify permission management.

Instead of assigning permissions individually:

* Add users to group
* Group receives permissions
* Users inherit group permissions

---

# Group Features

Groups can contain:

* Users
* Computers
* Other groups

Groups are also Security Principals.

---

# Important Default Security Groups

| Group | Purpose |
|---|---|
| Domain Admins | Full administrative control over domain |
| Server Operators | Manage Domain Controllers |
| Backup Operators | Access all files for backups |
| Account Operators | Create/modify accounts |
| Domain Users | All user accounts |
| Domain Computers | All computers |
| Domain Controllers | All DCs |

---

# Active Directory Users and Computers (ADUC)

## Purpose

Tool used to manage:

* Users
* Groups
* Computers
* OUs

---

## Opening ADUC

Open from:

```txt
Start Menu → Active Directory Users and Computers
```

---

# Organizational Units (OUs)

## Overview

* Container objects inside AD
* Used to organize users/computers

---

# Purpose of OUs

Mainly used for:

* Applying policies
* Organizing departments
* Managing users efficiently

---

# Example OU Structure

Example departments:

* IT
* Management
* Marketing
* R&D
* Sales

---

# Important OU Facts

* User can belong to only ONE OU
* OUs usually mirror company structure
* Policies applied at OU level

---

# Common Tasks in OUs

Admins can:

* Create users
* Delete users
* Modify users
* Reset passwords

---

# Default AD Containers

| Container | Purpose |
|---|---|
| Builtin | Default Windows groups |
| Computers | Newly joined computers |
| Domain Controllers | Stores DCs |
| Users | Default domain users/groups |
| Managed Service Accounts | Service accounts |

---

# Security Groups vs OUs

## Organizational Units (OUs)

Used for:

* Applying policies
* Organizing users/computers

Important:

* One user = one OU

---

## Security Groups

Used for:

* Granting permissions
* Access control

Examples:

* Shared folders
* Network printers

Important:

* Users can belong to multiple groups

---

# Key Differences

| Feature | OU | Security Group |
|---|---|---|
| Purpose | Organization & policies | Permissions |
| Multiple Memberships | No | Yes |
| Used For | Group Policies | Resource access |

---

# Key Points

* AD DS is central Windows domain service
* Stores users, computers, groups & resources
* Users & machines are Security Principals
* Machine accounts end with `$`
* Security groups manage permissions
* OUs organize users & apply policies
* ADUC tool manages AD objects
* Users can belong to many groups but only one OU
