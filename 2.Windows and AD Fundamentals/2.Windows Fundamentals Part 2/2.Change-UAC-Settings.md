# Change UAC Settings

## UAC (User Account Control)

### Purpose
- Protects Windows from unauthorized system changes
- Prompts for permission before high-level actions

> Disabling UAC is NOT recommended.

---

# UAC Security Levels

## 1. Always Notify
### Highest security level
- Notify for:
  - Apps making changes
  - User making changes
- Screen dims using:
```text
Secure Desktop
```

---

## 2. Notify for Apps (Default)
### Default Windows setting
- Notify only when:
  - Apps try to make changes
- No notification when:
  - User changes Windows settings

---

## 3. Notify Without Dimming
- Same as:
```text
Notify for Apps
```
- Difference:
  - Screen does NOT dim

---

## 4. Never Notify
### Lowest security level
- No alerts shown
- Apps/users can make changes silently

> Least secure option.

---

# Changing UAC Settings

## Open UAC Settings
Search:
```text
Change User Account Control settings
```

## Adjust Security Level
- Move slider:
  - Up = More secure
  - Down = Less secure

---

# Key Points

- UAC helps prevent malware/system compromise
- Default setting = Notify for apps
- Secure Desktop dims screen for protection
- Never Notify reduces security significantly
