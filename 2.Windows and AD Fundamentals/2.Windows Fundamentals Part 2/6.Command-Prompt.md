# Command Prompt (cmd)

## Overview

* `cmd` = Command Prompt
* Text-based interface to interact with Windows
* Used before GUI-based systems existed
* Still useful for:

  * Troubleshooting
  * System administration
  * Networking tasks
  * Automation

---

# Basic Commands

## hostname

Displays computer name.

```cmd
hostname
```

---

## whoami

Displays currently logged-in user.

```cmd
whoami
```

---

# Network Commands

## ipconfig

Shows network configuration details.

```cmd
ipconfig
```

### Displays

* IP Address
* Subnet Mask
* Default Gateway

---

## ipconfig Help

Use `/ ?` to display command help.

```cmd
ipconfig /?
```

Shows:

* Syntax
* Parameters
* Extra options

---

# Clearing Screen

## cls

Clears command prompt screen.

```cmd
cls
```

---

# Netstat Command

## netstat

Displays:

* Network connections
* TCP/IP statistics
* Listening ports

```cmd
netstat
```

---

## Common Parameters

### Show all connections

```cmd
netstat -a
```

### Show executable for connection

```cmd
netstat -b
```

### Show statistics

```cmd
netstat -e
```

---

# net Command

## Overview

* Used to manage network resources
* Works with subcommands

```cmd
net
```

---

# Getting Help

## General Help

```cmd
net help
```

---

## Help for Specific Subcommand

### Example

```cmd
net help user
```

---

# Useful net Subcommands

## User Management

```cmd
net user
```

## Group Management

```cmd
net localgroup
```

## Shared Resources

```cmd
net share
```

## Network Sessions

```cmd
net session
```

## Network Connections

```cmd
net use
```

---

# Key Points

* `cmd` provides direct interaction with Windows
* Useful for troubleshooting & administration
* Important commands:

  * `hostname`
  * `whoami`
  * `ipconfig`
  * `netstat`
  * `net`
* `/ ?` shows command help
* `cls` clears terminal screen
