# System Tools

## Task Scheduler

### Purpose
- Automates tasks
- Runs:
  - Programs
  - Scripts
  - Commands

### Task Triggers
- At logon/logoff
- On schedule
- One-time execution

### Example
```text
Run daily at 10:00 AM
```

### Create Task
```text
Task Scheduler → Create Basic Task
```

---

## Event Viewer

### Purpose
- View system/application logs
- Used for:
  - Troubleshooting
  - Auditing
  - Investigations

### Event Viewer Panes
1. Log providers tree
2. Event summary/details
3. Actions pane

### Windows Logs Types
- Application
- Security
- Setup
- System
- Forwarded Events

# Services and Applications

## Services

### Purpose
Manage background services.

### Service Information
- Display name
- Status
- Executable path
- Startup type

### Startup Types
- **Automatic** → Starts at boot
- **Manual** → Starts when needed
- **Disabled** → Cannot run

---

## WMI Control

### Purpose
Controls:
```text
Windows Management Instrumentation (WMI)
```

### Uses
- System management
- Remote administration
- Automation scripting

### Notes
- WMIC is deprecated
- PowerShell replaces WMIC
