# Registry Editor (regedit)

## Overview

* Windows Registry = central hierarchical database

* Stores configuration settings for:

  * Users
  * Applications
  * Hardware
  * Operating System

* Registry Editor tool:

```cmd id="6myw2z"
regedit
```

Used to:

* View registry
* Edit registry values
* Manage system configuration

---

# Information Stored in Registry

## User Profiles

* Settings for each user account
* User preferences & configurations

---

## Installed Applications

Stores:

* Installed programs
* File associations
* Supported document types

---

## Folder & Icon Settings

Contains:

* Folder preferences
* Desktop settings
* Application icon configurations

---

## Hardware Information

Stores details about:

* Connected hardware
* Drivers
* Devices

---

## Port Information

Contains:

* Ports in use
* System communication settings

---

# Registry Structure

* Organized like folders
* Main sections called:

  * Hives
  * Keys
  * Values

Common registry hives:

* `HKEY_LOCAL_MACHINE (HKLM)`
* `HKEY_CURRENT_USER (HKCU)`
* `HKEY_USERS (HKU)`
* `HKEY_CLASSES_ROOT (HKCR)`

---

# Why Registry is Important

Windows constantly references registry during operation for:

* System settings
* User settings
* Application behavior
* Hardware configuration

---

# Warning

* Registry is for advanced users
* Incorrect changes can:

  * Break applications
  * Cause boot problems
  * Affect system stability

Always be careful before modifying registry entries.
