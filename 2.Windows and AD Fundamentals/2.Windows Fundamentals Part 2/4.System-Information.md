# System Information (msinfo32)

## Overview

* `msinfo32` = Microsoft System Information tool
* Collects detailed information about:

  * Hardware
  * System components
  * Software environment
* Used for:

  * Troubleshooting
  * Diagnosing system issues
  * Viewing system specifications

---

# Main Sections

## 1. Hardware Resources

* Displays low-level hardware details
* Mostly useful for advanced troubleshooting
* Includes:

  * IRQs
  * DMA
  * Memory addresses

---

## 2. Components

Shows hardware information installed on the system.

### Examples

* Display
* Input devices
* Network adapters
* Storage devices

Useful for checking:

* Hardware details
* Driver information
* Device status

---

## 3. Software Environment

Displays software and OS-related information.

### Includes

* Running tasks
* Services
* Installed software
* Network connections
* Environment variables

---

# Environment Variables

## Overview

* Store operating system information
* Used by Windows and applications

### Examples

* OS paths
* Temp directories
* Processor information

---

## Common Variable

### `%WINDIR%`

* Points to Windows installation directory
* Usually:

```text
C:\Windows
```

Programs use it to locate Windows system files.

---

# Ways to Access Environment Variables

## Method 1

```text
msinfo32
→ Software Environment
→ Environment Variables
```

## Method 2

```text
Control Panel
→ System and Security
→ System
→ Advanced system settings
→ Environment Variables
```

## Method 3

```text
Settings
→ System
→ About
→ System info
→ Advanced system settings
→ Environment Variables
```

---

# Search Feature in msinfo32

* Search bar located at the bottom
* Helps quickly locate information

### Example

```text
Components → Search: IP Address
```

Useful for:

* Finding IP addresses
* Viewing hardware details
* Searching system entries quickly

---

# Key Points

* `msinfo32` provides detailed system information
* Useful for diagnostics and troubleshooting
* Main categories:

  * Hardware Resources
  * Components
  * Software Environment
* Environment variables help apps interact with Windows
* Built-in search makes navigation easier
