# System Configuration & Advanced System Settings

## System Configuration (MSConfig)

### Purpose
- Used for:
  - Troubleshooting
  - Diagnosing startup issues

### Open MSConfig
```cmd
msconfig
```

> Requires Administrator privileges.

---

# MSConfig Tabs

## 1. General Tab
Controls what Windows loads during startup.

### Options
- **Normal startup** → Load everything
- **Diagnostic startup** → Basic drivers/services only
- **Selective startup** → Choose what loads

---

## 2. Boot Tab
Used to configure boot settings.

### Examples
- Safe Boot
- Boot timeout
- Default OS
- Advanced boot options

---

## 3. Services Tab

### Purpose
- Shows all Windows services
- Includes:
  - Running services
  - Stopped services

### Notes
- Services run in background
- Can enable/disable services

---

## 4. Startup Tab

### Windows 10/11
Startup programs managed through:
```text
Task Manager → Startup
```

### Windows Server
Startup apps usually NOT shown in:
- Task Manager
- MSConfig

### View Startup Programs on Server
Open Run and type:
```cmd
shell:startup
```

This folder contains startup shortcuts/apps.

---

## 5. Tools Tab

Contains useful admin tools.

### Examples
- Event Viewer
- Registry Editor
- CMD
- Performance Monitor

### Notes
- Shows command for each tool
- Can launch tools directly

---

# Performance Settings

### Path
```text
Advanced → Performance → Settings
```

### Controls
- Visual effects
- Memory usage
- Virtual memory

---

# Virtual Memory (Page File)

## Purpose
- Uses disk as extra RAM
- Prevents crashes when RAM is full

## Information Available
- Page file location
- Initial size
- Maximum size
- Auto-managed or manual

---

# Startup and Recovery

### Path
```text
Advanced → Startup and Recovery → Settings
```

## Purpose
Controls:
- Startup behavior
- Crash dump settings

---

# Crash Dumps

## Purpose
Stores debugging info after BSOD/system crash.

## Dump Types
- Automatic Memory Dump
- Kernel Memory Dump
- Small Memory Dump (256 KB)
- Complete Memory Dump
- None

## Use
Helps troubleshoot system crashes.
