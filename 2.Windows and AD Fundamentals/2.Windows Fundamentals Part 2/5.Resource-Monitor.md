# Resource Monitor (resmon)

## Overview

* `resmon` = Resource Monitor
* Advanced Windows monitoring & troubleshooting tool
* Shows real-time usage of:

  * CPU
  * Memory
  * Disk
  * Network

Used for:

* Performance monitoring
* Troubleshooting slow systems
* Finding resource-heavy processes
* Detecting file locking issues

---

# Main Sections

## 1. CPU

Shows:

* CPU usage per process
* Running services
* Process activity
* Threads & handles

Useful for:

* Identifying high CPU usage
* Detecting stuck/unresponsive processes

---

## 2. Memory

Shows:

* RAM usage
* Used vs available memory
* Memory used by processes

Useful for:

* Detecting memory-heavy applications
* Troubleshooting low RAM issues

---

## 3. Disk

Shows:

* Disk activity
* Read/write operations
* Disk usage by processes
* File access details

Useful for:

* Identifying disk bottlenecks
* Detecting processes heavily using storage

---

## 4. Network

Shows:

* Network activity
* Active connections
* Sending/receiving data
* Network usage per process

Useful for:

* Monitoring internet usage
* Detecting suspicious connections
* Troubleshooting network problems

---

# Tabs in Resource Monitor

Tabs available at top:

* CPU
* Memory
* Disk
* Network

Each tab provides:

* Detailed statistics
* Real-time monitoring
* Process-specific information

---

# Real-Time Graphs

* Right-side pane displays live graphs for:

  * CPU
  * Disk
  * Memory
  * Network

Helps visualize:

* System load
* Resource spikes
* Performance trends

---

# Extra Features

Resource Monitor can:

* Start/stop services
* Pause/resume services
* Close unresponsive applications
* Detect deadlocked processes
* Identify file locking conflicts
